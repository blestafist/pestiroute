# M5.2 Local Responses Compatibility

This is an evidence-scoped offline profile report, not proof that a runtime,
model, or local account is installed or entitled. The conformance fixtures use
synthetic model IDs, loopback HTTP servers, and the pinned Connector profile
settings; they establish gateway boundary mechanics only. Live columns are
deliberately separate and remain unverified until their independently assigned
smoke cards are run and reviewed.

Offline checks use auth mode `none` against numeric-loopback fake upstreams.
Each test selects an exact synthetic model and account scope; these are not
real model or account identities. Cancellation proves request transport
cancellation only, not remote compute cancellation. The backpressure fixture
produces a 32 MiB response in gated steps, rejects whole-response/read-ahead
behavior, and verifies verbatim order after the reader resumes.

## Preflight policy boundaries

The policy is defined from pinned source audit in
[M5.2-LOCAL](M5.2-LOCAL.md#connector-enforcement-and-capability-evidence),
not inferred from synthetic fixture success. The Connector rejects known
significant excluded behavior before dispatch while preserving admitted native
bytes and unknown extensions. Examples include:

| Runtime profile | Offline source-policy rejection examples | Fixture limitation |
| --- | --- | --- |
| Ollama v0.40.3 | Stateful `conversation` / `previous_response_id`, excluded `background`, or `include` requesting omitted content | Wire disposition can be Unknown; policy rejection is gateway preflight, not a claim about server rejection. |
| vLLM v0.31.0 | `store:true` when the selected route disables storage; `background` without storage | Does not prove server/model behavior or response-store availability. |
| llama.cpp v0.6.0 | Non-empty `previous_response_id`; non-function tools the converter skips | Internal conversion is backend behavior; gateway bytes remain native and are not translated. |

These examples describe the pinned policy only. Unlisted fields remain
`unknown`, and no preflight matrix cell constitutes live engine evidence.

## Reproducible offline evidence

`TestLocalProfilesSharedConformance` and `TestLocalProfilesBackpressure` in
`internal/conformance/local_fixture_test.go` exercise each profile using
synthetic loopback fixtures. Existing native OpenAI, Anthropic translation,
and Codex conformance suites remain in the same package and are included in
the same offline test command. No background runtime, model download, external
request, or real inference is part of these checks.
