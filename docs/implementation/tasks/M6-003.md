## Scope

- Implement disposable framed-stdio parent/child test prototype in an isolated spike package under `internal/conformance`, reserving child stdout strictly for protocol framing and stderr for diagnostics.
- Implement length-prefixed framing respecting the 84 KiB encoded wire frame ceiling, correlation, and bidirectional dispatch for streaming execution, reverse credential lookup, and runtime HTTP streaming.
- Execute the exact M6-002 scenario: 1 warmup, 10 measured repetitions, 256 x 64 KiB chunks (16 MiB exact opaque payload), stalled callbacks, joint cancellation release, and a separate 4-call saturation run.

## Completion Evidence

Implemented only in `internal/conformance/stdio_spike_test.go`: before output, parent sends Execute containing a synthetic 1 KiB header and the fixed M6-002 opaque request; child validates both. Normal streaming delivers Body 1 and grants credit; Body 2 is retained without credit while credential/HTTP reverse calls proceed. The callback's 1 KiB header and four 16 KiB chunks are validated. The parent retains and counts encoded Body+callback frames during stalls and hashes output incrementally. Cancellation withholds Body credit and the HTTP callback response; Stop must set both release flags, followed by verified child exit/reap. Saturation holds three healthy calls while a fourth is cancelled, proving cancel progress before callbacks release. Each child has a watchdog for the worksheet's 10-second repetition deadline, started before `cmd.Start`; test cleanup closes stdin, kills and reaps on every failure. Saturation completion has a separate bounded wait. A deterministic child stalled on its pipe proves timeout unblocking/cleanup. No Core/production wiring or transport decision.

Environment: Go `go1.27.1-X:nodwarf5`, Linux `7.2.8-arch1-1`, x86_64, 11th Gen Intel Core i5-1135G7 (8 logical CPUs), 32,458,596 KiB RAM. Race-enabled child test binaries; helper sets `GORACE=atexit_sleep_ms=0` to exclude race-runtime's artificial post-exit delay from child-reap timings. Monotonic timing starts immediately before `cmd.Start`; first Body includes launch, Execute write, and startup. Completion stops at Complete; reap is separately measured after stdin close. CPU is child `getrusage`, excluding parent; peak RSS is Linux `/proc/<pid>/status` `VmHWM`. Queue metrics count retained encoded frame bytes and frames, not the largest individual frame. No credentials, network, or external dependencies.
