## Scope

- Add shared execution types and stream abstractions under `internal/core`:
  - `ExecutionRequest`, `RawPayload` (protocol, content type, opaque body bytes), `RequestMetadata` (transport headers, streaming preference, namespaced extensions), and required capability representation.
  - `StreamFrame` with explicit frame types (`Head`, `Body`, `Complete`), `HeadFrame` (protocol, content type, HTTP status, headers, optional GatewayError), `BodyFrame` (non-empty byte slice), and `CompleteFrame` (terminal outcome variants `succeeded`, `failed`, `cancelled`, `incomplete`, optional `UsageReport`, optional `GatewayError`).
  - Single-consumer `Stream` abstraction with `Next(context.Context) (StreamFrame, error)` and idempotent `Close() error`, enforcing ordered lifecycle (`Head -> Body* -> Complete -> EOF`), cancellation release, and transition validation.
  - `GatewayError` metadata with v1 categories, `RetryDisposition` (`safe`, `unsafe`, `unknown`), and client-safe vs diagnostic fields.
  - `UsageReport` with nullable token counts (`*int64`), source (`provider`, `estimate`, `unknown`), and completeness status.
- Document byte ownership (opaque `[]byte` immutability, producer/consumer responsibility) and idempotent `Close()` contract in code comments.
- Stop before HTTP transport/handlers (M1-007, M1-011), concrete HTTP Connector (M1-008, M1-009), configuration parsing (M1-006), runtime routing/dispatch (M1-010), descriptor registry, or universal LLM structures.

## Acceptance

- [x] Native body bytes and control metadata remain separate; `ExecutionRequest`, `RawPayload`, `StreamFrame` (Head/Body/Complete), `GatewayError`, and `UsageReport` implement the exact v1 contract semantics without universal LLM payload representations (`Message[]`, `Tool[]`, etc.).
- [x] A scripted stream producer exercises `Head -> Body* -> Complete -> EOF`, pre-head failure, idempotent `Close()`, and `context.Context` cancellation; illegal frame transitions (duplicate head, body after complete, etc.) are detected.
- [x] Unknown values (nullable token counts, unspecified retry disposition) do not silently default to zero or safe; zero tokens vs omitted tokens are distinguishable.
- [x] Package `internal/core` has no dependencies on HTTP adapters, concrete connectors, or third-party packages beyond the standard library.
