## Scope

- Create `scripts/smoke-m5.1-artifacts.py` implementing schema and redaction verification for paired direct-versus-gateway Codex inference and admin auth artifacts.
- Define JSON schemas and allowlists for:
  - Paired direct (`direct_codex`) and gateway (`gateway_responses_to_codex`) inference: scenarios (`plain_text`, `single_tool`, `two_calls`, `two_rounds`, `encrypted_reasoning`, `unsupported_rejection`), model `gpt-5.4-mini`, endpoint profiles (`offline_fixture`, `subscription_codex`), request records and scenario-specific event/tool-link evidence. Enforce paired equality for all observations, outcomes and client identity; only leg name and capture timestamp may differ. The reasoning observation records presence while ciphertext remains absent.
  - Paired redacted auth artifacts (`direct_auth`, `gateway_auth`): flows (`device_start`, `device_continue`, `refresh`), status, expiry preservation, boolean token presence, and zero secret leakage; paired flow/status/token/expiry semantics must agree.
- Enforce strict safeguards: timeout <= 30s, max output tokens <= 4096, client runs <= 2, provider dispatch caps, zero hidden retries, status/stream consistency, and strict allowlists/redaction rejecting API keys, `rt_` refresh tokens, bearer tokens, JWTs, OAuth codes, cookies, and raw prompts. Free metadata is constrained to fixed fixture/client/version labels.
- Implement `--self-test --output-dir <dir>` using loopback HTTP/SSE fakes: generates valid matched paired and auth artifacts, validates them, and confirms fail-closed rejection on deliberate secret leaks, over-cap budgets, unauthorized retries, and malformed schemas.
- Ensure self-test makes zero external network or real-provider calls and refuses unsafe public env overrides.
