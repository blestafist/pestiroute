## Outcome

Local developers and CI execute the identical verification suite—formatting, vet, unit tests, race detector, and offline build—on the pinned Go 1.27.1 toolchain, establishing the automated quality gate for [M0](../ROADMAP.md#m0--project-foundation). ## Scope

- Add a GitHub Actions workflow `.github/workflows/ci.yml` triggered on push and pull requests, pinning Go to 1.27.1 (matching `go.mod`).
- Add a shared local verification script `scripts/check.sh` (executable) that runs the identical check sequence as CI:
  - Patch whitespace: `git diff --check`
  - Formatting: `test -z "$(gofmt -l cmd internal)"`
  - Vet: `GOTOOLCHAIN=local go vet ./...`
  - Unit tests: `GOTOOLCHAIN=local go test ./...`
  - Race detection: `GOTOOLCHAIN=local go test -race ./...`
  - Offline artifact-free build: `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go build -o /dev/null ./...`
- Document the shared check command in `README.md`.
- Explicit limits: no external network calls, mock credentials, real-provider smoke tests, release packaging, or changes to runtime code in `cmd/` or `internal/`.

## Acceptance
