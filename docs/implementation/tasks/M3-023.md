## Scope

- In `internal/core`, define `RouteBudget` (`UnknownEstimate`: `"reject"` or `"reserve"`; `ConservativeTokens`: positive when `reserve`, forbidden/0 when `reject` per [M3-CONFIG.md](../M3-CONFIG.md#per-route-estimate-budget)) and estimation resolution helpers that invoke a target Connector's `EstimateUsage(ctx, UsageQuery, InvocationServices)`.
- Map supported and known estimates (`Supported: true, Known: true`) with non-negative input/output token counts to their checked sum as `estimate_tokens`, preserving the reported `Method`.
- Map unsupported (`Supported: false`), unknown (`Known: false` or nil `Usage`), missing counter, negative, or int64 overflowing estimates to the route's `RouteBudget`:
  - `UnknownEstimate == "reserve"`: resolve to positive `ConservativeTokens` (> 0);
  - `UnknownEstimate == "reject"`: return a fail-closed pre-admission error / `*GatewayError` preventing execution (`ConservativeTokens == 0`).
- Validate budget configuration and arithmetic fail-closed: `reserve` requires `ConservativeTokens > 0`; `reject` requires `ConservativeTokens == 0` (non-zero tokens forbidden); int64 addition overflows fail closed; zero is never a valid reservation.
- Preserve invocation isolation: estimate queries pass scoped `InvocationServices` and opaque `RawPayload` without mutating client bodies or imposing output caps.
- Verify `internal/connector/responses` honest `EstimateUsage` reporting (`Supported: false` or `Known: false`) integrates cleanly with route budget resolution.
- Explicit limits: does not create SQLite reservations or insert ledger rows (reserved for M3-024); does not dispatch inference executions (reserved for M3-027).

## Acceptance

- [x] Supported, known estimates with non-negative input and output tokens resolve to their checked sum and preserve the Connector's estimate method.
- [x] Unsupported, unknown (`Known: false` or nil usage), missing counter, negative, or overflowing estimates follow `RouteBudget` per normative [M3-CONFIG.md](../M3-CONFIG.md#per-route-estimate-budget):
  - `reserve` requires positive `ConservativeTokens` and resolves to positive reservation tokens;
  - `reject` requires `ConservativeTokens == 0` (forbidden/omitted in config) and returns an explicit pre-admission rejection error without executing inference.
- [x] Non-positive reservations, invalid budget configuration (`reject` with non-zero tokens or `reserve` with `<= 0` tokens), and int64 addition overflows fail closed; zero is never a valid reservation.
- [x] Estimate calls use invocation-scoped services and opaque payload without body mutation, token caps, or credential leakage.
- [x] Context cancellation or Connector error halts estimation without inference execution or zero-budget fallback.
