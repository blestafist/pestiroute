# M6-024 — Wrap the existing native Responses Connector

## Outcome

Wrap the existing production native Responses Connector (`internal/connector/responses`) in an external child-process server implementing the M6 IPC `gen.ConnectorServer` protocol. Reuses the exact native Responses implementation and its invocation-scoped HTTP/credential services without provider branches in Core. Proves byte-for-byte and streaming parity between in-process and external execution of the same native connector on identical fixture scenarios. See [registry](../TASKS.md#m6--external-plugin-runtime) and [milestone](../ROADMAP.md#m6--external-plugin-runtime).

## Scope

- Child server implementation in `internal/connector/external/`:
  - Child connector adapter that wraps any `core.Connector` (specifically `responses.Connector`) into a `gen.ConnectorServer`.
  - Bridges lifecycle calls: `Handshake`, `Descriptor`, `Init`, `Health`, `Capabilities`, `Models`, `EstimateUsage`, `Authenticate`, and `Close` to the underlying connector.
  - Bridges `Execute`: translates incoming execution requests/bodies, constructs `core.InvocationServices` backed by `NewHTTPDoerClient`, `NewCredentialClient`, and host logging client, invokes the underlying connector's `Execute`, and streams `ExecuteFrame` (Head, BodyChunk, Complete) back across IPC with DEC-017 flow control.
  - Flow control & cancellation: uses `ChildFlowControl` for credit reservations, acknowledgements, and prompt cancellation propagation.
  - Server runner/composition helper: handles socket binding (`PESTIROUTE_CONNECTOR_SOCKET`), host dialing (`PESTIROUTE_HOST_SERVICES_SOCKET`), gRPC server setup with 84 KiB frame bounds, and graceful shutdown on signal or Close RPC.
- Comparative fixture tests in `internal/connector/external/`:
  - Run the same native Responses connector in-process and in an external child process against identical upstream HTTP fixtures (fixed JSON, chunked SSE stream).
  - Verify exact byte-for-byte preservation of payload bodies and unknown fields.
  - Verify incremental delivery of partial frames before completion.
  - Verify error mapping and invocation cancellation equivalence.
- Limits:
  - Gateway protected startup / YAML configuration belongs to M6-025.
  - Full client-to-gateway HTTP JSON/SSE integration belongs to M6-026.
  - End-to-end SQLite reservation rollback and attempt accounting belong to M6-027.
  - No changes to `internal/core/` (Core remains provider-agnostic).
