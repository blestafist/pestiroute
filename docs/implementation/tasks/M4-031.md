## Scope

- In `internal/connector/anthropic/execute_test.go`:
  - Verify fail-closed stream rejection for unexpected Anthropic reasoning content:
    - `thinking` and `redacted_thinking` content blocks (both standalone and preceding or intermingled with `tool_use` blocks) reject immediately in `messagesStream.consume`.
    - In-stream reasoning deltas (`thinking_delta`, `signature_delta`) and split deltas on text and tool blocks emit sanitized `response.failed` and complete with `core.OutcomeFailed`.
    - Malformed or unclosed thinking blocks and out-of-order block transitions fail closed without fabricating `response.output_item.added`, `output_text` deltas, or false `response.completed`.
  - Verify usage reporting under reasoning scenarios:
    - Provider-reported `input_tokens`, `output_tokens`, and `cache_read_input_tokens` are normalized accurately, while `reasoning_tokens` remains `nil` (`UsageReport.ReasoningTokens == nil`).
    - No estimated or hidden tokens are converted to exact usage or double-counted in TPM settlement.
- In `cmd/gateway/translation_tool_rounds_test.go` (or `cmd/gateway/`):
  - Verify gateway multi-turn tool-round boundary under reasoning attempts:
    - Client request containing top-level `reasoning` controls derives required `llm.reasoning` in Adapter (`internal/adapter/responses/decode.go:208`) and fails closed at Core candidate eligibility (`internal/core/dispatch.go:210`) with HTTP 400 `unsupported_capability` before candidate dispatch.
    - Client request in a multi-turn tool round attempting to inject reasoning history items (`type: "reasoning"`) or replayed thinking/signature content parts (`type: "thinking"`, `type: "redacted_thinking"`, etc.) is treated as opaque by Core and rejected locally by Connector translation (`internal/connector/anthropic/translate.go:360`) with HTTP 400 `invalid_request` before upstream dispatch.
    - Upstream provider returning unexpected thinking blocks prior to `tool_use` in a multi-round tool turn fails closed in-band with `response.failed` and `core.OutcomeFailed`, never advancing client tool state or replaying fabricated calls.
    - Confirm ordinary single-turn and multi-round tool interactions remain unaffected without regression.
- Explicit limits:
  - Do not implement reasoning stream synthesis, Responses reasoning item creation, or thinking signature replay (declined by M4-029).
  - Do not alter Core routing, contracts, or add provider branching in Core.
  - No live provider network calls (governed by M4-036).
