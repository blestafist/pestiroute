# M6-011 — Implement invocation correlation and isolation

## Outcome

Correlate concurrent IPC invocations and reject stale/cross-call traffic. See [registry](../TASKS.md#m6--external-plugin-runtime) and [binding](../M6-BINDING.md#reverse-services-and-authority).

## Scope

- Runtime-issued invocation identity, process epoch, callback correlation, admission bounds and revocation only.
- Do not implement credential, HTTP, log service semantics or Execute stream framing; separate tasks own those.

## Acceptance

- [ ] Bind all invocation/callback traffic to host-issued invocation ID and current process epoch; child-provided account cannot confer authority.
- [ ] Reject stale epoch, unknown/completed invocation, duplicate call IDs and cross-invocation callbacks.
- [ ] Enforce four concurrent invocation and callback outstanding limits; cancel/revoke without waiting for full data queues; restart never reuses epoch.
