## Scope

- Test the public Connector invocation against controlled HTTP readers: first
  output before upstream finish, slow consumer backpressure, cancellation during
  request/body IO, consumer Close, malformed events, and premature EOF.
- Prove bounded retained data and once-only finalization, unknown/partial usage
  on incomplete paths, and no dispatch/replay after cancellation or commit.
- Keep tests deterministic and independent of provider access. No live capability
  promotion or production composition changes.

## Acceptance

- [ ] Synchronization gates prove incremental output and blocked IO cancellation.
- [ ] Read/memory bounds hold under a stalled reader and over-limit upstream events.
- [ ] Each success/failure has the contract's Head/Body/terminal sequence and
  usage provenance; runtime cleanup/finalization occurs once.
- [ ] Repeated Close/cancel and pre/post-commit errors never dispatch a second request.
