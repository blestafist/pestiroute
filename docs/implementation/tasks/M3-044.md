## Scope

- In `internal/core` (or companion boundary tests):
  - Expand package import and architecture boundary tests (e.g. in `internal/core/dependencies_test.go`):
    - Production Core imports strictly standard-library packages; external dependencies (including `modernc.org/sqlite` and `gopkg.in/yaml.v3`) are forbidden.
    - Production Core has no protocol-specific or provider-name branches (`openai`, `anthropic`, `gemini`, `ollama`) and no universal payload types (`Message`, `Tool`, `Reasoning`).
    - Connector packages (`internal/connector/...`) do not import persistence, database, or secret storage packages (`internal/storage/...`, `internal/crypto/...`, `modernc.org/sqlite`, or `database/sql`), enforcing that Connectors cannot persist secrets.
- In `internal/conformance` and `cmd/gateway`:
  - Run the established M1/M2 native regression suite across both protected M3 runtime composition and explicit legacy/M2 JSON startup:
    - Opaque byte/header preservation and unknown field retention.
    - Incremental SSE chunk streaming, bounded backpressure, and client/caller cancellation.
    - No automatic retry or hidden replay on unconfirmed deliveries or post-commit stream failures.
    - Selected per-target body/header limits and capability declarations (unknown capabilities remain unknown).
- Explicit limits:
  - Pure verification and boundary assertion suite; no changes to Core contracts, stream framing, schema migrations, or public CLI interfaces.
  - Deterministic loopback fake upstream and scripted connectors; no real provider credentials or paid inference.
