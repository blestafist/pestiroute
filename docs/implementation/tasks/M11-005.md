## Scope

- Expose policy administration routes in `internal/admin`:
  - `GET /admin/v1/policies`: query filters `enabled` (optional bool), `limit` (default 50, range 1..500), `offset` (>=0). Returns `PolicyPage`.
  - `POST /admin/v1/policies`: strict JSON body `PolicyWrite` (`{id, models, connectors, rpm, tpm}`). Creates revision 1 with `enabled: true`. Returns 201 `Policy`.
  - `GET /admin/v1/policies/{policy_id}`: query parameter `revision` (optional integer >= 1). Returns 200 `Policy`.
  - `PUT /admin/v1/policies/{policy_id}`: strict JSON body `PolicyUpdate` (`{expected_revision, models?, connectors?, rpm?, tpm?, enabled?}`). Revisioned CAS update: appends incremented immutable revision, preserves omitted fields from current revision, supports disable-only (`enabled: false` allowed; re-enable rejected). Returns 200 `Policy`, or 409 `revision_conflict` on revision mismatch.
- Expose virtual-key administration routes in `internal/admin`:
  - `GET /admin/v1/keys`: query filters `policy_id` (string), `enabled` (optional bool), `revoked` (optional bool), `limit` (default 50, range 1..500), `offset` (>=0). Returns `KeyPage` with redacted `VirtualKey` items.
  - `POST /admin/v1/keys`: strict JSON body `KeyCreate` (`{policy_id, policy_revision}`). Generates cryptographically secure key pair (`prk_*` / `prv_*`), pins policy and policy revision, and returns 201 `IssuedKey` containing the raw `secret` exactly once.
  - `GET /admin/v1/keys/{key_id}`: returns 200 `VirtualKey` (metadata only, no secret or digest; supports lookup by internal ID or public key ID).
  - `DELETE /admin/v1/keys/{key_id}`: idempotent revocation. Returns 200 `VirtualKey` with `revoked: true` and `revoked_at` set.
  - `PUT /admin/v1/keys/{key_id}/policy`: strict JSON body `KeyPolicyUpdate` (`{policy_id, policy_revision, expected_revision}`). CAS update of key policy assignment. Returns 200 `VirtualKey`, or 409 `revision_conflict` on revision mismatch or if key is already revoked.
- Wire handlers in `internal/admin/server.go` when `Config.DB` is present, or return 500 when `Config.DB` is nil.
- Explicit limits:
  - Raw virtual-key secret revealed strictly once upon creation in `POST /admin/v1/keys`; never in GET, list, revoke, or policy reassignment responses, and never stored in plain text.
  - No re-enabling revoked keys or disabled policies.
  - No auth coordinator bridging (reserved for M11-006).
  - No dynamic reload of gateway routing configuration or inference listeners.
