# M6-016 — Bridge authentication results and continuations

## Outcome

Bridge `core.Connector.Authenticate` over external IPC to child connector processes, preserving opaque continuation state, next actions, candidate credentials, optional safe user actions, and optional absolute credential expiry while Core retains CAS/persistence ownership under M3-AUTH and CONTRACT. See [registry](../TASKS.md#m6--external-plugin-runtime), [milestone](../ROADMAP.md#m6--external-plugin-runtime), [binding](../M6-BINDING.md#ownership-topology-versions), and [contract](../CONTRACT.md#connector-contract).

## Scope

- In `internal/ipc/proto/connector.proto`:
  - Add `rpc Authenticate(stream RecordFragment) returns (stream RecordFragment);` to `service Connector`.
  - Regenerate protobuf code via `protoc` in `internal/ipc/gen/`.
- In `internal/connector/external/`:
  - Implement `Authenticate(ctx context.Context, req core.AuthRequest, services core.InvocationServices) (core.AuthResult, *core.GatewayError)` on `*Connector`:
    - Enforce 2 s query timeout bounded by caller context; require initialized and non-closing connector.
    - Validate `AuthRequest`: non-empty `AccountID`, valid `Action` (`start`, `continue`, `refresh`).
    - Stream fragmented `AuthRequest` record to child; read and assemble fragmented `AuthResult` record from child.
    - Preserve `Supported`, opaque `State` bytes (converted to/from string without text coercion), `NextAction`, optional `UserAction` (`*core.AuthUserAction` with URI, code, positive duration), candidate `Credentials` map, and optional `CredentialExpiresAt` (`*time.Time` UTC instant with protobuf timestamp validity).
    - Fail closed on uninitialized/closing connector, invalid action/account, timeout, cancellation, or malformed child output.
- In `internal/connector/external/`:
  - Add unit/race tests with synthetic child fixtures:
    - `start` action returning `NextAction: "continue"`, safe `UserAction`, and opaque continuation `State`.
    - `continue` action returning terminal state (`NextAction: ""`) with candidate `Credentials` and `CredentialExpiresAt`.
    - `refresh` action returning candidate credentials and updated expiry.
    - Unsupported flow (`Supported: false`).
    - Invalid action, missing account, uninitialized or closing connector, operation cancellation, and fragmented records spanning >64 KiB envelopes.
- Limits: Bridge `Authenticate` operation over IPC only. Core retains credential storage, session lifecycle, revision CAS, refresh serialization, and quarantine on failure. No Execute streaming bridging (M6-017/018) or live provider/OAuth calls.
