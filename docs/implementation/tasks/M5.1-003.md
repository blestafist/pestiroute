- [x] Access token, refresh token, trusted account identity and access expiry form one durable acknowledged generation; runtime never parses provider JWTs.

- [x] Bootstrap, disabled accounts, external revision update and persistence failure have explicit outcomes and any semantic gap follows ADR rules.
