  admitted request metadata/capabilities, raw-byte preservation, JSON/SSE framing,
  terminal `[DONE]`, optional usage chunks, error/commit and cancellation behavior.

  Define native Connector scope explicitly; do not reuse a Responses declaration

  Prepare M9-002's exact fixture subset and checks without inventing support.
