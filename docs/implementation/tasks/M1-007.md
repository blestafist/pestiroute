## Scope

- Implement Responses Decode in package `internal/adapter/responses`:
  - Decode `*http.Request` into `core.ExecutionRequest` with protocol `"openai.responses.v1"`.
  - Validate media type: require `application/json` (optional UTF-8 charset); reject unsupported Content-Type or non-identity `Content-Encoding` before execution.
  - Enforce bounded body read up to `max_request_body_bytes`; reject bodies exceeding limit before execution.
  - Require exact model `gpt-4.1-mini-2025-04-14`; reject missing or mismatched model with `CategoryInvalidRequest`.
  - Extract capability requirements: `stream: true` (`llm.streaming`), nonempty `tools` (`llm.tools`), `parallel_tool_calls: true` with tools (`llm.tools.parallel`), recognized `reasoning` (`llm.reasoning`), vision/image inputs (`llm.vision`), audio inputs (`llm.audio`), and `text.format` structured output (`llm.structured_output`).
  - Extract metadata: `Streaming` pointer (`*bool`) reflecting `stream`, safe request headers filtered of hop-by-hop and credentials.
  - Preserve opaque body bytes exactly in `core.RawPayload.Body`: unknown nested fields, whitespace, and formatting must not be mutated or stripped.
  - Return client-safe `*core.GatewayError` for ingress rejections (`CategoryInvalidRequest`, `CategoryUnsupportedFeature`).
- Stop before HTTP routing/dispatch (M1-010), HTTP response encoding (M1-011), upstream calls (M1-008/M1-009), or universal conversation model parsing.

## Acceptance

- [x] Unknown nested fields, whitespace and original model bytes survive exactly in `core.RawPayload.Body`; extracted fields do not rewrite the payload.
- [x] Malformed JSON, missing required model, invalid known fields, unsupported media type, and over-limit input (limit+1) fail before execution with classified `*core.GatewayError`.
- [x] Boundary-sized and chunked/unknown-length requests respect the configured byte cap without reading unbounded streams into memory.
- [x] Safe transport headers are preserved in metadata; hop-by-hop headers and client credentials do not enter the envelope.
- [x] Derived capability set accurately reflects `stream`, `tools`, `parallel_tool_calls`, `reasoning`, vision, audio, and structured output per M1-BINDING.
