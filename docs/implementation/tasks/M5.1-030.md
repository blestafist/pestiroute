- Test two concurrent function calls with distinct item IDs (`fc_item_1`, `fc_item_2`), distinct call IDs (`call_1`, `call_2`), interleaved argument deltas, and distinct completed outputs in real-socket/gateway streaming, followed by a client round returning both function outputs.
