## Scope

- Implement `internal/connector/codex/component.go` with `Connector` satisfying `core.Connector`:
  - Static `Descriptor()` declaring ID `pestiroute.codex.responses`, kind `ComponentConnector`, API versions `[{Major: 1, Minor: 0}]`, protocols `["openai.responses.v1"]`, operations `["execute", "models", "estimate_usage", "authenticate"]`, connector type `"agent-protocol"`, and auth methods `["bearer"]`.
  - Non-secret `componentConfig` with `Model`, `AccountID`, and `Profile` (validating `codex-responses-http-sse-v1`), rejecting empty IDs, invalid profile, unknown JSON fields, or trailing data.
  - `Init`, `Health`, and `Close` lifecycle state machine: starts at `HealthUnknown`, becomes `HealthReady` on successful `Init`, transitions to `HealthUnavailable` on invalid config or `Close`. `Close` is idempotent after successful or failed `Init`.
  - `Capabilities`: reports supported capabilities only for exact configured target (`openai.responses.v1`, configured model, configured account ID, admitted mode); reports unproven capabilities as `Unknown`.
  - Unimplemented methods (`Execute`, `Models`, `EstimateUsage`, `Authenticate`): reject uninitialized, closed, or mismatched scopes with appropriate `core.GatewayError` or unsupported result; no provider network calls or speculative SDKs.
- Implement `internal/connector/codex/component_test.go` with unit test `TestConnectorLifecycleScopeAndSupport` verifying descriptor validity, config parsing and error handling, health transitions, capability isolation, and close idempotency.
- Maintain Core boundary: no concrete connector imports enter `internal/core`.
