## Scope

- Build a deterministic client harness and integration test in `cmd/gateway/translation_tool_rounds_test.go` (or `cmd/gateway/translation_composition_test.go`) executing multi-round client-driven tool interactions against a protected gateway route backed by a fake Anthropic server:
  - Round 1: Client submits initial prompt asking for tool assistance; fake upstream streams a single `tool_use` block; client parses Responses `function_call` event stream and synthesizes output.
  - Round 2: Client submits full history including Round 1's `function_call` and matching `function_call_output`; fake upstream verifies correct `assistant` (`tool_use`) and `user` (`tool_result`) translation and emits two distinct sequential tool calls (`tool_use` index 0 and 1); client receives both `function_call` items with distinct IDs and sequential `output_index`.
  - Round 3: Client submits full history including both prior tool calls and their outputs; fake upstream verifies chronological role-grouped blocks and emits a final text response with `stop_reason: "end_turn"`; client receives complete text response.
- Verify gateway execution constraints:
  - Exactly one upstream HTTP request per client request turn (3 client turns = 3 upstream requests).
  - No gateway conversation storage, session state, or tool execution; history and tool evaluation remain purely client-owned.
  - All stream frames deliver incrementally and complete truthfully with valid `response.completed` snapshots.
- Out of scope:
  - Cumulative usage normalization and cache components (M4-023).
  - Stream interruption and error stop reason translation (M4-024).
  - Gateway retry and fallback boundaries (M4-027).
  - Reasoning blocks (M4-029).
