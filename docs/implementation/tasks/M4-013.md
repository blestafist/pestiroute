## Scope

- Connect `Execute` in `internal/connector/anthropic` to perform plain-text streaming:
  - Translate incoming `core.ExecutionRequest` to Anthropic Messages payload using existing translator (`translate.go`).
  - Resolve credential via `services.ResolveCredential(ctx, scope.AccountID)` and build HTTP request using `BuildMessagesRequest` (`transport.go`).
  - Execute HTTP request via Connector's HTTP client.
  - On HTTP error response (status != 200), classify using `ClassifyHTTPError` (`http_error.go`) and return appropriate `core.GatewayError`.
  - On HTTP 200 response, return `core.ExecutionResponse` with `Head` (`core.ExecutionHead{Protocol: "responses", StatusCode: 200}`), an incremental streaming `Body` channel of `core.StreamFrame`, and lifecycle cleanup.
  - Run background streaming goroutine reading Messages SSE events using `NewMessagesSSEReader` (`sse.go`), driving the Responses SSE lifecycle via `newResponsesEmitter` (`responses_emitter.go`), emitting `core.StreamFrame` chunks into the `Body` channel.
  - Translate `message_start`, `content_block_start`, `content_block_delta` (text), `content_block_stop`, `message_delta` (stop_reason), `message_stop` events into Responses SSE events.
  - Bounded backpressure: handle downstream cancellation / `ctx.Done()`, close upstream HTTP response body on exit, ensure no leaked goroutines or deadlocks.
  - Deliver terminal `Complete` frame and truthful close, without fabricating success on early errors or malformed stream termination.
- Keep scope to plain text. Later tool (M4-017..M4-022), usage refinement (M4-023), failure refinement (M4-024), and reasoning (M4-029..M4-031) belong to their own cards; do not advertise them prematurely.
