## Scope

- In `cmd/gateway` (e.g. `cmd/gateway/stateful_fallback_test.go`):
  - Add end-to-end HTTP and route dispatch tests with fake upstreams exercising both singleton and multi-candidate route configurations with stateful, stateless, and unknown-affinity requests:
    - Singleton routes configured with `RetryMaxAttempts > 1`: stateful requests (`previous_response_id`, string `conversation`, object `conversation`) and unknown-affinity requests terminate after one safe-failing execution without repeating or selecting an alternative.
    - Singleton stateful and unknown-affinity successes: verify exact native request bytes, model, and contract metadata (`AffinityKnown`, `SessionBound`) captured from `ExecutionRequest`.
    - Multi-target stateful and unknown-affinity requests fail closed before candidate-side work; assert zero Connector capability/usage-estimate calls, account authorization calls, accounting Admit/BeginAttempt/dispatch-intent/finalize calls, and Execute calls, while separately asserting one inbound key verification.
    - Untrusted client metadata: forged true/false flags are tested distinctly on stateless-looking and unknown/stateful bodies; adapter-derived classification controls whether fallback is allowed.
    - Multi-target route with stateless request (`previous_response_id: null`, `conversation: null`, `background: false`, `store: true|false|null`): safe first-attempt failure successfully retries and falls back to candidate 2.
- Explicit limits:
  - No implementation of affinity storage, response-ID lookup, session portability, background execution, or cross-target affinity in M3;
  - Core remains protocol-agnostic, inspecting only `Metadata.SessionBound` and `Metadata.AffinityKnown` without JSON, SSE, or tool parsing.

## Acceptance

- [x] A safe first-target failure on a stateful/unknown-affinity request makes zero alternate calls on a singleton route, and multi-candidate configurations fail closed with zero calls before execution.
- [x] Stateless retry across fallback candidates is permitted only when `AffinityKnown: true` and `SessionBound: false` as determined by trusted Protocol Adapter classification; raw client JSON metadata (e.g. forged `"session_bound": false`) is ignored and cannot enable fallback.
- [x] Payload bytes, unknown fields, whitespace, and model remain byte-for-byte identical; stateful requests pass only to their singleton target without any Core protocol parsing or mutation.
