## Scope

- Implement offline state machine in `internal/connector/claudecode`:
  - `start`: generate cryptographically random PKCE verifier, S256 challenge, and unpredictable state parameter; construct authorization URL in `AuthUserAction.VerificationURI` (HTTPS scheme, empty `UserCode`, zero `PollInterval`); pack verifier, expected state, and redirect URI into opaque continuation `AuthResult.State`.
  - `continue`: accept pasted callback URL via `AuthRequest.CallbackInput`; compare raw scheme, authority, and escaped path byte-for-byte (without normalization) against configured redirect URI; strictly decode query requiring exactly one non-empty `code` and `state`; reject duplicate keys, malformed encoding, OAuth error parameters, and unexpected parameters; compare decoded state byte-for-byte with protected expected state; execute code exchange against synthetic token endpoint using exact configured redirect URI; return opaque credential bundle with valid `CredentialExpiresAt`.
  - `refresh`: atomic token refresh using stored refresh token without replaying ambiguous exchanges; return updated bundle with new expiration.
- Injectable fakes and deterministic test harness:
  - Injectable fake HTTP transport (`HTTPDoer` via `InvocationServices.Transport`), fake clock, and controllable randomness/entropy sources in connector constructors/options for deterministic unit/race testing.
- Security and error semantics:
  - Fail closed on any malformed input, redirect mismatch, state mismatch, replay, or provider error without reflecting/logging tokens, verifiers, raw callback inputs, or provider error details.
  - The Core runtime's durable continuation claim is strictly single-use; the Connector keeps no duplicate claim cache, and ambiguous or rejected exchanges are never automatically retried.
  - Zero discovery or provider network access: no external network, no live endpoints, no real credentials, no browser automation.
- Explicit limits:
  - Offline synthetic implementation only in `internal/connector/claudecode`.
  - Capabilities remain `Unknown` (`auth.oauth: Unknown`).
  - Connector remains non-routable / default-gated.
  - Zero live credentials, real logins, or production routes.
