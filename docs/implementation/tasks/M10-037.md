## Outcome

## Scope

- Antigravity stream translation (`internal/connector/antigravity/stream.go`):
  - Translate unsigned candidate parts with `thought: true` and non-empty valid UTF-8 `text` (and absent `thoughtSignature`) into Responses reasoning stream events:
    - `response.output_item.added` (`type: "reasoning"`, `id: "rs_" + s.responseID + "_" + strconv.Itoa(idx)`, `summary: []`, `status: "in_progress"`)
    - `response.reasoning_summary_part.added` (`item_id`, `output_index: idx`, `summary_index: 0`, `part: {type: "summary_text", text: ""}`)
    - `response.reasoning_summary_text.delta` (`item_id`, `output_index: idx`, `summary_index: 0`, `delta: part.text`)
  - Close active reasoning item before starting an ordinary message (`message`) or function call (`function_call`), or at stream finish (`STOP`/done):
    - `response.reasoning_summary_text.done` (`item_id`, `output_index: idx`, `summary_index: 0`, `text: accumulatedText`)
    - `response.reasoning_summary_part.done` (`item_id`, `output_index: idx`, `summary_index: 0`, `part: {type: "summary_text", text: accumulatedText}`)
    - `response.output_item.done` (`output_index: idx`, `item: {id, type: "reasoning", summary: [{type: "summary_text", text: accumulatedText}], status: "completed"}`)
  - Monotonic `outputIndex` sequencing: assign sequential indices per output item based on actual stream order (supporting thought-first as well as thought-after-text).
  - Strictly preserve fail-closed rejection for any part bearing `thoughtSignature` (string, object, or explicit JSON `null`) returning `errUnsupportedReasoning`.
  - Atomic multi-part candidate frame validation: validate all parts in incoming frame before emitting any SSE events; reject mixed invalid parts fail-closed.
  - Streaming guarantees: stream deltas immediately with bounded per-event validation; no complete-response buffering; retain text and summary in `retainedBytes` within the existing shared 1 MiB bound for terminal `response.completed` `output` array.
- Out of scope:
  - Inbound client reasoning history / multi-turn continuation (remains rejected before dispatch).
  - Tool continuity or thought signature verification/replay (remains BLOCKED).
  - Any Core runtime changes (Core remains provider-agnostic opaque transport).
  - Any live network calls or budget deduction.
