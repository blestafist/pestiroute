# M10-034 — Align Antigravity SSE framing with standards and add bounded stream error classification

## Outcome

Align Antigravity connector SSE parsing with W3C/WHATWG SSE standards (ignoring metadata fields, multiline data joined with LF, optional initial UTF-8 BOM, CR/LF/CRLF line endings) and disambiguate generic `precommit_framing` into precise fixed-enum diagnostic error categories, enabling robust ingestion and observable offline diagnostics without raw string/secret leakage. See [TASKS.md](../TASKS.md#m10--google-antigravity-connector) and [ROADMAP.md](../ROADMAP.md#m10--google-antigravity-connector).

## Scope

- Standards-conforming SSE event/line framing (`internal/connector/antigravity/stream.go`):
  - Stream reader: strip optional UTF-8 BOM (`\xEF\xBB\xBF`) only at the very start of the stream; support `\r`, `\n`, and `\r\n` line endings incrementally without complete-stream buffering.
  - Line parser: ignore non-data fields (`event`, `id`, `retry`, unknown field names) and comments (`:...`); accept colonless lines without errors per SSE spec.
  - Multiline data: concatenate multiple `data:` lines in a single event with LF (`\n`).
  - Enforce existing limits (`maxSSELine = 64 * 1024`, `maxEventSize = 1024 * 1024`) incrementally.
- Fine-grained secret-safe stream error classification (`internal/connector/antigravity/stream.go`):
  - Disambiguate generic `precommit_framing` into exact bounded enum categories: `precommit_eof`, `precommit_invalid_json`, `precommit_framing`, `precommit_unsupported_finish`, `precommit_unsupported_reasoning`, `precommit_invalid_usage`, `precommit_invalid_function`, `precommit_empty_content`, `precommit_invalid_content`, `precommit_invalid_order`, `precommit_bounds_exceeded`.
  - Distinguish genuine transport/framing anomalies from semantic candidate rejection errors.
  - Zero raw body strings, URLs, or payload tokens in logs.
  - Keep `scripts/antigravity_smoke_response.py` diagnostic schema synchronized with the bounded enum.
- Fail-closed semantic guards:
  - Preserve rejection of `thought: true` or `thoughtSignature`.
  - Preserve strict functionCall object and finishReason validation.
  - Preserve byte-incremental delivery, cancellation, and exactly-once finalization.
- Limits & boundaries:
  - Zero live provider calls; no request budget deduction. M10-028 remains frozen BLOCKED (budget 17/1000).
  - Preserve M10-028 untracked artifacts untouched; no live execution until review, commit, and promotion.
  - No buffering of entire HTTP response bodies.
  - No new Core API or universal SSE abstractions; changes remain internal to the Antigravity connector.
  - Do not claim that SSE formatting was the live upstream failure cause.
