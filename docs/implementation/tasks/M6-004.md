## Completion Evidence

`internal/conformance/grpc_spike_test.go` launches disposable child test processes on private Unix sockets and uses generated protobuf bidirectional gRPC frames. The child validates the exact synthetic header and opaque Execute body before output. The client hashes all 256 x 64 KiB response frames (16 MiB) while retaining a real pending Body alongside a split reverse HTTP callback; it verifies early Body delivery, NUL/0xff byte parity, callback request/reply parity, reverse credentials and the fixed frame limit. The server waits for client half-close after Complete; the client samples RSS before closing, and a distinct closed completion signal avoids consuming `cmd.Wait` results. gRPC message-size options are `ipcWireFrameMax-5`, accounting for the five-byte message prefix; tests accept exact-boundary frames and reject one-byte overflow in both directions. The test harness sets a 64 KiB HTTP/2 stream window solely to make cancellation backpressure reproducible; this is not a production transport setting. Joint cancellation synchronizes an actually blocked server `Send` and callback `Recv`, then verifies each and the client delivery/callback operation independently returns on context cancellation; the child exits normally without force-kill. Output attempts are capped at 63 Body frames to reserve one of 64 slots for the callback; occupancy includes the blocked pending Body. A boundary test proves the maximum 64 retained frames and exact 4 MiB queued application-body ceiling, rejecting a further frame. The process watchdog is fixed at 10 seconds. Linux metrics/Unix socket behavior are host-specific; no production transport/security claim or selection.

Tooling obtained: Go `go1.27.1-X:nodwarf5`; gRPC-Go v1.75.1; protobuf v1.36.6; protoc 33.0; protoc-gen-go v1.36.6; protoc-gen-go-grpc v1.5.1. Exact generation command is in `internal/conformance/grpc_spike/README.md`. Dependencies were fetched before offline checks; no version of protoc is assumed installed by the repository.

Environment: Go `go1.27.1-X:nodwarf5`, Linux `7.2.8-arch1-1`, x86_64, 11th Gen Intel Core i5-1135G7 (8 logical CPUs), 32,458,596 KiB RAM. Race-enabled child test binaries.
