## Scope

- Implement Messages request translation in `internal/connector/claudecode`:
  - Translate admitted `core.ExecutionRequest` (`openai.responses.v1`, translation mode) to Anthropic Messages JSON request format.
  - Set request target `https://api.anthropic.com/v1/messages?beta=true` and standard candidate headers (`anthropic-version: 2023-06-01`, `anthropic-beta`, `Authorization: Bearer <access token>`, `User-Agent: PestiRoute`).
  - Map system/developer instructions, history order/roles (`user`/`assistant`), content blocks (text and supported images), tool definitions, and tool choice.
  - Reject unsupported semantics losslessly with `unsupported_feature` before dispatch; do not guess Responses-specific state (`previous_response_id`, background execution).
- Implement SSE stream framing and event parsing in `internal/connector/claudecode`:
  - Parse candidate Messages events: `message_start`, `content_block_start`, `content_block_delta`, `content_block_stop`, `message_delta`, and `message_stop`.
  - Enforce UTF-8 validation and bounded buffer framing.
  - Fail attempt on malformed SSE frames, invalid JSON, unexpected event order, unknown events, mid-stream errors, or premature EOF before `message_stop`.
  - Map events to Responses stream frames: `Head` on `message_start`, incremental `Body` frames for content deltas and native `content_block_stop` delimiters, and terminal `Complete` after `message_stop`.
- Implement usage extraction in `internal/connector/claudecode`:
  - Extract input tokens from `message_start.message.usage.input_tokens` and output tokens from `message_delta.usage.output_tokens`.
  - Treat cache read/create counts as non-additive details.
  - Construct final `Complete.UsageReport` with source `provider`; preserve missing values as unknown/nullable; do not invent zero usage.
- Add deterministic unit tests in `internal/connector/claudecode` validating against the M7-008 synthetic fixture suite (`messages-request.json`, `stream-*.sse`, `http-*.json`).
- Explicit limits: Offline synthetic implementation only under DEC-018. Capabilities remain `Unknown`. Connector remains non-routable and uncomposed. Zero live calls, zero real credentials, zero proprietary binaries. Advanced stream backpressure and cancellation concurrency are scoped to M7-012.
