# M10-012 — Rebind Antigravity auth to official SSH UX, public client defaults, pasted-code continuation, and loadCodeAssist discovery

## Outcome

Align the offline Antigravity authentication candidate with official remote-SSH UX (browser login at verification URI, code displayed on `https://antigravity.google/oauth-callback`, pasted code input via stdin) and bounded post-exchange `loadCodeAssist` project discovery without automatic onboarding side effects. This does not establish provider OAuth/discovery compatibility or production readiness. See [Google Antigravity Connector](../M10-ANTIGRAVITY.md) ([Roadmap](../ROADMAP.md#m10--google-antigravity-connector)) and registry row in [TASKS.md](../TASKS.md#m10--google-antigravity-connector).
