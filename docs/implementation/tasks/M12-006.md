## Scope

- Asset embedding package (`internal/ui`):
  - Embed built frontend assets (HTML, JS, CSS) using Go `embed.FS`.
  - Include a checked-in fallback asset/placeholder so `go build` and `go test` succeed on fresh checkout without Node.
  - Implement `Handler() http.Handler` serving static assets under `/admin/` with appropriate MIME types, SPA route fallback returning `index.html`, 404 for missing static subresources (`/admin/assets/*`), and an explicit HTTP 503 unavailable response when only the fallback placeholder is present (never silently presenting missing assets as a working UI).
  - Ensure `/admin/v1` routes and inference endpoints are never swallowed or shadowed.
- Gateway composition root (`cmd/gateway/main.go`):
  - Wire `adminConfig.Static = ui.Handler()` when `c.Admin != nil`.
- Frontend polish (`web/src/App.tsx`):
  - Render an accessible `<Modal>` dialog for newly issued raw virtual keys (`issuedSecret`) in live mode, with focus trapping and Escape key dismissal.
  - Disambiguate duplicate `Policy ID` input labels between Create Policy form and Create Key form (e.g. `Target Policy ID`).
  - Support create-account then write-only credential creation from Connections.
- Browser automation (`web/browser`):
  - Pin Playwright and run a real browser against the packaged `/admin/` entry and local gateway/SQLite fixture.
  - Keep the Playwright/browser install and pinned Node prerequisites scoped to explicit WebUI packaging/testing; the default release build remains Go-only.
- Complete operator E2E test suite:
  - Automated integration test executing against real compiled gateway binary and SQLite database with a deterministic fake upstream:
    1. Authenticate with operator token held strictly in memory.
    2. Confirm gateway readiness and startup topology on Overview/Settings.
    3. Create account and write-only credential on Connections.
    4. Create policy and issue restricted virtual key, capturing the one-time raw secret.
    5. Dispatch inference request to gateway client port using issued virtual key.
    6. Verify request and attempt records appear in the Usage ledger.
    7. Revoke the virtual key.
    8. Confirm subsequent inference using revoked key fails.
    9. Log out, verifying in-memory token and cached views are cleared.
- Documentation and packaging scripts:
  - Document Go-only build and release build procedures in `scripts/release-build.sh` (or helper).
  - Publish `docs/implementation/M12-HANDOFF.md` documenting verified browser/gateway capabilities, reproducible build steps, and limitations.
- Out of scope:
  - Modifying Core routing contracts, SQLite schema, or public inference APIs.
  - Live provider credentials or external network access.
  - Production container/service orchestration (M13).
