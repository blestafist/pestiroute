# M4-015 — Compose protected translated and native routes

## Outcome

Compose protected translated and native routes. One bounded deliverable in the [M4 registry](../TASKS.md#m4--first-translation-connector)
toward the original [M4](../ROADMAP.md#m4--first-translation-connector).

## Read First

- [Inspected seams](../M4-TRANSLATION.md#inspected-implementation-seams).
- [Startup isolation](../M3-CONFIG.md#startup-isolation-and-compatibility).
- cmd/gateway/protected_startup.go, main.go and current registry/scoped-service wiring.

## Scope

- Register `pestiroute.anthropic.messages` only at the composition root (`cmd/gateway/`). Build translation instances and their scoped transport/SQLite credential services under existing protected startup.
- Add explicit non-secret `credential_id` to Anthropic connector settings (alongside `model` and `account_id`) to bind existing SQLite runtime scoped record selection (`(account_id, credential_id)`).
- Synchronize `docs/implementation/M3-CONFIG.md`, strict YAML config validation (`cmd/gateway/yaml_config.go`), and predecessor regression tests without changing public contracts or growing ADRs.
- Reuse policy/admission/accounting/dispatch and lifecycle cleanup; support explicit native and translated routes together without a second request engine.
- Keep one configured account/model scope initially, no implicit account fallback, and no secret values in YAML.

## Acceptance

- [x] Anthropic connector requires non-empty `credential_id` in settings; missing, empty, or whitespace-only `credential_id` fails closed during configuration validation and protected startup.
- [x] Protected client key reaches the selected translated instance with its stored SQLite API key; distinct native and translation credential records remain strictly isolated across accounts and routes.
- [x] Misbound credential records (non-existent record, mismatched account, disabled account, or expired credential) deny requests cleanly without fallback, crash, or secret leakage.
- [x] Native route in the same topology continues to forward opaque bytes using its own credential record.
- [x] Invalid/failed Init, unsupported implementations, and persistence failures withdraw readiness; partial startup resources close once and no secrets enter logs.

unknown. `M3-CONFIG.md` and strict YAML validation/tests are synchronized.

not returned to clients. No real provider call was made.
