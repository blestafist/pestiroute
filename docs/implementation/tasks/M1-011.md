# M1-011 — Native HTTP Encode

## Outcome

The adapter converts transport/control frames into one HTTP response without translating body bytes. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Read First

- M1-005 binding, [adapter](../CONTRACT.md#protocol-adapter-contract), [commit and frames](../CONTRACT.md#execution-response-and-streamframe), [errors](../CONTRACT.md#error-model).

## Scope

- Encode native Head/Body/Complete and client-safe pre-head gateway errors; filter response headers and preserve status/content metadata.
- Stop before mux composition and real SSE flush integration. Writer failures must already close/cancel the consumed stream.

## Acceptance

- [ ] Native bodies are written byte-for-byte without serializing provider errors or control metadata into the body.
- [ ] Final headers commit once; a later failure cannot emit replacement status/JSON or fabricate a provider event.
- [ ] Pre-head errors expose only safe messages; encoder exits and closes its stream on write failure.
