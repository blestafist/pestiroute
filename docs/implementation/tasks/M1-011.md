# M1-011 — Native HTTP Encode

## Outcome

The adapter converts transport/control frames into one HTTP response without translating body bytes. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Read First

- [M1 binding Go handoff](../M1-BINDING.md#go-handoff).
- [Protocol adapter contract](../CONTRACT.md#protocol-adapter-contract), [commit and frames](../CONTRACT.md#execution-response-and-streamframe), [error model](../CONTRACT.md#error-model).
- Existing packages: `internal/core/execution.go`, `internal/adapter/responses/decode.go`.

## Scope

- In `internal/adapter/responses/encode.go`, implement `Encode(w http.ResponseWriter, r *http.Request, resp core.ExecutionResponse, gatewayErr *core.GatewayError) error`.
- Encode pre-head `GatewayError`: map category to HTTP status (`CategoryInvalidRequest`/`CategoryUnsupportedFeature` -> 400, `CategoryUnauthenticated` -> 401, `CategoryPermissionDenied` -> 403, `CategoryRateLimited` -> 429, `CategoryUnavailable` -> 503, `CategoryTimeout` -> 504, `CategoryCancelled`/`CategoryInternal`/default -> 500); write client-safe JSON payload `{"error":{"message":...,"type":...,"code":...}}` and optional `Retry-After`; omit internal/provider diagnostics.
- Encode stream frames: on `Head`, commit HTTP status and safe headers, filtering hop-by-hop/connection headers; on `Body`, write raw data byte-for-byte; on `Complete`, do not write trailing payload or mutate committed response; stop on EOF.
- On writer error or context cancellation during streaming, close `resp.Stream` and return immediately without replacement response.
- Stop before mux composition (`M1-001`) and real SSE flush integration (`M1-013`).

## Acceptance

- [x] Native bodies are written byte-for-byte without serializing provider errors or control metadata into the body.
- [x] Final headers commit once at Head; a later failure cannot emit replacement status/JSON or fabricate a provider event.
- [x] Pre-head gateway errors serialize client-safe JSON with mapped HTTP status, category/code, and omit internal/provider diagnostics.
- [x] Client writer failures or context cancellation close/cancel the consumed stream immediately.
