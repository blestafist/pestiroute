## Scope

- Within `internal/connector/antigravity/`:
  - Implement `Connector` conforming to actual `core.Connector` interface methods (`Descriptor`, `Init`, `Health`, `Capabilities`, `Close`, `Execute`, `Models`, `EstimateUsage`, `Authenticate`).
  - Register descriptor `pestiroute.antigravity.v1internal`, profile `antigravity-v1internal`, protocol `openai.responses.v1`, translation mode only.
  - Implement configuration decoding requiring a non-empty, strictly validated `project` identifier; missing or invalid configuration fails initialization or pre-dispatch validation (`core.HealthUnavailable` / `invalid_request`).
  - Implement injected fake-only transport enforcement restricting network calls to `POST https://antigravity.synthetic.invalid/v1internal/projects/{project}:generateContent?alt=sse`. Reject any other destination, redirect, or non-fake transport before dispatch with `unavailable` / `RetryUnknown`.
  - Implement request validation and candidate translation: accept only `openai.responses.v1` JSON payloads with `stream: true`, non-empty fixture-allowlisted model (`gemini-2.5-pro`, `gemini-2.5-flash`), and non-empty prompt `input`. Reject duplicate keys, unknown fields, false/missing stream, tools, reasoning/thought signatures, and multimodal inputs pre-dispatch with `invalid_request` or `unsupported_feature` (`false / unsafe`). Candidate outer body shape: `project`, `model`, `request.contents[0].parts[0].text`, `requestType`, `userAgent`, `requestId`.
  - Implement credential access: retrieve runtime-scoped `oauth` bundle via `services.Credentials.Get(ctx, "oauth")`, decode single JSON object with non-empty `access_token` and no unknown fields, and format as `Bearer <token>` in `Authorization` header. Missing or invalid credentials return `unauthenticated` (`false / unsafe`).
  - Implement incremental SSE parsing and streaming translation: parse candidate `data:` JSON frames (`response.candidates[].content.parts`) and emit `openai.responses.v1` stream chunks (`Head → Body* → Complete → EOF`). Ensure incremental first chunk delivery before completion, bounded line buffers, terminal marker (`response.done: true`) usage extraction (or nil if missing), and error on premature EOF or malformed JSON frames.
  - Implement HTTP error mapping: map 401/403 to `unauthenticated` (`false / unsafe`), 429 to `rate_limited` (`true / unknown`), 5xx to `unavailable` (`true / unknown`). Bounded error body drain and close all response bodies on all paths.
  - Implement cancellation and replay safety: context cancellation aborts dispatch or terminates active stream promptly without leaking resources. Connector never retries internally; ambiguous post-`Do` errors classified as `unknown / unsafe`.
  - Add execution and unit tests exercising positive streaming, incremental first chunk before completion, cancellation, premature EOF, malformed JSON, 401/403/429/500 mapping, bounded reads, fake transport enforcement, and no retry after commit.
- Limits:
  - Strictly within `internal/connector/antigravity/**`, `docs/implementation/tasks/M10-004.md`, `docs/implementation/TASKS.md`, `docs/implementation/CURRENT.md`.
  - No edits to shared gateway composition (`cmd/pestiroute/...`), Core runtime contracts, or frontend/admin API (deferred to M11 / sequential integration).
  - No live network requests or live provider credentials.
  - No tools, reasoning replay, multi-turn session persistence, or enterprise project discovery.
