## Scope

- Extend `responsesEmitter` (`responses_emitter.go`) and `messagesStream` (`execute.go`) in `internal/connector/anthropic`:
  - Support multiple sequential content blocks for distinct tool calls across sequential block indices (`index: 0`, `index: 1`).
  - Emit distinct `fc_` item IDs and preserved `call_id`s in `response.output_item.added` with incrementing `output_index`.
  - Route argument deltas and item closures (`response.function_call_arguments.delta`, `response.function_call_arguments.done`, `response.output_item.done`) to the matching active `output_index` and `item_id`.
  - Aggregate all completed function items into `response.completed` snapshot in original order upon `message_delta` (`stop_reason: "tool_use"`) and `message_stop`.
  - Maintain the aggregate 1 MiB retained text/arguments budget across all blocks.
- Enforce strict block ordering and reject interleaved, out-of-order, or duplicate block indices and duplicate tool call IDs with truthful stream error.
- Verify interaction with parallel tool controls (`disable_parallel_tool_use` mapped in M4-018): parallel true/false request wire translation executes deterministically and preserves stream frame ordering.
- Out of scope: multi-round client tool execution/history rounds (M4-022), usage normalization/cache details (M4-023), committed stream failure classification (M4-024).
