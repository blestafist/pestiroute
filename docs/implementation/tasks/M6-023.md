# M6-023 — Implement drain and process-tree shutdown

## Outcome

Implement graceful drain and process-tree shutdown for external connector processes: stop admission immediately on shutdown/close, allow active in-flight invocations a finite drain window (up to context/30 s deadline), cancel lingering invocations and revoke callbacks on drain expiry, issue orderly Close RPC, and terminate the entire process group (direct child and any descendant processes) via SIGTERM and SIGKILL (2 s grace each, 5 s hard limit) with direct-child `Wait` exactly once, group disappearance verified, and owned IPC sockets/directories removed. See [registry](../TASKS.md#m6--external-plugin-runtime) and [milestone](../ROADMAP.md#m6--external-plugin-runtime).

## Scope

- Graceful drain and process-tree shutdown in `internal/connector/external/`:
  - **Admission cutoff**: closing/draining state immediately rejects new invocations with `CategoryUnavailable` / `RetryUnknown`.
  - **Finite drain**: active in-flight invocations are permitted to finish within a bounded drain deadline before cancellation.
  - **Drain cancellation**: upon drain deadline expiry or context cancellation, remaining in-flight invocations are cancelled and active callback leases revoked.
  - **Process-tree termination**:
    - Orderly Close RPC sent over gRPC/control lane.
    - If child and descendants do not exit within 2 s, SIGTERM sent to process group (`-PGID`).
    - If process group remains 2 s after SIGTERM, SIGKILL sent to process group (`-PGID`).
    - Direct child reaped via `Wait` exactly once.
    - Total termination/reaping window capped at 5 s; process group verified gone (`ESRCH`).
  - **Resource cleanup**: owned Unix domain sockets and private `0700` socket directory deleted after process exit/reap.
  - **Supervisor integration**: `Supervisor.Close` orchestrates connector drain and process shutdown without leaking watcher goroutines or crashing on repeated/concurrent Close.
- Deterministic unit and race tests in `internal/connector/external/`:
  - New admission rejected immediately once drain/shutdown starts.
  - Admitted in-flight operation completes successfully within finite drain window.
  - Expired drain cancels remaining in-flight invocation and revokes callbacks.
  - Child process spawning descendant processes: orderly exit reaps descendants, or uncooperative descendants are terminated by process-group SIGTERM/SIGKILL.
  - Owned socket file and directory removed after shutdown.
  - Idempotent repeated and concurrent `Close` calls.
- Limits:
  - Wrapping native Responses connector belongs to M6-024.
  - Gateway configuration / startup wiring belongs to M6-025.
  - End-to-end SQLite reservation rollback and attempt accounting belong to M6-027.

## Acceptance

- [x] New invocations are rejected immediately once shutdown/drain begins.
- [x] Active in-flight invocations complete normally if finished within the drain deadline.
- [x] Invocations exceeding the drain deadline are cancelled and their callback leases revoked.
- [x] Orderly Close RPC is sent to the child process.
- [x] Process group (`-PGID`) receives SIGTERM after 2 s and SIGKILL after 4 s if child or descendant processes linger; direct child is reaped with `Wait` exactly once and the group is confirmed gone within 5 s.
- [x] Owned Unix sockets and temp directory are deleted after process termination.
- [x] Concurrent and repeated `Close` calls are safe and idempotent.
