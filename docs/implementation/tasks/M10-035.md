# M10-035 — Disable dynamic thinking for gemini-2.5-flash and preserve fail-closed reasoning guard

## Outcome

Explicitly disable dynamic thinking in the Antigravity request envelope for `gemini-2.5-flash` (`generationConfig.thinkingConfig` with `thinkingBudget: 0` and `includeThoughts: false`), matching pinned 9router reference (`87a74e1`) to prevent upstream thinking parts from aborting the non-thinking Responses stream, while keeping `gemini-2.5-pro` unchanged and preserving fail-closed rejection of upstream thoughts/signatures. See [TASKS.md](../TASKS.md#m10--google-antigravity-connector) and [ROADMAP.md](../ROADMAP.md#m10--google-antigravity-connector).

## Scope

- In `internal/connector/antigravity/execute.go`:
  - When `model == "gemini-2.5-flash"`, add `generationConfig: map[string]any{"thinkingConfig": map[string]any{"thinkingBudget": 0, "includeThoughts": false}}` to the inner `request` object.
  - For `gemini-2.5-pro` (and any other models), leave the `request` envelope unchanged (no `generationConfig` / `thinkingConfig`).
- In `internal/connector/antigravity/stream.go`:
  - Preserve the strict fail-closed guard: reject any part where `thought: true` or `thoughtSignature` is present (including `null` or non-empty raw JSON) with `errUnsupportedReasoning` (mapped to `precommit_unsupported_reasoning`).
  - Do not discard thoughts or signatures silently; do not invent reasoning fields or expand public Responses API.
- Documentation & ADR:
  - Record ADR DEC-027 in `docs/project/DECISIONS.md` for this bounded request default compatibility choice.
  - Synchronize `docs/implementation/M10-BINDING.md` request envelope specification.
- Offline tests in `internal/connector/antigravity/execute_test.go` (and regression validation against `cmd/gateway`):
  - Exact wire check: `gemini-2.5-flash` request body contains `generationConfig.thinkingConfig` with `thinkingBudget: 0` and `includeThoughts: false`.
  - Exact wire check: `gemini-2.5-pro` request body omits `generationConfig`.
  - Rejection checks: upstream responses with `thought: true` or `thoughtSignature` still atomically fail closed with HTTP 503 `precommit_unsupported_reasoning` for both models.
  - Regressions: multipart text streaming, tool calling, multi-turn history, usage token counts, cancellation, and durable budget reservation.
