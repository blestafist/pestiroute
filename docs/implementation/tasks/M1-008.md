# M1-008 — Scoped one-attempt HTTP transport

## Outcome

One Connector invocation can send inference only to the selected target with its selected credential. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Scope

- Implement the native HTTP transport and request constructor in package `internal/connector/responses`:
  - Build `*http.Request` targeting the configured `upstream_endpoint` using `core.ExecutionRequest.Payload.Body`.
  - Attach the selected upstream credential as `Authorization: Bearer <credential>`; drop any incoming client `Authorization`.
  - Filter transport headers: drop hop-by-hop headers (`Connection`, `Keep-Alive`, `Proxy-Authenticate`, `Proxy-Authorization`, `TE`, `Trailers`, `Transfer-Encoding`, `Upgrade`) and any headers nominated in `Connection`; preserve safe headers such as `Idempotency-Key` (unless nominated by `Connection`).
  - Set request `Content-Type: application/json` and `Accept-Encoding: identity`.
  - Configure reusable `*http.Transport` and `*http.Client` with startup timeouts (`ConnectTimeout`, `TLSHandshakeTimeout`, `ResponseHeaderTimeout`).
  - Explicitly disable automatic redirect following (`CheckRedirect` returns `http.ErrUseLastResponse` or halts before following).
  - Explicitly disable automatic response decompression (`DisableCompression: true` on `http.Transport`).
  - Prevent hidden transport inference replay: ensure `http.Transport` cannot silently resend inference bodies on dropped reused connections (ensure `GetBody` is nil and verify non-replayable body semantics).
  - Support context cancellation: aborts in-flight round-trips and releases underlying connections.
- Stop before parsing/emitting response frames or stream classification (M1-009 / M1-012) and before Core dispatch or full gateway wiring (M1-010 / M1-001). No SDK, retry engine, or multi-account fallback.

## Acceptance

- [x] Captured request method is `POST`, target URL matches the configured endpoint, and body bytes match `core.ExecutionRequest.Payload.Body` exactly; client `Authorization` is stripped and only the configured upstream credential is sent.
- [x] Hop-by-hop headers and fields nominated by `Connection` are removed; safe headers (e.g. `Idempotency-Key`) pass through unless nominated by `Connection`.
- [x] Upstream 3xx redirects are not followed; redirect destinations receive zero requests and credentials are not leaked.
- [x] Connection failure on a reused connection does not silently resend or replay the inference body, including when `Idempotency-Key` is present.
- [x] Upstream response bytes are not automatically decompressed (`DisableCompression: true`), preserving raw response payload bytes.
- [x] Context cancellation stops transport work promptly and releases network resources without leaks.
