# M1-006 — Single-target startup configuration

## Outcome

Validated startup inputs for one native target, with runtime-owned credentials. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Read First

- [M1-BINDING.md](../M1-BINDING.md#startup-and-eligibility), `cmd/gateway/main.go` and `cmd/gateway/main_test.go`.
- [Scoped services](../CONTRACT.md#usage-and-scoped-runtime-services), [HTTP constraints](../STACK.md#http-and-streaming).

## Scope

- Extend strict JSON configuration in `cmd/gateway` with the M1-BINDING fields: `upstream_endpoint`, `upstream_credential_env`, `max_request_body_bytes`, `max_request_header_bytes`, `connect_timeout`, `tls_handshake_timeout`, `response_header_timeout`, and `stream_idle_timeout`.
- Validate inference configuration: absolute HTTPS URL ending in `/v1/responses` without userinfo/query/fragment (loopback HTTP permitted only for local tests), non-empty credential environment variable resolved into runtime-owned state, positive bounds and positive Go durations; require all inference fields when any is supplied (reject partial M1 configuration).
- Enforce inference listener security rule: unauthenticated inference is permitted only on numeric loopback binds (`127.0.0.1` or `::1`); reject wildcard, hostname, or non-loopback binds when inference is configured.
- Preserve backward-compatible probe-only startup when all inference fields are omitted (keeping existing `listen` and `shutdown_timeout` defaults).
- Ensure credential secret values never appear in errors, logs, printed configuration, or diagnostics; client input cannot choose or override the credential source.
- Stop before endpoint routing/dispatch, Core wiring, Connector transport, virtual keys, YAML migration, or persistent secret storage.

## Acceptance

- [x] Valid full inference configuration parses, validates endpoint/env/bounds/durations, and resolves the upstream credential from the environment into runtime state.
- [x] Invalid endpoint URL (non-HTTPS without loopback, missing `/v1/responses`, query/fragment/userinfo), missing/empty credential env var, non-positive bounds, or non-positive durations fail with clear diagnostics before serving inference.
- [x] Partial inference configuration (some but not all M1 fields supplied) is rejected.
- [x] Non-loopback or wildcard `listen` address is rejected when inference is configured; probe-only mode retains existing bind behavior when inference fields are omitted.
- [x] Secret values never appear in errors, printed configuration, or diagnostics.
- [x] Existing flag precedence, probe startup, and lifecycle tests in `cmd/gateway/main_test.go` remain valid and pass.
