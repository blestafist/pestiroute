  - Architectural guarantees: early delivery of first `Body` frame before upstream completion, context cancellation propagation before and during IO, stream teardown on partial close, bounded memory under slow consumers, strict rejection of malformed SSE frames, EOF handling, and prohibition of post-commit retry.
  - Token accounting: contract-correct source and completeness usage extraction into `Complete.UsageReport` without subset double-counting; `usage.exact` remains `Unknown`.
