## Scope

- Create `docs/implementation/M7-BINDING.md` specifying:
  - Component descriptor and profile configuration (`claude-code-messages-v1` parsed strictly from component configuration, not a Descriptor field) under existing CONTRACT v1.
  - Conservative capability policy: all capabilities (`llm.streaming`, `llm.tools`, `llm.reasoning`, `auth.oauth`, `usage.exact`, etc.) remain `Unknown`; connector is non-routable by default until live evidence is verified. Synthetic fixture success does not constitute provider proof.
  - Upstream transport URL (`https://api.anthropic.com/v1/messages?beta=true`) and request headers (`anthropic-version`, `anthropic-beta`, `Authorization: Bearer`, honest `User-Agent: PestiRoute`).
  - Responses (`openai.responses.v1`) to Claude Messages request body mapping; preservation of system instructions, messages history, and tool declarations.
  - Messages SSE stream event mapping (`message_start`, `content_block_start`, `content_block_delta`, `message_delta`, `message_stop`) to `Head`, `Body`, and `Complete` frames.
  - Architectural guarantees: early delivery of first `Body` frame before upstream completion, context cancellation propagation before and during IO, stream teardown on partial close, bounded memory under slow consumers, strict rejection of malformed SSE frames, EOF handling, and prohibition of post-commit retry.
  - Token accounting: contract-correct source and completeness usage extraction into `Complete.UsageReport` without subset double-counting; `usage.exact` remains `Unknown`.
  - OAuth PKCE authorization and token refresh lifecycle conforming to DEC-009 (`AuthUserAction`) and DEC-010 (`CredentialExpiresAt`).
- Explicit limits: Specification documentation only; zero runtime code changes, zero Core modifications, zero live network calls.
