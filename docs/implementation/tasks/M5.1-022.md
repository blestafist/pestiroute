## Scope

- Implement Connector-private HTTP execution in `internal/connector/codex` (`execute.go`, `transport.go`, and wire into `Connector.Execute` in `component.go`).
- Endpoint target: `https://chatgpt.com/backend-api/codex/responses` (with connector/test injection seam, e.g. unexported endpoint field or `services.Transport`).
- Use predecessor helpers: `validateResponsesProfile` (M5.1-019), `adaptRequest` (M5.1-020), and `buildRequestHeaders` (M5.1-021).
- Enforce non-replayable HTTP POST: `GetBody = nil`, `ContentLength = len(body)`.
- Configure upstream transport settings:
  - Disable redirect following (`http.ErrUseLastResponse`).
  - Disable compression (`DisableCompression: true`).
  - Disable HTTP/2 auto-retry (`ForceAttemptHTTP2: false`, empty `TLSNextProto`).
  - Phase timeouts: connect (2 s), TLS handshake (2 s), response header (30 s), stream idle (120 s).
- Deliver streaming response:
  - Return `core.ExecutionResponse` with `Head` and incremental `Body` frames chunked to at most 4 KiB without whole-response buffering under bounded backpressure.
  - Context cancellation, client disconnect, reader `Close()`, and transport errors promptly close the upstream HTTP response body and release resources.
- Conservative provisional completion:
  - Full SSE frame parsing and terminal classification (`response.completed`, `response.failed`, usage extraction) belong to subsequent cards M5.1-023 and M5.1-024; do not emit synthetic terminal events or claim successful completion without terminal SSE verification.
  - Fail closed on missing/invalid credentials, request validation failure, or HTTP dispatch failure.

- [x] Native and translation mode requests deliver raw Responses SSE stream bytes; no complete-response reconstruction or tool runner appears.
