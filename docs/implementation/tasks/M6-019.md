## Scope

- Connector Execute and response stream cancellation/deadlines in `internal/connector/external/execute_linux.go`:
  - Pre-Head cancellation: caller context cancellation before child emits `HeadFrame` returns mapped `execute_cancelled` error, revokes invocation, closes stream, and releases acquisition gate.
  - Pre-Head deadline: caller context deadline expiration before child emits `HeadFrame` returns mapped `connector_timeout` error, revokes invocation, and releases acquisition gate.
  - Post-Head cancellation: caller context cancellation during incremental `Next()` returns context error, revokes invocation and reverse callback authority, closes stream, and releases gate.
  - Post-Head deadline: caller context timeout during `Next()` returns `context.DeadlineExceeded` and closes stream.
  - Idempotent `Close()`: repeated `Close()` calls or concurrent `Close()` and `Next()` are safe, non-blocking, and release resources exactly once.
  - Subsequent `Next()` after `Close()` returns `io.EOF`.
- Callback unblock and revocation under invocation cancellation:
  - Stalled reverse callbacks (e.g. HTTP Do or credential lookup) held by child during an Execute invocation are promptly cancelled when the parent Execute context is cancelled or times out.
  - Revocation ensures any late callback frames arriving after cancellation fail closed.
- Test harness and deterministic test suite in `internal/connector/external/`:
  - Update `handshake_linux_test.go` with gated fixtures for pre-Head cancel/deadline, post-Head cancel/deadline, stalled callback release, and concurrent Close.
  - Update `execute_linux_test.go` with deterministic unit/race tests asserting bounded cancellation latency (<= 2 s), exact error classifications, callback release, and idempotent closure.
- Limits: Process-wide slow-reader backpressure and saturation queue limits are M6-020. Child crash isolation, unexpected EOF, and fault classification are M6-021. Supervisor restart and backoff are M6-022.
