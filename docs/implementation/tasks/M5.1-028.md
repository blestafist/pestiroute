## Scope

- Add `cmd/gateway/codex_streaming_test.go` verifying protected real-socket streaming through the composition root using a local loopback HTTP/TLS server and barrier synchronization.
- Verify that initial SSE delta bytes reach the client over a real TCP socket while upstream completion is gated behind a synchronization barrier.
- Verify terminal delivery across all four contract outcomes: `response.completed` (succeeded), `response.incomplete` (incomplete), `response.failed` / `error` (failed), and mid-stream EOF without terminal event (incomplete).
- Verify verbatim SSE byte forwarding, no whole-response buffering, and exactly-once SQLite ledger attempt/request settlement and token accounting.
- Modify production code only if a concrete defect is uncovered during integration; preserve existing Core/Connector boundaries.
- Explicit limits: Multi-round client tools belong to M5.1-029/030; encrypted reasoning replay belongs to M5.1-031; authorization isolation belongs to M5.1-032; backpressure/stalled reader cancellation belongs to M5.1-033; retry/replay affinity belongs to M5.1-034; durable recovery belongs to M5.1-035.
