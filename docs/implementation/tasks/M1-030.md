- In `cmd/gateway/main.go`, declare `llm.reasoning: core.Supported` in `dispatchCapabilities` for verified target (`https://api.openai.com/v1/responses`) and loopback HTTP fixtures; unverified targets return empty/unknown.

- Keep `llm.tools.parallel` undeclared (`unknown`) and verify fail-closed rejection before upstream egress.
- Limits: No ADR needed (CONTRACT already defines `llm.reasoning` vocabulary; no semantic contract change); no core reasoning parsing; no live provider calls.
