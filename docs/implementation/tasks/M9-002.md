## Scope

- Add the reviewed Chat adapter and protocol-compatible native Connector package
  with lifecycle/descriptor, envelope extraction, request limits and scoped HTTP.
- Preserve original JSON and SSE bytes, including unknown fields and tool IDs.
  Parse only metadata needed for eligibility, terminal validation, and usage.
- Cover text JSON/SSE, terminal/usage chunks, pre-head upstream failures,
  malformed streams, early delivery, cancellation, and bounded buffering.
- No gateway route registration yet, shared Core protocol branch, provider OAuth,
  model rewriting, schema changes, or Chat-to-Responses translation.

## Acceptance

- [ ] The native fake backend receives original body bytes and explicit model/protocol scope.
- [ ] Clients receive original JSON/SSE bytes incrementally, including valid terminal markers.
- [ ] Invalid lifecycle/protocol/input/bounds fail before dispatch; disconnect
  closes upstream IO; incomplete streams cannot claim successful completion.
- [ ] Missing usage is nullable; reported totals/details follow the binding.
- [ ] Component declarations and tests admit only the reviewed feature subset.
