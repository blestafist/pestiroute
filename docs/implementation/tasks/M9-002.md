[registry](../TASKS.md#m9--chat-completions-client-compatibility) and

## Scope

- Create `internal/adapter/chatcompletions`:
  - `core.ProtocolAdapter` implementation with descriptor ID
    `pestiroute.chat-completions.native` and protocol `openai.chat-completions.v1`.
  - JSON decode enforcing limits (`max_body_bytes`, `max_header_bytes`), single
    `application/json` Content-Type, identity encoding, duplicate key rejection,
    and the admitted schema subset in `M9-BINDING.md`.
  - Request capability derivation (`llm.streaming`, `llm.tools`,
    `llm.tools.parallel`, `llm.reasoning`, `llm.structured_output`, `llm.vision`,
    `llm.audio`) and rejection of unsupported features (`file`,
    `web_search_options`). Nullable fields (`stream`, `stream_options`,
    `reasoning_effort`, `audio`, `modalities`) treated per binding.
  - Preservation of original request body bytes verbatim, including unknown fields,
    whitespace, and tool IDs.
  - Response encoding: JSON status/header forwarding and SSE incremental
    event delivery (`text/event-stream`, blank-line delimiters) under backpressure.
- Create `internal/connector/chatcompletions`:
  - `core.Connector` implementation with descriptor ID
    `pestiroute.chat-completions.native`, protocol `openai.chat-completions.v1`,
    type `api`, auth `bearer`.
  - Native HTTP POST dispatch of unchanged payload bytes to configured endpoint
    path (`/v1/chat/completions`).
  - Response parsing: JSON body forwarding with usage extraction (`prompt_tokens`,
    `completion_tokens`, `cached_tokens`, `reasoning_tokens`) to contract
    `UsageReport`. Total and unsupported detail counters ignored; missing usage
    reports unknown.
  - SSE parsing: raw event bytes preserved, `[DONE]` terminal marker forwarded,
    optional usage-only chunk (`choices: []`) mapped to final token accounting.
  - Failure/lifecycle handling: pre-head upstream errors classified with safe
    retry metadata; post-commit failures terminate transport without fabricated
    terminal markers or success status; client disconnect cancels upstream IO.
- Add deterministic slice integration tests in `internal/conformance` or package
  test suites covering client-to-fake-backend JSON and SSE delivery.
- Boundaries: No gateway route composition (`cmd/gateway/**` is deferred to M9-003),
  no YAML config schema or SQLite migrations, no real provider credentials or
  network calls, and no Chat-to-Responses or Responses-to-Chat translation.

## Acceptance

- [x] Adapter and Connector descriptors declare ID `pestiroute.chat-completions.native`
  and singleton protocol `openai.chat-completions.v1`.
- [x] Fake backend receives original raw request body bytes unchanged (including
  unknown nested fields, ordering, and whitespace) with exact protocol/model scope.
- [x] JSON response passes upstream body bytes unchanged and extracts valid usage
  counters per binding; missing usage is left unknown.
- [x] Gated SSE delivers events incrementally to client before subsequent events are
  emitted; preserves raw event bytes and terminal `[DONE]`.
- [x] Tool deltas across chunks (indexes, IDs, name/argument fragments) and multi-round
  tool messages pass opaque and unchanged; capability requirements match binding.
- [x] Usage-only SSE chunk (`choices: []`) preceding `[DONE]` is forwarded as raw SSE
  bytes and yields exact contract token usage; stream missing chunk leaves usage unknown.
- [x] Malformed JSON/event, unterminated event, missing `[DONE]`, upstream HTTP error
  before commit, and post-commit stream failure produce failure/incomplete outcomes
  without fabricated terminal markers, success status, or post-commit retries.
- [x] Ingress limits and validation reject non-object body, non-string/empty model,
  empty/invalid messages, unsupported features (e.g. `file`, `web_search_options`),
  duplicate keys, or missing required capabilities.
- [x] Client disconnect cancels fake-upstream request context and closes upstream IO.
