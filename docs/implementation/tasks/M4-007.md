## Scope

- Implement plain-text history translation from Responses request body to Anthropic Messages structures in `internal/connector/anthropic/translate.go` (and `translate_test.go`).
- Define Connector-local types for Anthropic Messages request mapping (system text blocks, user/assistant messages, text content blocks) without shared `Message` abstractions across packages.
- Map instructions and input history to Anthropic `system` and `messages`:
  - Plain string input maps to a single `user` message with text content.
  - Array of typed `message` items accepts `role` in `{"user", "assistant", "developer"}`.
  - Contiguous leading `developer` prefix before any user/assistant turn maps in order with optional top-level `instructions` to ordered Anthropic `system` text blocks.
  - Require at least one `user` or `assistant` turn after any developer prefix; reject developer-only input (`request-developer-only.json`) because Anthropic requires non-empty `messages`.
  - Reject `developer` role appearing after any `user` or `assistant` turn (`request-late-developer.json`); do not hoist or reorder messages.
  - Reject `system` role in history array (`request-system-history.json`); system instructions are only representable via top-level `instructions` or leading developer prefix.
  - User content: non-empty string or one or more `{type: "input_text", text: ...}` parts.
  - Assistant content: one or more `{type: "output_text", text: ...}` parts; tolerate optional `status: "completed"`, empty `annotations: []`, and empty `logprobs: []`. Reject non-empty annotations/logprobs or invalid status.
- Keep admitted execution request bytes strictly immutable (verify no in-place mutation of request body).
- Preserve exact turn order, content part order, and Unicode characters without loss or corruption.
- Reject unrepresentable chronology, malformed shapes, non-text parts, tool/reasoning elements, and unlisted roles before network dispatch with client-safe `*core.GatewayError`.
- Out of scope: generation controls and top-level field allowlist (M4-008), usage budgeting (M4-009), HTTP status classification (M4-010), SSE streaming execution (M4-013), and tools (M4-017).
