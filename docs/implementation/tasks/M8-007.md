# M8-007 — Support configurable protected credential_id in Claude Code connector settings

## Outcome

Allow protected gateway configuration of `pestiroute.claudecode.messages` to specify a non-default SQLite `credential_id` in connector settings (e.g. `settings: {model: ..., account_id: ..., credential_id: ...}`), defaulting to `"oauth"` when omitted/empty, and mapping it to the runtime credential reference projection. This aligns Claude Code with existing settings contracts in [M3-CONFIG](../M3-CONFIG.md#settings) and `nativeSettings` without adding speculative quota features or modifying production YAML validation. See [registry](../TASKS.md#m8--claude-code-execution-and-gateway-integration) and [milestone plan](../M8-CLAUDE-INTEGRATION.md#delivery-sequence).

## Scope

- In `cmd/gateway/protected_startup.go`:
  - In `prepareProtectedConfig` for `case "pestiroute.claudecode.messages"`:
    - If `s.CredentialID` contains non-whitespace characters, set `component.CredentialEnv = strings.TrimSpace(s.CredentialID)`.
    - If `s.CredentialID == ""`, default `component.CredentialEnv = "oauth"` (preserving M8-006 compatibility).
    - If `s.CredentialID` is non-empty but whitespace-only, return a clear startup validation error (e.g. `connector %q: Claude Code credential_id cannot be whitespace`).
- In `cmd/gateway/claudecode_composition_test.go`:
  - Add test proving configurable `credential_id`:
    - Configure connector settings with `CredentialID: "custom-claude-credential"` mapped to a sealed SQLite credential record with ID `"custom-claude-credential"`.
    - Verify protected admission, streaming execution, and accounting using the custom credential ID.
    - Verify whitespace-only `CredentialID: "  "` is rejected at protected startup.
    - Verify omitted/empty `CredentialID` continues to resolve the `"oauth"` credential record.
