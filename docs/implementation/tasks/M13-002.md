# M13-002 — Package reproducible single-node startup

## Outcome

Package reproducible single-node startup for [M13 — Deployment and Recovery](../M13-OPERATIONS.md) and [Roadmap Stage 13](../ROADMAP.md#m13--deployment-and-recovery). Delivers reproducible Linux/amd64 build script, unprivileged container recipe, and systemd service unit with explicit config/state/key paths and graceful shutdown. Registered in [TASKS](../TASKS.md#m13--deployment-and-recovery).

## Scope

- Create standalone reproducible build script `scripts/release-build.sh` generating an unprivileged static Linux/amd64 binary (`CGO_ENABLED=0`, `-trimpath`) from a clean checkout.
- Create multi-stage container recipe `Dockerfile` (or `deploy/Dockerfile`) building from source and running as an unprivileged user (`nonroot:nonroot` or UID 10001:10001), including system CA certificates, explicit volume mount points for configuration (`/etc/pestiroute`) and state (`/var/lib/pestiroute`), without bundled credentials, master keys, or databases in the image or build context.
- Create systemd service unit example `deploy/systemd/pestiroute.service` configuring unprivileged `User=`/`Group=`, restricted filesystem directives (`ProtectSystem=strict`, `ProtectHome=yes`, `UMask=0077`), `ExecStart` running protected YAML (`-config-format yaml -config /etc/pestiroute/gateway.yaml`), `KillMode=control-group`, and explicit `TimeoutStopSec=30`.
- Provide illustrative protected YAML configuration `deploy/config/gateway.yaml.example` and deployment guide `deploy/README.md` defining filesystem permissions (`0700` state directory, `0600` DB/key files).
- Provide automated verification script `scripts/verify-packaging.sh` validating static build, non-root execution, `/readyz`, fake upstream request, SIGTERM clean exit, and lock release.
- Limits: Single-node Linux/amd64 only; no Kubernetes, Helm charts, Docker Compose orchestration, remote databases, or background service agents. No changes to core contracts, schema, or CLI flags (`-config`, `-config-format`, `-listen`, `-shutdown-timeout` remain unchanged). No changes to M11/M12 owned directories.
