# FND-002 — Runnable startup slice

## Outcome

A runnable `cmd/gateway` binary with a documented startup command, minimal configuration subset, health and readiness endpoints, explicit startup failure reporting, and bounded graceful shutdown, completing the lifecycle core for the [M0 foundation](../ROADMAP.md#m0--project-foundation). ## Scope

- Implement a minimal startup configuration loader (e.g. listener address, shutdown timeout) from a configuration file and/or CLI flags.
- Implement HTTP server startup using `net/http` and `http.ServeMux` exposing:
  - `GET /healthz` (liveness: 200 OK once process is live).
  - `GET /readyz` (readiness: 200 OK once configuration is loaded and listener is serving; not a check of upstream provider availability).
- Implement clear failure handling: exit non-zero with descriptive stderr output on invalid configuration (e.g. malformed file, invalid listen address, unreadable path).
- Implement bounded graceful shutdown on SIGINT and SIGTERM via `context.Context` (bounded wait for inflight connections to close).
- Provide unit and integration tests covering configuration loading, health/readiness endpoints, startup failures, and graceful shutdown.
- Update `cmd/gateway/main.go` and root `README.md` with verified startup and lifecycle commands.
- Limits: no fake upstream (FND-003), no CI setup (FND-004), no M3 storage/database/accounts/keys, and no proxy/routing execution (M1).
