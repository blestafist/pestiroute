## Scope

- Offline preflight: Install pinned genuine official CLI (`@openai/codex@0.162.1`) into isolated local directory `/tmp/opencode/official-codex-cli` without modifying global node modules or repo root. Verify runnable binary provenance and version (`codex --version` -> `0.162.1`).
- Safe login entry: `scripts/m5.1-official-auth.py` supervises the genuine CLI `login --device-auth` in a private helper process with bounded in-memory stdout/stderr capture, strict public URL/code filtering, status polling, cancellation, fixed v3 private paths `/tmp/opencode/official-codex-auth-v3` and `/tmp/opencode/official-codex-session-v3`, and one-attempt locking. No path selector is exposed; the v1/v2 attempt paths are never reused or reset. It must not emit raw output or persist logs.
- Independent fresh device login: only after independent review and explicit operator approval, run the helper and present only its allowlisted verification URL and short device code through the `question` tool.
- Paired comparison: Compare fresh official CLI auth against existing verified gateway device auth evidence (M5.1-040) on the same account. Proves separate credential stores, distinct rotating refresh tokens, no overwriting of gateway credentials (`/tmp/opencode/pestiroute-auth.pQ8lCE/gateway.db`), and no forced logout or revocation. A new contemporaneous gateway login is not required; comparison uses M5.1-040 baseline.
- Local comparison must open the saved database read-only, compare the credential envelope/revision before and after in memory, and emit only fixed CLI/gateway provenance plus boolean results. Never persist identifiers, ciphertext digests, tokens, raw CLI metadata, or the private account selector.
- Zero token copying between gateway and CLI; zero forced logout/revocation; zero parallel refreshes.
- Validate the official CLI-versus-M5.1-040 comparison with `scripts/smoke-m5.1-artifacts.py --official-auth <artifact>`. The existing `--auth` mode remains for gateway device-auth artifacts; it is not the CLI-comparison schema.
