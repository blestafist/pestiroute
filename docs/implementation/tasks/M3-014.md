# M3-014 — Add the local administration command boundary

## Outcome

Add the local administration command boundary to the gateway binary (`cmd/gateway`), providing subcommand dispatch (`gateway admin ...`), stream-injected CLI execution environment (`stdin`, `stdout`, `stderr`), master-key validation, SQLite store lifecycle, fail-closed migration version checking, and bounded secret stream input without starting a network listener. This is one bounded deliverable in the [M3 registry](../TASKS.md#m3--access-accounts-and-accounting) toward [M3](../ROADMAP.md#m3--access-accounts-and-accounting).

## Scope

- Implement the local administration command boundary in `cmd/gateway` (e.g. `admin.go` or `internal/cmd/admin` dispatched from `main.go`):
  - Subcommand dispatch for administrative operations: `gateway admin [flags] <subcommand> [args]`.
  - Injected execution environment (`stdin io.Reader`, `stdout io.Writer`, `stderr io.Writer`, `args []string`, `ctx context.Context`) for deterministic in-process testing.
  - Global admin flags for database path (`--db`) and master-key file path (`--master-key`).
  - Store and crypto lifecycle:
    - Master key loading via `crypto.LoadMasterKey`: enforces regular file, strict mode `0600`, process owner EUID, 32 bytes, rejecting symlinks and FIFOs non-blockingly.
    - Database connection management via `sqlite.Open`: applies WAL mode, `synchronous=FULL`, foreign keys, and 500 ms busy timeout; ensures `Close()` is called on all exit paths.
    - Migration authority and version checks: verifies current schema version against supported code migrations; fails closed on unsupported future schemas. Supports explicit migration runner (`gateway admin migrate`) applying ordered migrations via `sqlite.Migrate`.
  - Stream-based secret input seam:
    - Helper reading secret values from injected `stdin` rather than process arguments (`argv`) or environment overrides.
    - Bounded read size (max 64 KiB), single trailing newline trimming, memory zeroing, and complete redaction in error messages, logs, `stdout`, and `stderr`.
  - Exit status conventions: 0 on success; non-zero (1 or 2) on syntax error, unknown subcommand, missing/invalid key or database, future schema, or execution error.
  - Help and usage output (`gateway admin --help`, `gateway admin <subcommand> --help`) that runs cleanly without opening database or starting any network listener.
- Explicit limits:
  - Account and credential subcommands belong to [M3-015](M3-015.md).
  - Virtual-key and policy subcommands belong to [M3-016](M3-016.md).
  - Usage inspection subcommands belong to [M3-031](M3-031.md).
  - OAuth login/refresh commands belong to [M3-036](M3-036.md) / M5.1.
  - No admin HTTP API, web UI, or remote network listener is introduced.
  - Core runtime (`internal/core`) remains untouched and standard-library only.

## Acceptance

- [x] Help and invalid commands (`gateway admin --help`, unknown subcommand, missing flags) print usage or clean error to stdout/stderr and exit with appropriate status code without starting an HTTP/TCP listener or opening storage/key files.
- [x] Admin commands requiring storage validate the master key via `crypto.LoadMasterKey` and fail closed with a classified error and non-zero exit on missing, symlink, permissive mode (`0644`), or wrong-length key files.
- [x] Admin commands open SQLite via `sqlite.Open` with WAL, `synchronous=FULL`, foreign keys, and 500 ms busy timeout; fail closed on unsupported future schema versions; and close all connection handles on exit.
- [x] Migration command (`gateway admin migrate`) executes ordered migrations via `sqlite.Migrate` to initialize or upgrade the database to the current supported version.
- [x] Secret input helper reads bounded secret bytes (max 64 KiB) from injected stdin; secret values are never accepted from process arguments (`argv`), and neither secret bytes nor master-key bytes appear in stdout, stderr, or error strings.
- [x] Concurrent CLI invocations against an active file-backed database serialize under SQLite's writer lock bounded by the 500 ms busy timeout without deadlock or unbounded retries.
