# M10-038 — Handle unsigned empty Gemini text parts as no-ops and add fixed invalid-content debug subkinds

**Status:** ACTIVE — GPT-6 Luna (M10-038 worker)

## Outcome

Accept unsigned empty text parts in candidate Antigravity SSE streaming frames as no-ops without emitting spurious delta or item events, while preserving usage extraction, stream finalization, and fail-closed handling for thought signatures and mixed function calls. Emit fixed debug-only subkind enums (`done_with_candidates`, `text_with_function_call`, `invalid_utf8_text`) for `precommit_invalid_content` diagnostics without changing wire categories. Resolves offline false-positive rejection of valid provider empty text parts. See [TASKS.md](../TASKS.md#m10--google-antigravity-connector) and [ROADMAP.md](../ROADMAP.md#m10--google-antigravity-connector).
