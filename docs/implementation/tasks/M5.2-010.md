## Scope

- In `internal/connector/responses`:
  - Add versioned synthetic request, JSON response, and SSE stream wire fixtures for each of the three pinned runtimes:
    - Ollama v0.40.3 (source commit `eab97e9f92b9a25c2d52d2cc6c1b1c99bd9fae21`):
      - Valid text requests (string and item array), function declaration and call output resubmission, accepted-but-ignored `include`, unsupported fields (`conversation` decoded but unused, `previous_response_id` lacks handling), and invalid item type.
      - Wire/SSE responses: valid text JSON and the pinned serializer's complete ordered text lifecycle (created/in-progress, item/content added, `response.output_text.delta`, text/content/item done, completed with usage); include `response.failed` only for the source-evidenced web-search failure path.
    - vLLM v0.31.0 (source commit `db9527a46873454610df6dbedf79a36d6bf1a7f6`):
      - Valid text requests (string and item list), client-resubmitted history, accepted-but-ignored `prompt_cache_key`, unsupported `store:true` / `background` without storage.
      - Wire/SSE responses: text JSON response, ordered SSE lifecycle (`response.created`, `response.in_progress`, `response.output_item.added`, `response.content_part.added`, `response.output_text.delta`, `response.output_text.done`, `response.content_part.done`, `response.output_item.done`, `response.completed`) with usage counts/details, and synthetic tool call trace.
    - llama.cpp v0.6.0 (source commit `d81235049384534c167caea52b85a694f6103d14`):
      - Valid text requests (`input` string and items), unsupported non-empty `previous_response_id` (rejected by conversion), rejected `input_file` / invalid item shapes, instruction and reasoning effort mappings, non-function tools (warned/skipped).
      - Wire/SSE responses: `/v1/responses` format with `event:` and JSON `data:` framing (blank-line separated), the pinned created/in-progress, item/content-added, output-text delta/done, item/content-done, completed sequence, and prompt/decode/total/cached usage counts.
    - Generic observer mechanics:
      - Separate unattributed generic observer test fixtures for failure, incomplete, premature EOF, and CRLF / chunk boundary splits, without attributing them to specific runtime sources.
  - Document runtime, source commit, and synthetic profile provenance for every fixture.
  - Provide deterministic unit tests verifying fixture integrity, syntax validity, and expected event/usage structures.

  - No live network calls, runtime daemons, model downloads, or GPU access.
  - No fixture labeled as live evidence or general runtime compatibility proof.
  - No changes to existing native Responses connector fixtures (`fixed_test.go`, `sse_test.go`).
