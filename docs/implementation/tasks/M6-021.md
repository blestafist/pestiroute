# M6-021 — Classify IPC loss and malformed stream failures

## Outcome

Classify IPC loss, malformed frames, protocol violations, and child crashes into truthful GatewayError categories and retry dispositions across explicit dispatch milestones (before-send, delivered/ambiguous, and post-Head committed), guaranteeing no ambiguous replay, prompt invocation/resource cleanup, and never fabricating successful completion. ## Scope

- Dispatch milestone tracking and conservative failure classification in `internal/connector/external/execute_linux.go` and `internal/connector/external/lifecycle_linux.go`:
  - **Before-send milestone**: transport dial failure, context cancel/timeout before writing request, or broker credit reservation failure before send; classified cleanly; retry safe only if proven never sent.
  - **Delivered / ambiguous milestone**: request sent onto wire, awaiting Head; sudden transport disconnect, unexpected EOF, or child crash returns `connector_unavailable` (`CategoryUnavailable`) with `RetryDisposition: RetryUnknown` (or `RetryUnsafe`), never `RetrySafe`.
  - **Post-Head committed milestone**: Head already delivered to caller; subsequent transport drop, child crash, or unexpected EOF causes subsequent `Next()` to return error and closes stream; never synthesizes `Complete(succeeded)`.
  - **Malformed frames and protocol violations**: invalid frame types, out-of-order sequence, payload exceeding limits, data after `CompleteFrame`, or EOF without `CompleteFrame` return classified contract errors (`CategoryInvalidRequest` or `CategoryInternal`), marked non-retryable (`RetryUnsafe`).
  - **Prompt cleanup on crash**: transport disconnection or child exit immediately unwinds pending `stream.Recv()` calls, releases held credit broker reservations, unblocks waiting callers, and revokes invocation slots.
- Test harness and deterministic test suite in `internal/connector/external/`:
  - Update `execute_linux_test.go` (or dedicated fault test file) with before-send, after-send (ambiguous), and post-Head failure injection.
  - Test sudden child severance asserting prompt unblocking (<= 2 s), `CategoryUnavailable`, and `RetryUnknown`.
  - Test post-Head severance asserting stream error on `Next()`, no fabricated success, and credit/invocation slot release.
  - Test protocol violation fixtures: out-of-order sequence, bad frame type, trailing frame after Complete, and unexpected EOF before Complete.
- Limits:
  - Supervisor restart backoff, crash-loop budgets, and child restart belong strictly to M6-022.
  - Process-group drain, SIGTERM/SIGKILL sequence, and tree shutdown belong to M6-023.
  - Native Responses child wrapping belongs to M6-024.
  - End-to-end SQLite reservation rollback and attempt accounting belong to M6-027.

## Acceptance

- [x] Before-send failure (e.g. pre-send context cancellation or reservation failure) produces classified GatewayError; if cancelled, `CategoryCancelled`; if timed out, `CategoryTimeout`.
- [x] Delivered / ambiguous failure (transport severed or child crash before Head) returns `CategoryUnavailable` with `RetryDisposition` of `RetryUnknown` or `RetryUnsafe`, guaranteeing Core will not trigger ambiguous automatic replay.
- [x] Post-Head failure (transport severed or child crash during streaming) causes `Next()` to return a non-nil error, closes the stream, revokes the invocation, and never yields `Complete(succeeded)` or corrupt frame bytes.
- [x] Protocol violations (unexpected frame type, non-monotonic sequence, premature EOF before Complete, or frames received after Complete) are rejected as malformed errors and fail closed.
- [x] Sudden child process death or transport closure promptly unblocks all in-flight caller `Recv()` / `Send()` operations (within 2 s) and releases held credit broker reservations and invocation registrations.
- [x] All tests pass under `go test -race` with zero data races.
