## Scope

- Configure and run the local PestiRoute gateway on `127.0.0.1:8080` targeting upstream OpenAI Responses with dedicated upstream credentials (`PESTIROUTE_UPSTREAM_BEARER`).
- Execute the gateway leg with OpenCode 2.0.6, `gpt-5.4-mini`, clean HOME/XDG, synthetic client Bearer, and identical prompt/files (`alpha.txt`, `beta.txt`).
- Instrument every request (including tool continuations) to record per-round usage and timing without complete-stream buffering, preserving bounded backpressure and streaming.
- Observer sizing: enforce body limits >= 32 KiB and reasonable upstream POST limits so valid continuation payloads (specifically >= 12,641 bytes observed in M1-024) are not prematurely rejected.
- Limit manual client runs to at most 2 per scenario (single-tool and parallel-tool).
- Produce structurally sanitized evidence at `docs/implementation/evidence/m1/openai-responses/gpt-5.4-mini/opencode-2.0.6/gateway.json` and update the adjacent `README.md`.
