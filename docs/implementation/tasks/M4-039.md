# M4-039 — Support test-only ANTHROPIC_BASE_URL injection for compatible endpoint smoke testing

## Outcome

Enable offline test suites and smoke harnesses to override the Anthropic Messages target URL via `ANTHROPIC_BASE_URL` (supporting compatible endpoints such as `https://ai.pestit.pl/v1`), while preserving the official `https://api.anthropic.com/v1/messages` default in production, keeping production YAML schema unbroadened, maintaining proxy/redirect security defaults, and keeping compatible-endpoint evidence strictly distinct from pinned direct-Anthropic M4-036. Links to row in [TASKS.md](../TASKS.md#m4--first-translation-connector) and milestone [ROADMAP.md](../ROADMAP.md#m4--first-translation-connector).

## Read First

- `internal/connector/anthropic/transport.go` (`messagesEndpoint`, `NewTransport`, request construction).
- `docs/implementation/SMOKE-M4.md` (harness configuration and provider profile).
- `scripts/smoke-m4-artifacts.py` (offline artifact generation and validator).
- `docs/implementation/tasks/M4-036.md` (pinned direct-Anthropic gate and blocker condition).

## Scope

- Test injection seam allowing `ANTHROPIC_BASE_URL` (or test transport option) to configure base URL in connector unit/integration tests and smoke scripts without modifying production YAML schemas or exposing arbitrary public endpoints.
- Normalization of base URL to `/v1/messages` or `/messages` path without path-traversal or malformed URL bugs.
- Security defaults preserved: redirect refusal (`ErrUseLastResponse`), no ambient proxy fallback, strict header filtering.
- Smoke documentation/scripts updated to recognize test base URL while distinguishing compatible third-party captures from official direct-Anthropic M4-036 artifacts.
- Out of scope: production YAML configuration changes, live network requests, credential acquisition, closing M4-036 with compatible endpoint runs.

## Acceptance

- [x] When `ANTHROPIC_BASE_URL` is unset, `Transport.Request` targets `https://api.anthropic.com/v1/messages`.
- [x] When `ANTHROPIC_BASE_URL` is set in tests/harness (e.g. `https://ai.pestit.pl/v1`), requests target the resolved messages path (`https://ai.pestit.pl/v1/messages`), preserving headers and payload.
- [x] Production YAML schemas remain unchanged; invalid/unknown fields in protected YAML continue to fail closed.
- [x] Security defaults (redirect refusal, proxy suppression, header stripping) remain enforced regardless of target URL.
- [x] Offline unit, integration, and smoke artifact self-tests pass with both default and configured test base URLs.
- [x] Specification and smoke guidance explicitly separate compatible endpoint evidence from pinned direct-Anthropic M4-036 evidence; compatible endpoint runs do not mark M4-036 DONE.
