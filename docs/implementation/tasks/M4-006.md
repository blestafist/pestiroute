## Outcome

Build selected-account HTTP requests and credentials. One bounded deliverable in the [M4 registry](../TASKS.md#m4--first-translation-connector)
toward the original [M4](../ROADMAP.md#m4--first-translation-connector).

## Read First

- [Stream/resource policy](../M4-TRANSLATION.md#stream-completion-and-resource-policy).

## Scope

- Implement one scoped Messages HTTP request path with API key from runtime CredentialAccess, fixed allowed endpoint, API-version header, appropriate accept/content-type and safe header allowlist.
- Use the configured scoped transport, cancellation, no redirects, no hidden retry/decompression and a non-replayable request body. Retain neither credentials nor invocation services on the Connector.
- Do not implement OAuth, field conversion, output parsing or a platform SDK retry wrapper.

## Acceptance

- [ ] Upstream receives only the selected account API key; client virtual keys, cookies, forged account/version/beta/auth and hop-by-hop headers cannot override it.
- [ ] Redirects and ambiguous network failures never cause another inference call; cancellation/Close release response bodies and sensitive diagnostics are sanitized.
