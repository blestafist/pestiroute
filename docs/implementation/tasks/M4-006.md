## Scope

- Implement scoped Messages HTTP request construction and transport in `internal/connector/anthropic/transport.go` (and `transport_test.go`).
- Request path targets the configured/default endpoint (`https://api.anthropic.com/v1/messages`), with `x-api-key` retrieved on-demand from scoped `CredentialAccess` (`"bearer"` or `"api_key"`), `anthropic-version: 2023-06-01`, `content-type: application/json`, and `accept: text/event-stream`.
- Enforce strict client header sanitization: block/strip hop-by-hop headers, `Authorization`, `x-api-key`, `anthropic-version`, `anthropic-beta`, cookies, and connection-nominated headers. Forward only safe allowlisted headers.
- Configure `http.Transport` and `http.Client`: non-replayable body (`GetBody = nil`), disable automatic compression (`DisableCompression: true`), disallow redirects (`CheckRedirect: http.ErrUseLastResponse`), no HTTP/2 cached-connection retries (`ForceAttemptHTTP2: false`), and honor context cancellation.
- Retain neither credentials nor invocation services on the `Connector` or `Transport`. Sanitize sensitive keys from error messages and diagnostics.
- Out of scope: message payload translation/decoding (M4-007), generation controls (M4-008), pre-head status classification (M4-010), SSE parsing (M4-011), streaming through Execute (M4-013), and interactive auth / OAuth.

## Acceptance

- [x] Upstream request contains `x-api-key` matching the selected account credential from `InvocationServices.Credentials`, with `anthropic-version: 2023-06-01`, `content-type: application/json`, and `accept: text/event-stream`.
- [x] Client headers cannot override upstream credentials or version: `Authorization`, `x-api-key`, `anthropic-version`, `anthropic-beta`, cookies, `Host`, `Content-Length`, `Content-Type`, `Accept-Encoding`, and hop-by-hop headers (`Connection`, `Keep-Alive`, `Proxy-*`, `TE`, `Trailers`, `Transfer-Encoding`, `Upgrade`) are stripped/blocked.
- [x] Transport enforces `CheckRedirect` returning `http.ErrUseLastResponse` and non-replayable request body (`GetBody = nil`); redirects and transport errors do not trigger hidden retry.
- [x] Scoped credentials are isolated across accounts; credentials and `InvocationServices` are never stored/retained on connector or transport structs.
- [x] Context cancellation immediately terminates the in-flight upstream request and releases resources; error and logging diagnostics never leak raw credentials.
