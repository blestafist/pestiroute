Establish public source provenance, accepted ADR DEC-025, and normative binding in `M10-AUTH-BINDING.md` for explicit opt-in missing-project recovery via Antigravity `onboardUser` and LRO operation polling, with durable sanitized request budget accounting (hard <=1000 total request ceiling across all operations) and strict credential persistence invariant (credentials persisted only when project confirmed). ## Scope

- Public Research & Provenance:
  - Audit and pin wire schemas for `loadCodeAssist` tier metadata (`allowedTiers`, `currentTier`, `ineligibleTiers`), `v1internal:onboardUser` request/response, and `v1internal/operations/*` LRO polling from `gemini-cli`, `gemini-oauth`, and `9router`.
  - Document missing-project recovery procedure: when `cloudaicompanionProject` is absent/null and account has eligible default tier, how onboarding initiates and polls until project provisioning completes.
- Architecture & Decisions:
  - Draft and record accepted ADR DEC-025 in `docs/project/DECISIONS.md`:
    1. Scope override: explicitly authorized opt-in flag/config (e.g. `--allow-onboard`) enables onboarding; default unconfigured mode remains strictly fail-closed `auth_project_missing`.
    2. Durable request budget accounting: enforce a hard total ceiling of at most 1000 provider HTTP requests across ALL operations (auth, token exchange, discovery, onboarding, LRO polls, inference, refresh, retries); track budget durably before any live dispatch; fail closed if budget exhausted; use fewest necessary calls.
    3. Invariant: zero credentials saved until a project ID is verified.
    4. Guardrails: no paid resources, billing changes, destructive actions, or implicit account hopping.
    5. Sanitized stage & diagnostic reporting: define safe codes (`auth_onboarding_started`, `auth_onboarding_polling`, `auth_onboarding_failed`, `auth_tier_ineligible`, `request_budget_exceeded`) without echoing provider payload values.
- Specification & Binding Updates:
  - Synchronize `M10-AUTH-BINDING.md` and `M10-RESEARCH.md` with the normative onboarding state machine, operation polling bounds (max attempts, interval, deterministic context timeout, cancellation), no ambiguous replay, and sanitized diagnostic codes.
  - Specify deterministic synthetic fixture vectors in `internal/connector/antigravity/testdata/` (absent project with eligible default tier, LRO polling in-progress -> done with project ID, ineligible tier error, poll timeout).
- Explicit limits:
  - No live network requests or external provider calls during planning or task execution.
  - No secrets, tokens, or private operator payload reads/logging.
  - No code changes to Go files in this task (reserved for subsequent implementation task).
