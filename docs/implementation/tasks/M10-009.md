## Scope

- In `internal/connector/antigravity`:
  - Extend configuration in `component.go` to accept optional `oauth` config block: `client_id`, optional `client_secret`, `auth_endpoint` (default `https://accounts.google.com/o/oauth2/v2/auth`), `token_endpoint` (default `https://oauth2.googleapis.com/token`), `redirect_uri` (default `http://localhost:8080/callback`), `scopes` (default pinned Google scopes: `https://www.googleapis.com/auth/cloud-platform https://www.googleapis.com/auth/userinfo.email https://www.googleapis.com/auth/userinfo.profile https://www.googleapis.com/auth/cclog`). Operator supplies own OAuth client ID; no invented identity requirement.
  - Implement `Authenticate(Action="start")`: generate cryptographically secure 32-byte PKCE verifier (base64url) and SHA-256 code challenge, 32-byte random state; construct verification URL with query parameters; return `core.AuthResult{Supported: true, State: <serialized continuation>, NextAction: "continue", UserAction: &core.AuthUserAction{VerificationURI: ...}}`. Zero outbound network requests before user sign-in.
  - Implement `Authenticate(Action="continue")`: validate continuation state, parse callback input URL/query, verify state parameter matches expected state, exchange authorization code via POST to `token_endpoint` (`grant_type=authorization_code`, `code`, `client_id`, `redirect_uri`, `code_verifier`), parse token response (`access_token`, `expires_in`, optional `refresh_token`), calculate `CredentialExpiresAt`, return `core.AuthResult{Supported: true, Credentials: map[string][]byte{"oauth": ...}, CredentialExpiresAt: ...}`.
  - Support real transport opt-in: allow standard HTTP transport (e.g. from runtime `services.Transport`) for token exchange in addition to `OfflineTestTransport`, enabling full production flow while keeping deterministic tests safe.
  - Add unit tests in `auth_test.go` and `auth_coordinator_test.go` for start, continue, PKCE validation, state mismatch, malformed callback, and error mappings.
- In `cmd/gateway` (under user-granted serialized gateway test/wiring window):
  - In `admin_auth.go`: add `"antigravity"` to `defaultAdminAuthRegistry` (instantiate and init connector), `authCredentialRefs` (map `"oauth"` credential name), and `useDefaultTransport` (opt in to default HTTP transport for real exchange).
  - Add end-to-end integration test in `cmd/gateway/admin_auth_test.go` (or `cmd/gateway/auth_store_test.go`) verifying `runAuthAdmin` `start` and `continue` with simulated callback input and deterministic test transport / mock server, verifying encrypted credential persistence in SQLite and decryptable reload into `Execute`.
- Explicit limits:
  - No live provider/network calls during automated tests.
  - No tool calling implementation (tracked in M10-010).
