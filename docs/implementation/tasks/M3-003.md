## Scope

- Write `docs/implementation/M3-RUNTIME.md`: trusted principal passing outside opaque payload, runtime-owned repository signatures (`AccountingStore`, `PolicyStore`, `KeyStore`), policy snapshot/revision rules, Connector `EstimateUsage` invocation and unknown-estimate policy, atomic admission (`Admit`), attempt reservation (`BeginAttempt`, `RecordDispatchIntent`), and exactly-once settlement (`FinalizeAttempt`).
- Define exact RPM/TPM window arithmetic, integer overflow handling, and clock behavior. RPM derives from accepted requests (`accepted_at`); TPM reserves attempt budget and reconciles against terminal usage. Specify conservative charging for exact/partial/unknown usage, unsent pre-commit failures, overage, cancellation, and restart.
- Specify error propagation and SQLite acknowledgement around terminal settlement replacing the lossy/void `Finalize` callback; define pre-commit versus post-commit storage failure behavior and fail-closed admission.
- Limits: Documentation and semantic runtime architecture specification only; no production/test Go code changes in `internal/core` or SQLite migrations in this card.
