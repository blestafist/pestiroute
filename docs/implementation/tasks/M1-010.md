# M1-010 — Single-target Core execution

## Outcome

Core owns one attempt and its lifecycle without interpreting provider bytes. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

- `internal/core/execution.go` and `internal/core/execution_test.go`.

## Scope

- Add single-target Core execution in `internal/core` dispatching to an injected target interface.
- Assign trusted runtime request ID and attempt ID; enforce static M1 capability check (`openai.responses.v1`, `gpt-4.1-mini-2025-04-14`, native execution; supported: `llm.streaming`, `llm.tools`, `llm.structured_output`; reject unsupported/unknown).
- Enforce frame ordering, commit at Head handoff, cancellation/Close propagation, and exactly-once in-memory attempt finalization with terminal outcome and usage reporting.
- Stop before concrete adapter or connector imports, HTTP wiring, configuration parsing, persistent accounting, M2 target registry, multiple accounts, or fallback/retries.

## Acceptance

- [x] One admitted request invokes one Execute on the injected target; client metadata cannot select an account or overwrite runtime request/attempt IDs.
- [x] Unsupported model, protocol, execution mode, or undeclared/unknown required capability returns a pre-execution GatewayError without invoking the target.
- [x] Valid streams, pre-head errors, and post-head stream failures (unexpected EOF, malformed ordering, context cancellation) finalize exactly once in memory with terminal outcome and usage; EOF without Complete is not success.
- [x] Head delivery commits the attempt; no retry or replacement attempt after Head handoff.
- [x] Core imports no concrete adapter or connector packages and parses no JSON/SSE payload bytes.
