## Scope

- Add docs/references/CLAUDE_CODE_CONNECTOR_RESEARCH.md with dated source provenance for official Claude Code docs, published client artifacts or source, and the candidate subscription backend.
- Record exact product/client/backend versions or revisions where available, source URLs, applicable reuse licenses, and access limits.
- Separate source evidence, observed runtime evidence, and unknowns. If an artifact or source is unavailable, state that rather than inferring behavior.
- Do not make live requests, inspect or store user credentials, reuse code with unresolved licensing, or claim compatibility.

## Acceptance

- [ ] The note identifies the exact Claude Code client/backend target being researched and pins source versions or explains why a version cannot yet be pinned.
- [ ] Every source has a date, URL, provenance and license/reuse status.
- [ ] The note lists unresolved facts needed before protocol/auth implementation and links to this card and M7 roadmap.
- [ ] No secret, private payload or unsupported compatibility claim is committed.

## Verification

Manually verify source URLs, version/revision identifiers and license statements against the cited sources; check relative links and anchors. Run git diff --check from the repository root. No runtime test is expected for this research-only task.
