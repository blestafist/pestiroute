## Scope

- Extend test observer (`scripts/m1-gateway-observer.py`) with offline-verified first-event notification (callback/signal) and client disconnect/transport error recording during live streaming.
- Run bounded long-response interruption across direct leg (client -> observer -> OpenAI, preserving direct path) and gateway leg (client -> gateway -> observer -> OpenAI).
- Drive client interruption immediately upon first SSE event via real-client control (PTY SIGINT or OpenCode session interrupt API).
- Enforce strict run limit: at most 2 manual interruption attempts per leg.
- Capture client transport closure, gateway cleanup, observable upstream cancellation, attempt counts, and absence of retry without claiming remote compute cancellation from socket closure alone.
- Write sanitized traces to `docs/implementation/evidence/m1/openai-responses/gpt-5.4-mini/opencode-2.0.6/cancellation.json` and update adjacent `README.md`.
- Limits: Stop before changing client/provider behavior, altering gateway contracts, or replacing deterministic fake-upstream cleanup tests. No model substitution or uncommitted retry/routing fallbacks.
