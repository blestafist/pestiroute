## Scope

- Add unit and guarantee tests in `internal/connector/claudecode`:
  - `TestStreamingGuaranteesEarlyFrameDelivery`: prove `Head` and initial `Body` delta frames are delivered on demand without requiring full upstream response consumption or complete stream buffering.
  - `TestStreamingGuaranteesCancellation`: prove cancellation via `context.Context` (pre-canceled, during `Next()`, or mid-stream) and underlying IO read failure terminates cleanly with appropriate `GatewayError` and does not hang, leak goroutines, or panic.
  - `TestStreamingGuaranteesBackpressure`: prove the stream reader steps forward on demand; upstream bytes are read only as consumer advances `Next()`.
  - `TestStreamingGuaranteesTerminalAccounting`: prove exactly-once accounting finalization, ensuring successful streams report provider usage with complete status, failed/interrupted streams report partial/unknown usage with failed outcome, and no frames are emitted after stream completion.
- If necessary, refine `internal/connector/claudecode/sse.go` to ensure context propagation and clean terminal error handling satisfy all streaming guarantees.
- Explicit limits: Offline synthetic unit tests only. No live network calls, no real credentials, connector remains uncomposed and non-routable.

## Acceptance

- [x] `Head` and initial delta frames are yielded before reading subsequent stream chunks; verify reader read count at initial yield is bounded and does not read to EOF.
- [x] Context cancellation before or during `Next()` immediately halts stream traversal and returns error/failure without deadlocking.
- [x] Upstream reads occur strictly on-demand per `Next()` call without unconstrained background prefetching.
- [x] Terminal `Complete` frame is emitted exactly once per stream; succeeding streams report provider usage, and failed or canceled streams report failure with partial or unknown usage.
- [x] No frames or panics occur after stream closure or terminal completion (`Next` returns `io.EOF`).
- [x] Deterministic tests pass with `-race`.
- [x] Repository `./scripts/check.sh` and `git diff --check` pass.
