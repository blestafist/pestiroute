## Scope

- Assess text, client-owned tools and multiple tool rounds, reasoning, streaming usage, cancellation, statefulness/affinity, errors and retry dispositions.
- For each capability, record evidence, version/account scope and supported, unsupported or unknown; source evidence alone cannot establish runtime support.
- Identify any changes that would require an ADR; do not change the contract or implementation.

## Acceptance

- [ ] Every matrix entry has evidence and scope, or is explicitly unknown.
- [ ] Ambiguous delivery is not treated as safely retryable; post-commit fallback is prohibited.
- [ ] The matrix distinguishes client-owned agent/tool behavior from backend behavior.
