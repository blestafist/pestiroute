# M2-025 — Add stream-contract violation conformance cases

## Outcome

Runtime validation and conformance checks verify that malformed producer stream sequences are consistently caught, classified as runtime contract errors, trigger producer Close and exactly-once attempt finalization, while preserving any observed usage without concealment as success, and valid native/scripted output passes the same invariants without error. A follow-up healthy execution succeeds after every violation. See [registry](../TASKS.md#m2--connector-api-and-conformance-baseline) and [M2](../ROADMAP.md#m2--connector-api-and-conformance-baseline).

## Scope

- Expand `internal/conformance/conformance_test.go` with shared stream-contract violation scenarios executed against scripted producers and validated through Core execution:
  - Systematic coverage of all v1 stream lifecycle invariants via malformed scripted streams:
    - Duplicate Head frame.
    - Head with undeclared, empty, or mismatched protocol.
    - Invalid discriminant/payload (Type `head` with nil `Head` or non-nil `Body`/`Complete`; Type `body` with nil `Body` or non-nil `Head`/`Complete`; Type `complete` with nil `Complete` or non-nil `Head`/`Body`; unknown frame discriminant).
    - Empty Body frame (`Data == nil` or `len(Data) == 0`).
    - Body before Head frame.
    - Body after Complete frame.
    - Duplicate Complete frame.
    - Invalid completion outcome / error correlation (`OutcomeSucceeded` with non-nil `Error`; non-`OutcomeSucceeded` with nil `Error`; Head carrying `Error` followed by `Complete(succeeded)`; unrecognized outcome string).
    - Trailing frames after Complete (e.g. extra Body, Head, or Complete after an otherwise complete stream, or unexpected non-EOF read).
    - Premature EOF (`io.EOF` before emitting a Complete frame).
  - Assert that Core dispatch (`core.Dispatcher.Execute` wrapping the stream in `core.NewCheckedStream` / `attemptStream`) enforces the contract:
    - Returns or yields a classified runtime contract error (`ErrStreamContract` / GatewayError with `execution_failed`).
    - Underlying producer stream is closed (`Close()` called).
    - Attempt is finalized exactly once via observation sink / finalize hook.
    - Attempt outcome is recorded as failed (never concealed as succeeded).
    - Delivered prefix bytes before the violation are preserved.
    - When Complete carried usage before a trailing violation, usage report remains available on the finalized attempt record.
    - A follow-up healthy execution succeeds immediately on the same connector/dispatcher after every violation.
  - Verify that valid native-loopback and scripted streams pass the same invariant validator without error.
- Explicit limits:
  - Do not implement error normalization, provider mapping, or retry policy (M2-026).
  - Do not implement cancellation / partial-close teardown (M2-027) or bounded backpressure (M2-028).
  - No changes to production `internal/core/` or `internal/connector/` unless fixing broken contract validation discovered during conformance assertion.
  - Test-only additions under `internal/conformance/`; synthetic local fixtures only, no live credentials or network access.

## Acceptance

- [x] Conformance runner executes the full violation matrix through Core dispatch: duplicate Head/Complete, Body before Head, Body after Complete, wrong/empty protocol, invalid discriminant/payload, empty Body, invalid outcome/error correlation (succeeded with error, failed without error, Head error followed by Complete succeeded, unknown outcome), and premature EOF.
- [x] Trailing frames after Complete (extra Body, Head, or Complete) are rejected as stream contract errors; the attempt is recorded as failed (never concealed as succeeded), and any observed usage from Complete remains attached to the finalized attempt record.
- [x] In every violation scenario, the underlying stream producer is closed (`Close()` called) and the attempt is finalized exactly once via the observation sink / finalize hook.
- [x] A follow-up healthy execution succeeds cleanly on the same connector/dispatcher after each injected violation.
- [x] Valid native-loopback and scripted streams pass the same invariant validator checks without error.
