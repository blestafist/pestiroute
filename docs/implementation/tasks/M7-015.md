## Scope

- Record DEC-019 in `docs/project/DECISIONS.md`:
  - Record that user direction adopting 9Router manual callback flow authorizes extending offline candidate scope to minimal generic runtime/admin/IPC plumbing in M7-016 alongside M7-010 and M7-013, strictly offline-only without live calls, real credentials, capability promotion beyond `Unknown`, or production routing.
  - Extend `AuthUserAction`: permit optional/empty `UserCode` and zero `PollInterval` when authentication uses browser redirects rather than RFC 8628 device codes.
  - Add additive `CallbackInput string` to `AuthRequest` (and `AuthCoordinator.Continue`): strictly bounded (1–4096 printable ASCII bytes), client-supplied at continuation, never treated as opaque continuation state, never logged.
  - Security requirements: configured redirect URI is absolute with no query/fragment; Connector compares callback raw scheme, authority, escaped path byte-for-byte with it (no normalization), strictly requires exactly one non-empty `code` and `state`, and rejects malformed encodings, duplicates, errors, or unexpected parameters before exchange.
- Synchronize `docs/implementation/CONTRACT.md`:
  - Document `AuthRequest.CallbackInput` and amended `AuthUserAction` rules.
- Synchronize `docs/implementation/M3-AUTH.md`:
  - Document runtime conventions for `CallbackInput` and continuation handling.
- Synchronize `docs/implementation/M7-BINDING.md`, `M2-BINDING.md`, `M6-BINDING.md`, and `M6-HANDOFF.md`:
  - Update candidate OAuth PKCE binding to replace the documented contract blockers with the DEC-019 manual callback flow.
  - State the exact transport field semantics and explicitly defer Go/coordinator/protobuf implementation to M7-016.
- Limits: Documentation and specification changes only; no Go implementation code in this task. Generic runtime/IPC implementation is deferred to M7-016.
