# M11-002 — Add opt-in authenticated admin listener

## Outcome

Add an opt-in, authenticated management HTTP listener to the gateway without changing inference behavior, establishing operator bearer authentication, Host/Origin validation, body and timeout bounds, and the static asset mount seam for M12. Delivers the runtime listener baseline for [M11 Administrative HTTP API](../M11-ADMIN-API.md) in [TASKS.md](../TASKS.md#m11--administrative-http-api) under [ROADMAP.md](../ROADMAP.md#m11--administrative-http-api).

## Scope

- Implement management server and middleware in a new package `internal/admin` (listener configuration, router, bearer auth, constant-time token comparison, Host and Origin validation, request body size limits, timeout configuration, standard error JSON responses, and static file mount seam).
- Wire optional `admin` configuration in `cmd/gateway/yaml_config.go` and `cmd/gateway/protected_startup.go`.
- Wire concurrent startup, readiness coordination, and graceful drain/shutdown in `cmd/gateway/main.go`.
- Explicit boundaries:
  - No endpoint business logic (status, accounts, keys, policies, usage, auth endpoints belong to M11-003 through M11-006).
  - Default inference mux (`/v1/responses`, `/v1/chat/completions`) must never mount admin routes, and admin listener must never mount inference routes.
  - Virtual inference keys cannot authenticate against the admin listener; only the operator bearer token is valid.
  - No changes to Core contracts, SQLite schema, or connector implementations.

## Acceptance

- [x] Default inference startup is completely unchanged when `admin` is unconfigured: no admin listener binds, and inference mux returns 404 for admin paths.
- [x] When `admin` is configured, an opt-in listener binds to the configured loopback address (`127.0.0.1` or `[::1]`) and serves `/admin/v1/**` with required `Authorization: Bearer <token>`.
- [x] Operator token loaded out-of-band from file or environment variable; token comparison uses constant-time comparison; missing or invalid token returns 401 with standard error envelope `{ "error": { "code": "unauthorized", ... } }`; inference virtual keys are rejected with 401.
- [x] Strict Host and Origin checks enforced: unapproved `Host` header or unapproved/null `Origin` returns 403 `forbidden`; same-origin or configured origins are permitted; non-browser clients without Origin header proceed with bearer auth.
- [x] Request payload size bound enforced (e.g. 64 KiB default via `http.MaxBytesReader`) returning 413 `payload_too_large` on overflow; timeouts (read, write, idle) configured.
- [x] Startup validation fails cleanly if `admin` is enabled without a valid bearer-syntax token, if token file has insecure permissions (world/group-writable) or is empty, or if non-loopback bind is configured without TLS.
- [x] Optional static asset mount seam at `/admin/` serves files without bearer authentication and does not fall through to `/admin/v1/**` API routes.
- [x] Graceful lifecycle: SIGINT/SIGTERM or context cancellation cleanly drains and shuts down both listeners within configured shutdown timeout without socket leaks or unhandled errors.
