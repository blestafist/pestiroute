## Scope

- Add a Connector-private byte-preserving SSE observer in `internal/connector/codex` (`sse.go` or `observer.go`), integrated inline into `executeStream` in `execute.go`.
- Stream response bytes through the observer incrementally as chunks arrive (`executeChunkSize = 4 KiB`), preserving caller-visible `core.BodyFrame` bytes byte-for-byte.
- Parse SSE framing incrementally: handle arbitrary chunk boundaries (including 1-byte splits), CRLF and LF line endings, multiline `data:` fields, comments/keepalive lines (`: keepalive`), and UTF-8 without whole-response buffering.
- Enforce binding ceilings: bound single SSE events to 1 MiB and scalar lines to bounded memory (e.g. 4 KiB); reject oversize events or malformed framing deterministically.
- Explicit non-scope: terminal outcome classification and usage extraction belong to subsequent cards M5.1-024 and M5.1-025; gateway route composition belongs to M5.1-027.

## Acceptance

- [x] SSE observer processes stream bytes inline with `executeStream.Next()` without whole-stream buffering or reserialization of caller-visible bytes.
- [x] Exhaustive split boundaries (including 1-byte chunks, arbitrary splits across `event:`, `data:`, CRLF, and UTF-8 sequences) yield identical observer state and byte-for-byte identical output.
- [x] Per-event memory ceiling (1 MiB event bound, bounded scalar lines) is enforced; oversize events or malformed framing fail closed deterministically without buffering unbounded input.
- [x] Cancellation or stream `Close()` while an event is incomplete halts processing, closes upstream response body, and releases resources promptly without leaking goroutines.
