# M8-005 — Bind Claude Code admin OAuth callback flow and encrypted SQLite credential lifecycle

## Outcome

Enables and proves interactive admin OAuth `start`, manual pasted callback URL `continue`, and token `refresh` for Claude Code accounts in the gateway admin CLI, persisting encrypted credential bundles to SQLite under AES-256-GCM master keys. Bridges M8's connector auth mechanics into gateway operations without enabling live provider routing. ## Scope

- In `cmd/gateway/admin_auth.go` (`defaultAdminAuthRegistry`):
  - Recognize Claude Code account connector (`claudecode` or `pestiroute.claudecode.messages`).
  - Instantiate and initialize `claudecode.NewConnector()` with profile `claude-code-messages-v1` using package configuration.
- In `cmd/gateway/admin_auth_test.go`:
  - Add deterministic integration tests for Claude Code admin authentication:
    - `admin auth start --account=<id>` starts interactive flow, stores durable session in SQLite, and displays authorization URI and pasted-callback instruction.
    - `admin auth continue --session=<id>` receives callback URL with authorization code, completes PKCE exchange via offline fake HTTPS `.invalid` transport, and stores AES-256-GCM encrypted token bundle `{access_token, refresh_token, expires_at}` in SQLite auth store.
    - `admin auth refresh --account=<id>` rotates expired/due tokens cleanly against the fake endpoint and updates encrypted store.
    - Error cases: malformed callback URL, CSRF state mismatch, rejected HTTP exchange, canceled context, expired session, and tamper fail closed.
    - Redaction: PKCE verifier, tokens, and raw callback parameters stay out of logs and terminal presentation.
- Shared file ownership:
  - M8 holds implementation ownership of the Claude Code admin auth branch in `cmd/gateway/admin_auth.go` and its tests in `cmd/gateway/admin_auth_test.go`.
  - M9 is confined to `internal/adapter/chatcompletions/**`; no file or semantic overlap.
- Limits:
  - Do NOT modify `cmd/gateway/yaml_config.go` or enable production execution routing (`pestiroute.claudecode.messages` remains fail-closed / unsupported in gateway config).
  - No external/live provider network calls; fake `.invalid` TLS transport only.
  - Connector capabilities remain `Unknown`. No public contract changes.
