## Scope

- Create directory `internal/connector/codex/testdata/responses/` with versioned request and SSE fixtures plus provenance manifest:
  - `request-positive.json`: valid standard Responses request with model, instructions, text prompt, `stream: true`, `store: false`, and `reasoning.encrypted_content` include.
  - `request-tools-history.json`: multi-round conversation with tool declarations, function call items, and tool call results.
  - `request-reasoning-item.json`: conversation history containing an opaque encrypted reasoning item with ciphertext and summary fragments.
  - `request-unknown-fields.json`: valid request carrying unknown optional extension fields that must survive opaque pass-through.
  - `request-store-true.json`: request with explicit `store: true` for negative rejection testing.
  - `request-stream-false.json`: request with explicit `stream: false` for negative rejection testing.
  - `stream-normal-text.sse`: incremental text stream (`response.created`, `response.output_item.added`, `response.content_part.added`, `response.output_text.delta`, `response.content_part.done`, `response.output_item.done`, `response.completed` with full inclusive usage).
  - `stream-tools.sse`: function tool call arguments stream (`response.output_item.added`, `response.function_call_arguments.delta`, `done`, `output_item.done`, `response.completed`).
  - `stream-interleaved.sse`: stream with multiple interleaved content parts, item IDs, and call IDs.
  - `stream-reasoning.sse`: stream delivering reasoning summary fragments, reasoning ciphertext item, and `response.completed`.
  - `stream-incomplete.sse`: terminal stream yielding `response.incomplete` with an incomplete reason.
  - `stream-failed.sse`: terminal stream yielding `response.failed`.
  - `stream-error.sse`: terminal stream yielding `error` event.
  - `stream-premature-eof.sse`: stream dropping connection abruptly before any terminal event, with unterminated delta and no trailing blank line.
  - `stream-crlf-multiline.sse`: stream using CRLF delimiters, multiline `data:` blocks, and multi-byte Unicode runes split across chunk boundaries.
  - `stream-usage-zero-missing.sse`: terminal stream with missing/zero usage counters and cached/reasoning subset details.
  - `stream-boundary-keepalive.sse`: stream with provider keepalive/rate_limits non-terminal events and a payload approaching the 1 MiB SSE event ceiling.
  - `README.md`: provenance manifest with pinned OpenCode v2 / Responses API provenance, SHA-256 table, synthetic vs captured classification (zero usable secrets guarantee), and declared intended outcome for every stream.
- Create `internal/connector/codex/fixtures_stream_test.go` with concrete test checks:
  - `TestResponsesFixtureIntegrityAndMalformedInput`: verifies SHA-256 table parity and rejection of mutated fixture bytes, asserts positive request fields and the explicit `store:true` / `stream:false` fixture shapes (not production rejection), validates stream event sequencing, item IDs, call IDs, phases, CRLF/multiline data parsing, Unicode splits, usage counters, and terminal event classification (`completed`, `incomplete`, `failed`, `error`).
  - `TestResponsesFixtureFakeUpstreamStreaming`: exercises `fakeupstream.Server` with gated step delivery (early chunk read while upstream is waiting), client cancellation before completion, and connection drop / premature EOF assertion.
- Test-only fixture loader and integrity validation; do not implement `Execute`, an HTTP transport, or a production SSE observer.
