## Scope

- Define runtime-owned policy snapshot and account authorizer interfaces in `internal/core` (standard library only):
  - `PolicySnapshot` (`ID string`, `Revision int64`, `Enabled bool`, `Models, Connectors []string`, `RPM, TPM int64`) and `PolicyStore` (`Snapshot(context.Context, TrustedPrincipal) (PolicySnapshot, error)`).
  - `AccountAuthorizer` seam in Core (`AuthorizeAccount(ctx context.Context, accountID, connector string) error` or `AccountStore` returning safe account metadata) without importing `internal/storage/sqlite`.
- Establish candidate authorization predicate in Core (`AuthorizeCandidate` / admission check) evaluating:
  - Principal validity: verified `TrustedPrincipal` present in context, active `PolicySnapshot` loaded and enabled, policy revision matches `TrustedPrincipal.PolicyRevision`.
  - Model allowlist: requested/target model is explicitly listed in `PolicySnapshot.Models` (empty list denies all).
  - Connector allowlist: candidate connector instance ID is explicitly listed in `PolicySnapshot.Connectors` (empty list denies all).
  - Account validity: target account exists, is enabled, and belongs to candidate connector.
  - Capability eligibility: candidate adapter and connector are initialized and satisfy all required capabilities (`EligibilityCandidate.Eligible`).
  - Request limits: candidate connector request body and header limits satisfy payload size and original client headers (enforced before dispatch by the existing selected-route validator in gateway ingress; candidate-specific limits for fallback targets integrate in M3-037).
- Predicate is reusable for initial target selection and future retry/fallback candidate evaluation ([M3-037](M3-037.md)), ensuring retries recheck the same immutable policy snapshot and key identity.
- Map authorization rejections to client-safe 403 Forbidden errors (`CategoryPermissionDenied`, code `permission_denied`) before reservation, estimation, or backend execution; denied requests make zero backend/connector calls.
- Purely identity- and descriptor-driven: zero branching on provider names anywhere in Core authorization.
- Explicit limits:
  - Rate limiting (RPM) and token budget reservation (TPM) belong to [M3-021](M3-021.md)–[M3-024](M3-024.md).
  - Durable accounting transaction ledger belongs to [M3-024](M3-024.md)–[M3-028](M3-028.md).
  - Protected YAML configuration loader belongs to [M3-020](M3-020.md).
  - Multi-target fallback ordering and dispatch loop belong to [M3-037](M3-037.md) and [M3-039](M3-039.md).
  - Protected gateway composition belongs to [M3-030](M3-030.md).
  - No semantic contract changes without an accepted ADR in DECISIONS.
