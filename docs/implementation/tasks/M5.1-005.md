## Scope

- Create directory `internal/connector/codex/testdata/auth/` with versioned synthetic JSON fixtures and provenance manifest:
  - `start-success.json`: device authorization start response with `device_code`, `user_code`, `verification_uri`, numeric `interval`, `expires_in`.
  - `start-string-interval.json`: start response with numeric string `interval` (e.g. `"5"`).
  - `start-invalid-interval.json`: start response with invalid/non-positive `interval`.
  - `poll-pending.json`: polling response with `error: "authorization_pending"`.
  - `poll-pending-403.json`, `poll-pending-404.json`: pending response cases for HTTP 403 and 404.
  - `poll-slow-down.json`: polling response with `error: "slow_down"` and increased interval.
  - `poll-authorized.json`: polling response returning authorization code / authorized outcome.
  - `exchange-success.json`: token exchange response with `access_token`, `refresh_token`, `expires_in`.
  - `exchange-no-refresh.json`: token exchange response omitting rotated refresh token.
  - `exchange-terminal-error.json`: terminal token exchange error payload (e.g. `invalid_grant` / `access_denied`).
  - `refresh-success.json`: refresh token exchange response with new `access_token`, rotated `refresh_token`, `expires_in`.
  - `refresh-no-rotation.json`: refresh exchange response omitting rotated refresh token.
  - `refresh-terminal-error.json`: terminal refresh error payload (e.g. `invalid_grant`).
  - `malformed.json`: malformed JSON payload failing unmarshal.
  - `README.md`: provenance manifest with pinned OpenCode v2 / RFC 8628 provenance, SHA-256 table, synthetic classification, and explicit zero usable secrets guarantee.
- Create `internal/connector/codex/fixtures_auth_test.go` establishing the new `codex` package and concrete tests:
  - `TestAuthFixtureIntegrityAndMalformedInput`: verifies SHA-256 hashes against manifest, asserts rejection of `malformed.json`, parses and asserts fields on success/poll/exchange/refresh fixtures, validates string vs integer interval parsing, and checks hash mismatch detection.
- Test-only fixture loader and integrity validation using local files; no provider exchange implementation or live account access.
