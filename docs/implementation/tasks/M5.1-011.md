## Scope

- Implement the authorization code exchange step of `Authenticate(continue)` in `internal/connector/codex`:
  - When `Authenticate` receives `request.Action == "continue"`, detect authorized continuation holding `AuthorizationCode` and `CodeVerifier` (produced by authorized polling in M5.1-010).
  - Verify connector readiness and account scope (`request.AccountID == c.accountID`).
  - Send POST request to `/oauth/token` using invocation-scoped `services.Transport` (default base `https://auth.openai.com`, with loopback test URL override), capped at the binding's 30s response-header deadline.
  - Send URL-encoded form body (`Content-Type: application/x-www-form-urlencoded`):
    - `grant_type=authorization_code`
    - `code=<authorization_code>`
    - `redirect_uri=https://auth.openai.com/deviceauth/callback`
    - `client_id=app_EMoamEEZ73f0CkXaXp7hrann`
    - `code_verifier=<code_verifier>`
  - Refuse redirects fail-closed via `doAuthNoRedirect` (RoundTripper direct execution).
  - Read provider response with bounded limit (64 KiB).
  - Parse provider JSON response (`access_token`, `refresh_token`, `id_token`, `expires_in`, `token_type`).
  - Extract account ID using `accountIDFromTokens(provider.IDToken, provider.AccessToken)`: require non-empty extracted account ID matching `c.accountID`. Reject mismatch as `auth_rejected` or `scope_mismatch`.
  - Validate `expires_in > 0`; calculate absolute expiry in UTC: `time.Now().Add(time.Duration(expiresIn) * time.Second)`.
  - Validate `refresh_token` presence: an initial device authorization code exchange without a refresh token is rejected per M5.1-003 specification.
  - Encode candidate credentials using `encodeOAuthBundle` into `oauthBundle{Version: 1, AccessToken: ..., RefreshToken: ..., AccountID: ..., ExpiresAt: expiresAt}`.
  - Return `core.AuthResult`:
    - `Supported: true`
    - `NextAction: ""` (cleared)
    - `State: ""` (cleared)
    - `UserAction: nil`
    - `Credentials: map[string][]byte{"oauth": encodedBundle}`
    - `CredentialExpiresAt: &expiresAt`
  - Fail closed with sanitized `*core.GatewayError` on HTTP non-200, malformed JSON, oversized response, missing required tokens, missing or mismatched account ID, missing refresh token, non-positive expires_in, transport error, or caller context cancellation; clear all continuation/secret state.
  - Never format or leak code, verifier, or token secrets into error messages, user-action output, or logs.
  - No automatic exchange replay follows an uncertain response.
- Implement comprehensive unit tests in `internal/connector/codex/auth_test.go`:
  - Primary check `TestDeviceAuthCodeExchange`: verify code exchange against mock HTTP server with URL-encoded form parameters, header validation, token parsing, account ID validation, DEC-010 expiry, and returned candidate credential bundle.
  - Negative cases: HTTP error responses (`exchange-terminal-error.json`), missing refresh token (`exchange-no-refresh.json`), malformed response (`malformed.json`), oversized body, missing account ID in token JWT claims, account ID mismatch against configured connector target, redirect refusal, unready connector state, mismatched request account ID, and caller context cancellation.
  - Secret sanitization tests: assert errors do not contain code, verifier, or token bytes.
- Explicit limits:
  - Do NOT persist credentials or session state to SQLite (belongs to M5.1-013).
  - Do NOT implement refresh token exchange (belongs to M5.1-012).
  - Do NOT wire coordinator or operator CLI commands (belongs to M5.1-014/015).
  - Local mock server only; no live provider network calls.
