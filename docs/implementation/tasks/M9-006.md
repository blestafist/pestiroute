# M9-006 — Add explicit YAML capability declarations for native Chat connector

## Outcome

Add explicit, optional capability declarations to the protected YAML configuration for `pestiroute.chat-completions.native` and align `M9-BINDING.md`. This enables protected startup and CLI procedures to declare reviewed capabilities (`llm.streaming`, `llm.tools`, `llm.tools.parallel`, `llm.structured_output`) without Core eligibility denials, unblocking [M9-005](M9-005.md) offline CLI smoke and handoff. See [registry](../TASKS.md#m9--chat-completions-client-compatibility) and [milestone](../M9-CHAT-COMPLETIONS.md).

## Scope

- Update [M9-BINDING.md](../M9-BINDING.md):
  - Extend the protected YAML connector settings allowlist for `pestiroute.chat-completions.native` to include optional `capabilities: map[string]string`.
  - Specify that keys must be non-empty strings and values must be strictly one of `supported`, `unsupported`, or `unknown`.
  - Document that undeclared capabilities remain `unknown`, and that `supported` declarations allow operators/fixtures to declare reviewed capabilities (`llm.streaming`, `llm.tools`, `llm.tools.parallel`, `llm.structured_output`).
- Implementation files (owned by M9-006 executor):
  - `cmd/gateway/yaml_config.go`: admit `capabilities` in `allowed` settings keys for `pestiroute.chat-completions.native`; permit non-empty `Capabilities` map; validate that map keys are non-empty and states are one of `supported`, `unsupported`, `unknown`.
  - `cmd/gateway/protected_startup.go`: map `component.Capabilities = s.Capabilities` for `case chatImplementation:`.
  - Tests in `cmd/gateway/chat_protected_test.go` (or dedicated test) proving protected YAML loading with explicit capabilities, correct propagation to connector, and pre-dispatch admission/rejection based on declared capabilities.
- Semantic contract assessment: No ADR is required because `CONTRACT.md` and `internal/core` interfaces are unchanged; the capability model (`core.Capability`, `core.CapabilityResult`) already defines scoped declarations, and this task additively aligns the Chat connector YAML settings and startup binding with the existing capability model (matching the pattern used by `pestiroute.responses.local` in M5.2).
- Shared file ownership: M9 holds named exclusive sequencing ownership for shared gateway files (`cmd/gateway/main.go`, `cmd/gateway/yaml_config.go`, `cmd/gateway/protected_startup.go`, and test files in `cmd/gateway`). No changes to Responses or Claude connector paths.
