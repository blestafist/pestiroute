## Scope

- Implement an in-process HTTP fake upstream test fixture in `internal/testutil/fakeupstream`:
  - Request inspection: capture received request method, path, query, headers, and raw body bytes (preserving arbitrary JSON and unknown fields).
  - Configurable response handling:
    - Fixed status, headers, and body bytes (e.g. JSON responses or errors).
    - Incremental SSE (`text/event-stream`) streaming with deterministic synchronization gates (channel-based triggers or step controls) to allow test assertions before stream completion.
    - Simulated connection failures (e.g. abrupt connection closure/hijack mid-stream).
    - Client cancellation observation: channel or callback signaling when the client context disconnects (`r.Context().Done()`).
- Provide package tests in `internal/testutil/fakeupstream` verifying all fixture behaviors (capture, gated SSE, connection breaks, cancellation notification) deterministically without sleep timings.
- Limits: no gateway proxy or routing implementation (M1), no CI workflow setup (FND-004), no live provider network calls, and no provider credentials.

## Acceptance

- [x] Fake upstream starts on a local loopback listener and shuts down cleanly without leaking resources or goroutines.
- [x] Captures incoming HTTP request method, path, headers, and raw body bytes byte-for-byte, preserving arbitrary JSON structures and whitespace.
- [x] Streams incremental chunked/SSE responses with explicit synchronization gates allowing assertions on intermediate delivery before upstream response completion.
- [x] Simulates connection drops/aborts before or during response streaming.
- [x] Observes and notifies test harness of client-side context cancellation / disconnect.
- [x] Local package tests verify these behaviors deterministically without external credentials or network access.
