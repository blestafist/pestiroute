# M8-004 — Map multi-round function-call and result history in synthetic Claude execution

## Outcome

Translates Responses multi-round function-call and result history into Anthropic Messages
`tool_use` and `tool_result` content blocks under the package-private offline fake transport
(`api.anthropic.invalid`, `synthetic-beta`). Extends the synthetic execution slice to support
agentic tool loops without expanding public contracts, Core abstractions, or live access.
See [registry](../TASKS.md#m8--claude-code-execution-and-gateway-integration) and
[milestone plan](../M8-CLAUDE-INTEGRATION.md#delivery-sequence).

## Scope

- Within `internal/connector/claudecode/translate.go`, extend input translation for Responses history:
  - Map Responses `function_call` input item to Messages `role: "assistant"` with `type: "tool_use"`
    block preserving `id` (as `call_id`), `name`, and JSON arguments.
  - Map Responses `function_call_output` input item to Messages `role: "user"` with `type: "tool_result"`
    block matching `tool_use_id` (from `call_id`) and output text content.
  - Support consecutive/parallel `function_call` items in a single assistant turn and consecutive
    `function_call_output` items in the subsequent user turn.
  - Enforce chronology: reject orphan `function_call_output`, duplicate outputs for the same `call_id`,
    interleaved messages while tool calls remain pending, or unresolved pending calls when non-tool items appear.
  - Fail closed pre-dispatch (`unsupported_feature`) on unsupported agent semantics (e.g. Responses
    `reasoning` items, unrecognized input types, malformed JSON, or missing required IDs).
- Add deterministic unit and public `Execute` tests in `internal/connector/claudecode/translate_test.go`
  and `execute_test.go` using the package-private offline fake transport (`api.anthropic.invalid`, `synthetic-beta`).
- Limits: No changes to Core runtime, `core.Connector` interface, or public contracts. No changes to
  gateway composition or default fail-closed rejection. No live/network dispatch, no real credentials,
  and capabilities remain `Unknown`.

## Acceptance

- [x] Responses input history containing `function_call` translates to Messages `role: "assistant"` with `tool_use` content blocks preserving `id`, `name`, and parsed JSON arguments.
- [x] Responses input history containing `function_call_output` translates to Messages `role: "user"` with `tool_result` content blocks matching `tool_use_id` and string output content.
- [x] Parallel tool calls (consecutive `function_call` items in an assistant turn) and corresponding `function_call_output` items preserve ordering and group into valid Messages turns.
- [x] Chronology violations (orphan outputs, duplicate results for a single call, interleaved messages before pending outputs resolve, or dangling tool calls) fail pre-dispatch with `unsupported_feature` and zero dispatch.
- [x] Unsupported agent semantics (e.g. `type: "reasoning"`, `custom_tool_call`, unknown fields) fail pre-dispatch with `unsupported_feature`.
- [x] Public `Execute` dispatches multi-round history requests to the offline fake transport (`api.anthropic.invalid`, `synthetic-beta`) and parses the resulting stream successfully.
- [x] Descriptor capabilities remain `Unknown` and gateway composition continues to reject the connector.
