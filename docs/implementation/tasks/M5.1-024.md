## Scope

- Classify HTTP non-2xx status codes (400/422 `CategoryInvalidRequest`, 401 `CategoryUnauthenticated`, 403 `CategoryPermissionDenied`, 429 `CategoryRateLimited`, 5xx `CategoryUnavailable`) into bounded, sanitized `GatewayError` metadata before Head, emitting client-visible error body bytes in `BodyFrame` and ending with `Complete(failed)` without internal retries.
- Extend `sseObserver` / `executeStream` in `internal/connector/codex` (`sse.go`, `execute.go`) to observe terminal events on 2xx SSE streams:
  - `response.completed` with `status: "completed"` -> `core.OutcomeSucceeded` (nil `GatewayError`).
  - `response.failed` or `error` -> `core.OutcomeFailed` with sanitized, bounded `GatewayError`.
  - `response.incomplete` -> `core.OutcomeIncomplete` with sanitized `GatewayError`.
  - Unterminated stream / EOF without valid terminal event -> `core.OutcomeIncomplete` with `GatewayError`.
  - Trailing data after terminal event or malformed terminal JSON -> sticky `core.OutcomeIncomplete` with `GatewayError`.
- Ensure exactly one orderly `CompleteFrame` followed by EOF, without altering caller-visible body bytes.
- Explicit non-scope: token usage extraction belongs to M5.1-025; usage estimation and route budget binding belong to M5.1-026; route composition belongs to M5.1-027.

## Acceptance

- [x] HTTP non-2xx responses emit classified `HeadFrame` with sanitized `GatewayError`, pass through bounded raw error body bytes, and terminate with `Complete(OutcomeFailed)` without internal inference retries, account rotation, or token refresh-and-replay.
- [x] SSE `response.completed` with `status == "completed"` transitions stream to `Complete(OutcomeSucceeded)` with nil error; unterminated EOF, truncated stream, or idle timeout terminates with `Complete(OutcomeIncomplete)`.
- [x] SSE `response.failed` or `error` yields `Complete(OutcomeFailed)` with sanitized, bounded `GatewayError`; `response.incomplete` yields `Complete(OutcomeIncomplete)`.
- [x] Trailing SSE data after a terminal event or malformed/conflicting terminal payload fails closed to sticky `Complete(OutcomeIncomplete)`.
- [x] Exactly one `CompleteFrame` is emitted per stream before `io.EOF`; original raw SSE bytes in `BodyFrame` are preserved verbatim.
