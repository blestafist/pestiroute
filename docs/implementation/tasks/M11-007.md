## Open Questions / Blocker

Resolved: the task card's prior startup names were erroneous. Normative
[`CONFIGURATION.md`](../CONFIGURATION.md#administrative-http-listener) lines
102–113 specify `admin.listen`, token source, allowlists, timeouts/size, and flat
TLS fields. `cmd/gateway/yaml_config.go:33-44` implements those fields; its
strict-key list at `cmd/gateway/main.go:368-372` rejects unknown admin keys.
`M11-BINDING.md:8-21` sets listener security but does not specify config key
spellings. The mismatch was between the prepared card (`admin.enabled`,
`admin.bind`, nested `admin.tls.*`) and the existing normative configuration,
not a missing product decision. No semantic contract change or ADR is needed.
There are no admin listener CLI flags; the optional `admin` object itself is the
opt-in.
