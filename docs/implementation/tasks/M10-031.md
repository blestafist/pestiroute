# M10-031 — Implement secret-safe runtime --debug inference diagnostics and bounded runner extraction

## Outcome

Add minimal, secret-safe DEBUG diagnostic telemetry to Antigravity execution via existing `InvocationServices.Logger`, provide a runtime `--debug` gateway CLI flag, and safely extract structured diagnostic fields in the smoke runner before log deletion, without leaking raw payload bytes, provider tokens, or URLs, and without altering core contract boundaries or expanding model scope. See [TASKS.md](../TASKS.md#m10--google-antigravity-connector) and [ROADMAP.md](../ROADMAP.md#phase-4--provider-expansion).

## Scope

- In `cmd/gateway/main.go`:
  - Add `--debug` flag to `loadConfig`, configuring `c.logger = slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{Level: slog.LevelDebug}))` when enabled, preserving default silence (nil or LevelInfo).
- In `internal/connector/antigravity/execute.go`:
  - Emit structured `Debug` log through existing `services.Logger` when non-nil on transport errors, non-200 HTTP status, and malformed responses.
  - Telemetry schema strictly restricted to:
    - `status`: integer HTTP status (or 0 for transport failure)
    - `branch`: fixed enum (`"http_error"`, `"transport_error"`, `"invalid_response"`)
    - `upstream_status`: allowlisted upstream error status enum (`"UNAUTHENTICATED"`, `"PERMISSION_DENIED"`, `"RESOURCE_EXHAUSTED"`, `"INVALID_ARGUMENT"`, `"other"`, or `"none"`)
    - `transport_error_class`: bounded transport error class (`"timeout"`, `"connection_refused"`, `"dns"`, `"eof"`, `"tls"`, `"other"`, or `"none"`)
  - Strictly no raw body, prompt text, user/assistant messages, tokens, URLs, request IDs, or project strings.
  - Preserve 8 KiB body read bound (`io.LimitReader(resp.Body, 8192)`).
- In `scripts/antigravity-live-smoke.sh` and `scripts/antigravity_smoke_response.py`:
  - Launch gateway with `--debug` flag in runner.
  - Parse and extract only known allowlisted diagnostic fields from `gateway.log` before directory removal / log cleanup. No full log dump.
- Tests:
  - Offline unit and race tests in `internal/connector/antigravity` and `cmd/gateway`.
  - Validate `--debug=false` silence vs `--debug=true` fixed emission.
  - Zero-leak assertion: malicious canary in response bodies, error messages, and transport errors is absent from logs.
  - Python runner fixture tests covering structured extraction.
- Limits:
  - No public Core provider API changes; uses existing `core.InvocationServices.Logger`.
  - No changes to HTTP dispatch budget reservation, atomic accounting, retry disposition, attempt finalization, or Responses envelope formatting.
  - Model scope remains `gemini-2.5-pro` and `gemini-2.5-flash`; potential model staleness from 9router `87a74e1` noted for future decision, not expanded here.
  - Zero live calls in this task.
