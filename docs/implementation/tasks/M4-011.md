# M4-011 — Parse bounded Messages SSE events across byte splits

## Outcome

Parse bounded Messages SSE events across byte splits. One bounded deliverable in the [M4 registry](../TASKS.md#m4--first-translation-connector)
toward the original [M4](../ROADMAP.md#m4--first-translation-connector).

## Read First

- [Stream/resource policy](../M4-TRANSLATION.md#stream-completion-and-resource-policy).
- [Accepted stream and lifecycle binding](../M4-BINDING.md#stream-and-lifecycle-binding) (1 MiB line/event limit, 64 content blocks).
- Streaming fixtures in `internal/connector/anthropic/testdata/stream-*.sse`.
- Reference implementation in `internal/connector/responses/sse.go` for proven bounds/cancellation patterns.

## Scope

- Implement a Connector-private incremental SSE reader in `internal/connector/anthropic` handling LF, CRLF, comments/pings, multiline `data:` fields, UTF-8, and arbitrary read buffer boundaries.
- Enforce the binding's line and event limits (1 MiB ceiling per line and event), terminating oversized inputs boundedly with a size error.
- Recognize selected Anthropic Messages lifecycle/delta event types: `message_start`, `content_block_start`, `content_block_delta`, `content_block_stop`, `message_delta`, `message_stop`, `ping`, `error`. Document harmless unknown-event treatment (ignoring ping/harmless notifications without error) versus unsupported semantic content.
- Do not translate events to Responses format (deferred to M4-012/M4-013), create a universal SSE API, or buffer the entire stream.

## Acceptance

- [x] Selected fixtures (`stream-normal.sse`, `stream-max-tokens.sse`, `stream-error.sse`, `stream-premature-eof.sse`) parse at every single-byte split and across arbitrary multi-byte read chunks, preserving event sequence, event types, and data payloads.
- [x] Incremental parser correctly handles LF, CRLF, leading field space stripping, comments (`: ...`), pings, multiline `data:` lines joined by single newlines, and multi-byte UTF-8 sequences split across chunk boundaries without loss or corruption.
- [x] Bounded line and event limits: lines and events up to the 1 MiB binding ceiling parse successfully (exceeding `bufio.Scanner` default 64 KiB), while lines or events exceeding 1 MiB terminate boundedly with an explicit error without unbounded memory allocation.
- [x] Truncated streams, premature EOF before block/message closure, malformed framing, oversized events, and context cancellation terminate boundedly without hanging, fabricated terminal success, or unbounded queues.
