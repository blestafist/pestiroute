## Outcome

Shutdown stops admission, drains within its deadline and cancels remaining upstream work. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Scope

- Test one request that drains and one that remains gated past shutdown deadline; close pooled resources and partial initialization.
- Stop before hot reload, process supervisors or deployment packaging.

## Acceptance

- [ ] Expired drain cancels active upstream work and terminates within a bounded margin using the documented exit/error behavior.
- [ ] Component/stream Close is idempotent; startup failure does not leave serving or transport resources alive.
