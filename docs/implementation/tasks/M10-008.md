## Scope

- In `internal/connector/antigravity`:
  - Extend `Execute` credential parsing in `execute.go` to accept optional `refresh_token` string alongside `access_token` in the single `oauth` JSON object; strictly reject unknown fields, empty tokens, duplicate keys, malformed JSON; project only `access_token` into outbound Authorization header.
  - Implement `Connector.Authenticate` in `auth.go` for `Action="refresh"`: validate `refresh_token` from input `oauth` credential; execute at most one POST via injected fake transport to synthetic `.invalid` endpoint; parse `access_token`, `expires_in`, optional `refresh_token`; return single replacement candidate `oauth` bundle and explicit non-zero `CredentialExpiresAt`.
  - Add synthetic refresh fixtures and update `manifest.json` under `internal/connector/antigravity/testdata/`.
  - Add deterministic unit/race tests in `auth_test.go`, `auth_coordinator_test.go`, and `execute_test.go`.
- In `cmd/gateway/auth_store_test.go` (user-granted serialized gateway test window):
  - Add an end-to-end integration test verifying Antigravity connector with `newSQLiteAuthCoordinatorStore`, proving real encrypted SQLite credential replacement, atomic generation CAS with `CredentialExpiresAt`, and decrypted reload into `Execute`.
- Explicit limits:
  - No live network requests or real Google OAuth endpoints/credentials.
  - No authorization-code browser flow (waiting on user-provided browser auth).
  - No changes to production `cmd/gateway` code during this test window.
  - No tool calling implementation.
