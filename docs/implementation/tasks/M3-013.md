# M3-013 — Validate and persist key policies

## Outcome

Implement a persistent key policy repository in SQLite storage providing policy creation, immutable revision history, optimistic CAS updates, exact model and connector allowlist validation, safe non-negative RPM/TPM limits, defensive snapshot copying, and PolicyStore runtime integration. ## Scope

- Implement pure Go SQLite key policy repository in `internal/storage/sqlite` (`policies.go` and `policies_test.go`), keeping SQL persistence outside Core.
- Model entities matching schema v3 and runtime contracts:
  - `KeyPolicy`: `ID string`, `Revision int64`, `Enabled bool`, `Models []string`, `Connectors []string`, `RPM int64`, `TPM int64`, `CreatedAt time.Time`.
  - `PolicySnapshot`: matching `M3-RUNTIME.md` (`ID string`, `Revision int64`, `Enabled bool`, `Models, Connectors []string`, `RPM, TPM int64`).
  - `CreateKeyPolicyParams`: `ID string` (optional; generated random opaque ID if empty), `Enabled bool` (defaults to true if unspecified), `Models []string`, `Connectors []string`, `RPM int64`, `TPM int64`.
  - `UpdateKeyPolicyParams`: `Enabled bool`, `Models []string`, `Connectors []string`, `RPM int64`, `TPM int64`.
  - `KeyPolicyFilter`: `Enabled *bool`.
- Implement `KeyPolicies` repository operations on `*sql.DB` opened with `sqlite.Open`:
  - `Create(ctx context.Context, params CreateKeyPolicyParams) (KeyPolicy, error)`: validates ID, limits (`RPM >= 0`, `TPM >= 0`), and exact model/connector lists (rejecting empty or whitespace-only elements). Serializes models and connectors as JSON arrays. Inserts row with initial `revision = 1` and UTC Unix-millisecond `created_at`. Returns defensively cloned `KeyPolicy`.
  - `Get(ctx context.Context, id string, revision int64) (KeyPolicy, error)`: queries exact immutable `(id, revision)`; returns typed `ErrKeyPolicyNotFound` if absent. Clones slice fields.
  - `GetLatest(ctx context.Context, id string) (KeyPolicy, error)`: queries highest revision for policy ID (`ORDER BY revision DESC LIMIT 1`).
  - `Snapshot(ctx context.Context, principal TrustedPrincipal) (PolicySnapshot, error)`: queries exact `(principal.PolicyID, principal.PolicyRevision)` matching `PolicyStore` interface from `M3-RUNTIME.md`; returns typed `ErrKeyPolicyNotFound` if absent. Clones slice fields.
  - `Update(ctx context.Context, id string, expectedRevision int64, params UpdateKeyPolicyParams) (KeyPolicy, error)`: validates params, acquires `BEGIN IMMEDIATE`, verifies latest revision matches `expectedRevision`, and inserts a new immutable row with `revision = expectedRevision + 1`. Fails with `ErrKeyPolicyRevisionMismatch` on stale or concurrent revision. Does not mutate or overwrite historical revisions.
  - `List(ctx context.Context, filter KeyPolicyFilter) ([]KeyPolicy, error)`: lists latest revision of each policy matching filter, ordered deterministically (`id ASC`).
- Ensure slice immutability: defensively copy `Models` and `Connectors` slices on both ingress (creation/update) and egress (get/snapshot/list) so callers cannot alter stored or returned state.
- Empty allowlist behavior: empty `models` or `connectors` slices (`[]`) are preserved verbatim as empty allowlists (fail closed / deny all) and never broadened to implicit wildcards.
- Explicit limits:
  - Route-owned estimate budget (`RouteBudget`: `UnknownEstimate`, `ConservativeTokens`) belongs to route configuration per M3-004 / M3-CONFIG.md, not the key policy table.
  - CLI management commands (`pestictl policy create/update/list`) belong to [M3-016](M3-016.md).
  - Virtual key lifecycle belongs to [M3-012](M3-012.md).
  - Runtime request authorization and admission enforcement belong to [M3-018](M3-018.md) and [M3-019](M3-019.md).
  - Core remains standard-library only and does not import `internal/storage/sqlite`.

## Acceptance

- [x] Policy creation validates non-negative `rpm` and `tpm`, non-empty identifiers, serializes `models` and `connectors` as JSON arrays, assigns initial `revision = 1` and integer UTC Unix-millisecond `created_at`, and rejects negative limits or malformed lists with typed errors.
- [x] Empty allowlists (`models: []`, `connectors: []`) are stored as `'[]'` and returned as empty slices, never defaulted to wildcards or expanding access permissions.
- [x] Concurrent updates enforce optimistic revision checks (`expectedRevision`), create a new immutable `(id, expectedRevision + 1)` row under `BEGIN IMMEDIATE`, and reject stale or concurrent revisions with `ErrKeyPolicyRevisionMismatch`.
- [x] Historical policy revisions are immutable: updating a policy adds a new revision without modifying or deleting earlier revision rows.
- [x] `Snapshot` and `Get` return defensive clones of `Models` and `Connectors`; mutating returned slices has zero effect on subsequent queries or stored policies.
- [x] Foreign key integrity: a virtual key referencing `(policy_id, policy_revision)` successfully links to any valid policy revision, and deletion of referenced policy rows is restricted by `ON DELETE RESTRICT`.
- [x] All persisted policies, revisions, and metadata survive `db.Close()` and reopen with `sqlite.Open`.
