## Scope

- Add assembled-path isolation regressions in `cmd/gateway` for spoofed headers, two account configurations, policy restrictions, and safe cache affinity.
- Assembled two-account isolation is proven using the gateway composition root (`composeHandlerWithFactory`) with distinct persistent credential record IDs (e.g. `codex-cred-1`, `codex-cred-2`) mapped to the logical credential name `oauth` via existing runtime mechanisms (`configuredCredentialRefs` and `internal/core/persistent_services.go`); no protected YAML schema expansion or SQLite schema migration is required.
- Verify virtual keys and inbound client account/session/auth headers never reach the upstream provider or override the runtime identity.
- Verify disabled, revoked, or out-of-scope requests make zero upstream provider sends; failure under one account cannot expose another account's credential.
- Verify cache affinity (`prompt_cache_key`) is scoped according to the binding and does not imply backend resource ownership across accounts.
- Verify logs, diagnostics, and error responses contain no secret tokens or credential values.
- Explicit limits: Cancellation/bounded backpressure belongs to M5.1-033; delivery-safe retry and replay affinity belong to M5.1-034; durable recovery and settlement belong to M5.1-035.
