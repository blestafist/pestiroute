# M2-008 — Wrap the native Connector lifecycle and support operations

## Outcome

The existing native Responses transport is discoverable as a common `core.Connector` component with honest scoped support and bounded support operations. See [registry](../TASKS.md#m2--connector-api-and-conformance-baseline) and [M2](../ROADMAP.md#m2--connector-api-and-conformance-baseline).

- `internal/connector/responses/transport.go`, `cmd/gateway/main.go` `dispatchCapabilities`, and [M1 declaration limits](../M1-BINDING.md#startup-and-eligibility).

## Scope

- In `internal/connector/responses`, add a connector wrapper implementing `core.Connector` (`Descriptor`, `Init`, `Health`, `Capabilities`, `Close`, `Models`, `EstimateUsage`, `Authenticate`, and `Execute`).
- `Descriptor` declares `ComponentConnector`, API version 1.0, protocol `openai.responses.v1`, operations (`execute`, `models`, `estimate_usage`, `authenticate`), connector type `api`, and auth methods (`bearer`).
- `Init` validates configuration; failed Init cleans up any allocated resources; `Close` is idempotent and closes underlying transport connections.
- `Capabilities` evaluates exact scope (`openai.responses.v1`, `native`, target model/account): returns `llm.streaming`, `llm.tools`, `llm.reasoning` as `Supported` for the verified baseline target (`gpt-5.4-mini`) and verified fixtures; keeps `llm.tools.parallel` as `Unknown`. Non-matching protocols, modes, or unknown accounts/models evaluate to `Unknown`.
- `Models` returns static identity-mapped model information without network/inference side effects.
- `EstimateUsage` reports `Supported: false` (or `Known: false`), never fabricating zero usage.
- `Authenticate` reports `Supported: false` (runtime bearer credentials are used; state-machine auth is not supported).
- Keep Execute invocation migration behind `InvocationServices` for M2-009; `Execute` in M2-008 can delegate to existing transport execution or report an explicit error if invoked directly before M2-009 wiring.
- Do not add SQLite, remote auth, model rewriting, or broaden live capabilities beyond verified M1 evidence.

## Acceptance

- [x] `Descriptor()` reports required connector metadata, exact API versions, and protocols with no network/inference side effects.
- [x] `Init()` validates configuration and leaves component ready; failed `Init()` allocates no transport; `Close()` is idempotent.
- [x] `Capabilities()` for verified baseline (`gpt-5.4-mini` / verified target) returns `llm.streaming: Supported`, `llm.tools: Supported`, `llm.reasoning: Supported`, and `llm.tools.parallel: Unknown`; unverified models/accounts/protocols return `Unknown`.
- [x] `Models()` returns static identity-mapped metadata; `EstimateUsage()` reports unknown/unsupported usage (never zero); `Authenticate()` reports unsupported.
