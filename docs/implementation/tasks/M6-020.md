# M6-020 — Enforce aggregate backpressure and control progress

## Outcome

Implement an explicit host-owned epoch credit broker enforcing aggregate per-invocation (64 frames / 4 MiB) and process-wide (256 frames / 16 MiB) transport limits across both directions and both gRPC sockets (Execute and HostServices HTTP), with reserve-before-produce semantics, consumption acks, and an independent prioritized cancel/close control lane (64 messages / 256 KiB). See [registry](../TASKS.md#m6--external-plugin-runtime) and [milestone](../ROADMAP.md#m6--external-plugin-runtime).

## Architecture & DEC-017 Specification Synchronization

### Decision (DEC-017): Explicit Host-Owned Epoch Credit Broker
1. **Diagnosis**: Independent test `ses_ec3d213aeffeNGJPeY5GI21XJm` confirmed that unconstrained gRPC socket/HTTP-2 buffering allows probes of 257 x 64 KiB `Send` to complete with no `Recv`. Socket window tuning alone cannot enforce cross-socket ceilings.
2. **Broker Architecture**:
   - Host owns the centralized `CreditBroker` bound to the active process epoch.
   - Aggregate limits: at most 64 frames / 4 MiB per invocation; at most 256 frames / 16 MiB process-wide across at most 4 concurrent invocations.
   - Covers BOTH directions (Host → Child and Child → Host) across BOTH sockets (`Connector.Execute` and `HostServices.HTTPDo`).
3. **Reservation & Accounting Lifecycle**:
   - Senders MUST reserve credits `(frames, bytes)` from the broker BEFORE producing or enqueuing a data frame.
   - Counted as occupied once while queued, in-flight, or held by the receiver.
   - Released strictly on consumption ACK:
     - Body frames: when receiver completes delivery (`Next()` returns to caller; HTTP reader finishes chunk).
     - Record fragments: when validated assembler incorporates fragment into typed message (assembler itself excluded from queue count).
4. **Identity & Ordering**:
   - Every control message carries `(epoch, invocation_id, call_id, direction, monotonic_seq)`.
   - Stale epoch, replayed sequence, or unreserved frames fail closed.
5. **Separate Transport Control Lane**:
   - Independent bidirectional control channel/RPC on the IPC connection.
   - Handles `Reserve`, `Grant`, `Ack` (with coalesced ACKs) and prioritized `Cancel`/`Close`.
   - Capped at 64 messages / 256 KiB process-wide; never blocked by data queues.
   - Internal to connector IPC; zero Core or provider API exposure.

## Scope

- Implement `CreditBroker` and transport control integration in `internal/connector/external/`:
  - Credit tracking per invocation and process-wide with atomic reserve, grant, and ack.
  - Gated sender pumps for Execute responses and reverse HTTP streams.
  - Prioritized cancel/close lane that drains control signals immediately under saturation.
- Test suite in `internal/connector/external/`:
  - Reusable test fixtures and child harnesses for backpressure and control verification.
- Limits: Full native Responses child composition belongs to M6-024. Process crash isolation belongs to M6-021. Supervisor restart belongs to M6-022.

## Acceptance

- [x] Sender reserves credit before producing/enqueuing data frames; Send blocks when the 64-frame or 4-MiB per-invocation credit is exhausted.
- [x] Process-wide ceiling of 256 frames / 16 MiB across 4 invocations is enforced; excess invocations or frames block until consumption ACKs replenish credits.
- [x] Both directions and both sockets (Execute output from child and HTTPDo response/body from host) consume from the unified invocation credit pool.
- [x] Frame-count ceiling blocks producers on tiny frames (e.g. 64 x 100 B frames) even when byte limits are not reached.
- [x] Large gRPC window configurations cannot bypass backpressure: Send blocks on credit broker exhaustion regardless of transport socket buffer depth.
- [x] Stale epoch, replayed sequence numbers, or unreserved frames are rejected with classified IPC errors.
- [x] Prioritized cancel and stream `Close()` proceed unblocked under full queue saturation, revoke reservations, and release held credits with zero goroutine leaks.
- [x] All tests pass under `-race` with zero data races.
