# M2-009 — Move native Execute behind scoped Connector services

## Outcome

One common native Execute owns its backend attempt without composition-root provider logic. See [registry](../TASKS.md#m2--connector-api-and-conformance-baseline) and [M2](../ROADMAP.md#m2--connector-api-and-conformance-baseline).

## Read First

- [Execute and ownership](../CONTRACT.md#connector-contract), [native bytes](../../project/ARCHITECTURE.md#native-passthrough-and-model-mapping), and [Invocation services](../M2-BINDING.md#component-api).
- `internal/connector/responses/{component,transport,fixed,sse}.go`, `internal/core/{connector,services}.go`, `cmd/gateway/main.go` fixedTarget.

## Scope

- In `internal/connector/responses`, implement common `Connector.Execute` consuming `core.InvocationServices` (`Credentials`, optional `Transport`, and redacting `Logger`) and validating `core.AttemptScope`.
- Move credential resolution from static connector configuration to attempt-scoped `InvocationServices.Credentials.Get(ctx, "bearer")`.
- Select fixed JSON or SSE streaming execution inside `Connector.Execute` based on request streaming metadata without composition-root branching.
- Validate protocol (`openai.responses.v1`), mode (`native`), and matching model/account scope before attempting upstream execution, returning explicit `core.GatewayError` on mismatch.
- Support optional `InvocationServices.Transport` (`core.HTTPDoer`) while preserving connector transport defaults, timeouts, redirect refusal, and connection pooling.
- Retain existing byte observation, incremental streaming, bounded backpressure, cancellation, timeout handling, and single-attempt non-replay guarantees.
- Do not modify provider error semantics, add account fallback, or implement translation.

## Acceptance

- [x] `Connector.Execute` rejects unready connector state, unsupported protocol, non-native mode, or mismatched model/account with an explicit `core.GatewayError` before issuing any HTTP request.
- [x] Execute performs at most one upstream request using the credential resolved from `InvocationServices.Credentials`, and routes through `InvocationServices.Transport` when supplied.
- [x] Missing or failing attempt credentials return a clear `gatewayError` without leaking secret values or attempting network calls.
- [x] Both fixed JSON and streaming SSE modes preserve exact M1 payload bytes, SSE event structure, and error categories; cancellation and partial stream close cleanly release upstream resources.
- [x] Transport retries and HTTP redirects remain disabled; credential values are not exposed in error messages or logs.
