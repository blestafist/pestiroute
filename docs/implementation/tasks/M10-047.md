## Scope

- Usage rejection classification:
  - Instrument `parseUsageMetadata` and error logging in `internal/connector/antigravity/` to capture safe diagnostic metadata when usage rejection occurs (`errInvalidUsage`).
  - Fixed safe `subkind` enum: `invalid_json`, `non_object`, `unknown_field`, `invalid_type`, `negative_range`.
  - For `unknown_field`, classify unrecognized keys against an allowlisted enum of candidate names: `candidates_tokens_details`, `prompt_tokens_details`, `thoughts_token_count`, `cached_content_token_count`, `cache_token_count`, `other`. Never emit raw or unvetted key strings.
  - Deterministic priority when multiple rejection causes coincide (e.g. non-object > unknown field > invalid type > negative range).
- Telemetry & Logging:
  - Emit classified enums via safe `s.logger.Debug` telemetry in `logStreamError` for `category=precommit_invalid_usage` and postcommit usage failures.
  - Zero numeric token values, payload bodies, or private credentials logged or persisted.
- Preserved invariants:
  - Strict rejection unchanged: unknown fields or malformed usage must still fail closed with `errInvalidUsage`. No allowlist expansion or semantic ADR in this task.
  - Core prompt/output accounting remains untouched.
  - File ownership isolation: changes confined to `internal/connector/antigravity/stream.go` and connector tests/helpers. Frozen M10-046 runner/test files (`scripts/antigravity-live-smoke.sh`, `scripts/test_antigravity_live_smoke.py`, `cmd/gateway/antigravity_operator_metadata_test.go`) must not be touched.
- Non-scope:
  - Purely offline; strictly zero live provider requests in this task.
