# FND-001 — Reproducible Go scaffold

## Outcome

A clean checkout has one buildable Go module and a minimal `gateway` entrypoint, providing the prerequisite for the [M0 foundation](../ROADMAP.md#m0--project-foundation). See the [registry row](../TASKS.md#m0--foundation).

- [Official Go downloads](https://go.dev/dl/) for the selected Go 1.27.1 toolchain; the module path is `github.com/blestafist/pestiroute`.

## Scope

- Add root `go.mod` with module `github.com/blestafist/pestiroute`, `go 1.27`, and `toolchain go1.27.1`. Use only the standard library at this stage; do not create a dependency solely to exercise the scaffold.
- Add one buildable `cmd/gateway` main package. Make its current startup behavior explicit: until FND-002 there is no configured serving mode or claim that inference is ready. A small informative exit is sufficient.
- Create the currently absent root `README.md` with the prerequisite Go version, exact clean-checkout build command, and observed scaffold startup behavior. Keep output artifacts out of the tracked tree; use a build command that produces no local binary.
- Leave configuration parsing, health/readiness, HTTP listeners, fake upstream, routing, CI, and container packaging to their registered tasks. No framework or package skeleton for future components.

## Acceptance

- [ ] The module path and both Go version directives match the selections above; the documented command works with Go 1.27.1 and dependency fetching disabled.
- [ ] `cmd/gateway` is a valid main package, and `GOTOOLCHAIN=local go build ./...` succeeds on a clean checkout.
- [ ] Invoking the entrypoint before FND-002 does not silently claim that a configured service is running. Its documented behavior matches observation.
- [ ] The README distinguishes the scaffold build from a working server, and the change has no added application dependencies or generated binary.

## Verification

From the repository root, with Go 1.27.1 installed: run `go version`, `GOTOOLCHAIN=local go list -m`, `GOTOOLCHAIN=local go list ./cmd/gateway`, and `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go build ./...`. Compare the version/module output with this card; build must exit 0. Run `GOTOOLCHAIN=local go run ./cmd/gateway` and compare its exit status and text with the documented pre-FND-002 behavior. Run `git diff --check` and `git status --short` to check whitespace and untracked output. Repeat the offline build from a fresh checkout or a clean worktree; no provider credentials should be needed. The build is a task-established check, not an already verified command in CURRENT.
