## Scope

- Implement Connector-private credential encoding/decoding and bounded trusted-exchange JWT claim extraction in `internal/connector/codex/token.go`:
  - Versioned `oauthBundle` struct containing access token, refresh token, account ID, and absolute expiry metadata, serializing to/from opaque JSON bytes for the SQLite credential envelope under DEC-010.
  - Base64url JWT payload decoder bounded to 64 KiB, rejecting malformed segments, invalid JSON, or missing required fields.
  - Account ID extraction precedence: `chatgpt_account_id` > `https://api.openai.com/auth.chatgpt_account_id` > `organizations[0].id`; check ID token first then access token. Reject silent account substitution when ambiguous.
  - Error sanitization ensuring no token or secret material is formatted into error messages or string representations.
- Implement unit tests in `internal/connector/codex/token_test.go`:
  - Table-driven tests for positive claim extraction across ID/access tokens, claim precedence, and organization fallback.
  - Negative tests for malformed JWTs, oversized payloads, invalid JSON, missing account identity, and truncated tokens.
  - Codec round-trip tests validating preservation of access/refresh tokens, extracted account ID, and absolute expiry.
- Core boundary: pure Connector-internal package; no Core imports modified.

## Acceptance

- [x] Malformed/oversized token data and missing required identity fail with sanitized errors without leaking token material.
- [x] Claim precedence and ID/access-token behavior match the bound profile; organization fallback cannot silently change the selected account.
- [x] Absolute expiry and a versioned complete credential generation survive codec round trips without leaking token material.
