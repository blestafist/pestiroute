# M4-020 — Translate streamed function calls and arguments

## Outcome

Translate streamed function calls and arguments into the Responses streaming event lifecycle. One bounded deliverable in the [M4 registry](../TASKS.md#m4--first-translation-connector)
toward the original [M4](../ROADMAP.md#m4--first-translation-connector).

## Read First

- [Stream/resource policy](../M4-TRANSLATION.md#stream-completion-and-resource-policy).
- [Stream and lifecycle binding](../M4-BINDING.md#stream-and-lifecycle-binding).
- [Execution response and streamframe contract](../CONTRACT.md#execution-response-and-streamframe).
- Anthropic [Messages streaming](https://docs.anthropic.com/en/api/messages-streaming).
- Existing stream helpers: `internal/connector/anthropic/responses_emitter.go`, `execute.go`, `sse.go`.

## Scope

- Extend `responsesEmitter` (`responses_emitter.go`) and `messagesStream` (`execute.go`) in `internal/connector/anthropic`:
  - Translate Anthropic `content_block_start` with `tool_use` (`id`, `name`) into Responses `response.output_item.added` (item of type `function_call`, distinct `fc_` item ID, `call_id` from Anthropic tool use id, `name`).
  - Translate `content_block_delta` with `input_json_delta` (`partial_json`) into Responses `response.function_call_arguments.delta` (`item_id`, `output_index`, `delta`).
  - Translate `content_block_stop` into Responses `response.function_call_arguments.done` (`item_id`, `output_index`, `arguments`) and `response.output_item.done` (`item` containing final arguments).
  - Handle `message_delta` with `stop_reason: "tool_use"` as a successful normal stream outcome, and `message_stop` emitting `response.completed` with complete response snapshot and truthful token usage.
- Keep argument deltas as strings and accumulate without parsing incomplete deltas as complete tool input; assemble the bounded final arguments snapshot.
- Validate UTF-8 and enforce bounded argument memory within the 1 MiB retained limit.
- Reject malformed block indexes, duplicate block identities, unexpected/unknown delta types, and premature EOF with truthful stream failure.
- Out of scope: multiple parallel tool calls in one stream (M4-021), multi-round client interactions (M4-022), usage refinement/cache breakdown (M4-023), committed stream failure classification (M4-024).

## Acceptance

- [x] Streamed Anthropic `tool_use` block start, `input_json_delta` chunks, and block stop translate incrementally into Responses `response.output_item.added`, `response.function_call_arguments.delta`, `response.function_call_arguments.done`, and `response.output_item.done` with distinct IDs (`resp_`, `fc_`, `call_...`), preserving argument strings and Unicode across arbitrary chunk splits.
- [x] `message_delta` with `stop_reason: "tool_use"` followed by `message_stop` successfully completes the Responses lifecycle with `response.completed`, `Complete(succeeded)`, and truthful token usage.
- [x] Unknown delta types, argument overflow (>1 MiB), incomplete closure, duplicate block IDs, malformed block indexes, and premature EOF cannot emit a successful terminal event and terminate with truthful stream error.
