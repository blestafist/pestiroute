# M6-008 — Implement child process launch and resource cleanup

## Outcome

Launch and reap one configured child with owned private Unix-socket resources. See [registry](../TASKS.md#m6--external-plugin-runtime) and [binding](../M6-BINDING.md#ownership-topology-versions).

## Read First

- [M6-BINDING](../M6-BINDING.md#ownership-topology-versions)
- [M6-EXTERNAL](../M6-EXTERNAL.md#binding-gate)
- `internal/core/registry.go`; repository process-launch conventions

## Scope

- External supervisor/process package only; explicit executable/argv, working directory, allowlisted environment, private directory and paired Connector/HostServices sockets, bounded diagnostics and process-tree cleanup.
- No gateway config/startup wiring or handshake implementation; those remain separate tasks.

## Acceptance

- [ ] Launch absolute executable/literal argv/working directory without a shell; inherit no environment and inject only the two named socket-path variables; both socket peers/ownership are checked and only owned resources are removed.
- [ ] Own a new process group; stop/drain, TERM, KILL after 2 s, direct-child Wait exactly once, group disappearance by 5 s, and owned socket cleanup follow M6-BINDING. Child reaps its descendants on orderly close; no claim that host reaps orphan descendants' wait statuses.
- [ ] Bound diagnostic retention to 64 KiB; close/reap on startup error, cancellation and shutdown.
- [ ] No OS sandbox or cross-platform claim.

## Verification

From repository root, run `GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go test -race -count=1 ./internal/connector/external/... -run '^TestM6Process(Launch|RejectsForeignSocket|StartupDeadline|BoundsDiagnostics|ReapsGroup|CleansOwnedSocket)$'`, then `./scripts/check.sh` and `git diff --check`. Use disposable helper children; assert exact argv/env/socket paths, foreign socket preservation, diagnostic cap, startup timeout, TERM/KILL timing, direct-child Wait and group disappearance.
