## Outcome

Runtime tests can substitute a Connector without relying on the native HTTP implementation. See [registry](../TASKS.md#m2--connector-api-and-conformance-baseline) and [M2](../ROADMAP.md#m2--connector-api-and-conformance-baseline).

## Scope

- Create a test-only common Connector in `internal/testutil/scripted` with per-execution scripts for valid Head/Body/Complete, declared scopes, and controlled Init/Health/Close lifecycle.
- Capture immutable requests/scopes and call/close counts; gate stream progress with explicit synchronization channels, not sleeps. Keep out of production startup.
- Implement `core.Connector` and `core.Stream` interfaces, returning ordered `StreamFrame` sequences terminating in `io.EOF`.
