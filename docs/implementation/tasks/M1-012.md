# M1-012 — Incremental native SSE Connector

## Outcome

The Connector forwards SSE incrementally and reports terminal outcome separately from native bytes. See [registry](../TASKS.md#m1--transparent-responses-proxy-planning-candidates) and [M1](../ROADMAP.md#m1--transparent-responses-proxy).

## Read First

- [M1-009](M1-009.md) (Connector baseline), [M1-004](M1-004.md) and [M1-BINDING](../M1-BINDING.md#connector-observation-without-response-buffering) (observer rules, bounds and encoding limits), [frames](../CONTRACT.md#execution-response-and-streamframe), [HTTP streaming](../STACK.md#http-and-streaming), `internal/testutil/fakeupstream/` step gates.

## Scope

- Extend `internal/connector/responses/` to support native SSE responses (`text/event-stream`), yielding `FrameHead`, incremental opaque `FrameBody` chunks, and one classified `FrameComplete`.
- Parse UTF-8-safe event boundaries incrementally across read chunks and multiline `data` fields; support events >256 KiB with bounded token scanning (at most 4 KiB scratch for terminal field/scalar tokens).
- Classify terminal events (`response.completed`, `response.failed`, `response.incomplete`, `error`) and extract known usage; recognize HTTP-200 provider failure events as `OutcomeFailed`.
- Maintain exact upstream body bytes, line endings, and unknown fields without whole-event buffering.
- Apply non-identity `Content-Encoding` pre-Head rejection and idempotent stream `Close()` context cancellation.
- Stop before HTTP flush wiring in adapter (M1-013), translation, tool execution, or capability discovery.

## Acceptance

- [x] First Body frame is consumable while a later upstream step is gated; ordering and raw bytes match upstream exactly.
- [x] Terminal outcomes (`OutcomeSucceeded`, `OutcomeFailed`, `OutcomeIncomplete`) are truthfully observed; transport EOF without terminal SSE ends incomplete; HTTP-200 failure events classify to `OutcomeFailed`.
- [x] Multiline data, split UTF-8 boundaries, and events >256 KiB are handled within bounded scratch (<=4 KiB per retained token); malformed terminal metadata or scalar overflow yields `OutcomeIncomplete` with `UsageUnknown` rather than inferring success.
- [x] Non-identity upstream `Content-Encoding` fails pre-Head without forwarding body frames.
- [x] Stream `Close()` terminates upstream request and releases resources promptly without deadlocks.
