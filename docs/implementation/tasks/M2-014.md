# M2-014 — Select explicit native routes deterministically

## Outcome

A request selects one eligible configured target by protocol and original model identity. See [registry](../TASKS.md#m2--connector-api-and-conformance-baseline) and [M2](../ROADMAP.md#m2--connector-api-and-conformance-baseline).

## Read First

- [Model mapping](../../project/ARCHITECTURE.md#native-passthrough-and-model-mapping), [stateful constraints](../../project/ARCHITECTURE.md#stateful-responses).
- [Routes and startup compatibility](../M2-BINDING.md#routes-and-startup-compatibility).
- [Registry](../../internal/core/registry.go), [Eligibility](../../internal/core/eligibility.go).

## Scope

- Implement explicit route definitions and selection types in `internal/core` matching the M2 binding: `RouteLookupKey`, `RouteIdentity`, `SelectionContext`, `Route`, and route collection / routing lookup table.
- Validate route table inputs: require unique `RouteIdentity`, non-empty protocol/mode/model/account, native-only mode for M2, and resolvable component instance IDs against registered components.
- Deterministic selection: exact match on `(Protocol, Mode, Model)` and trusted `SelectionContext.AccountID` resolves one Adapter instance and one Connector instance.
- Fail closed on missing route, unselected account, duplicate identity, or unavailable/ineligible component targets; client payload bytes and model remain unmodified, client metadata cannot select account, and no load balancing or silent fallback is performed.

## Acceptance

- [x] Route table validation accepts valid route declarations and rejects duplicate identities, empty fields, non-native modes, and unresolvable/mismatched component instances.
- [x] Deterministic selection matches exact `(Protocol, Mode, Model, AccountID)` to its configured Adapter and Connector instances without mutating request payload/model or honoring client-supplied account hints.
- [x] Route misses, unselected accounts, ambiguous/conflicting matches, and unavailable or ineligible target components fail closed with explicit errors without alternate fallback.
