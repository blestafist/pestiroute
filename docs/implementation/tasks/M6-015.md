# M6-015 — Bridge model enumeration and usage estimates

## Outcome

Bridge `core.Connector` model enumeration (`Models`) and usage estimation (`EstimateUsage`) over external IPC to child connector processes, conveying runtime-owned route body limit `MaxBodyBytes` on `UsageQuery` under authorized DEC-015, preserving protocol/mode/account scope, supported/known flags, nullable token counters, and route-bounded request payload bodies. See [registry](../TASKS.md#m6--external-plugin-runtime), [milestone](../ROADMAP.md#m6--external-plugin-runtime), [binding](../M6-BINDING.md#ownership-topology-versions), and [contract](../CONTRACT.md#connector-contract).

## Scope

- Exact authorized decision (DEC-015) and contract synchronization:
  - Add `MaxBodyBytes int64` to `core.UsageQuery` in `internal/core/connector.go`.
  - In `internal/core/dispatch.go`, populate `UsageQuery.MaxBodyBytes` from `selection.Route.MaxBodyBytes` (or route's effective admitted limit).
  - Synchronize ADR DEC-015 in `docs/project/DECISIONS.md`, `docs/implementation/CONTRACT.md`, and `docs/implementation/M6-BINDING.md`.
- In `internal/ipc/proto/connector.proto`:
  - Add `int64 max_body_bytes = 6;` to `UsageQuery` message.
  - Define `EstimateFrame` carrying `RecordFragment` and `BodyChunk` oneof (mirroring `HTTPFrame` structure).
  - Add `Models(stream RecordFragment) returns (stream RecordFragment)` to `Connector` service.
  - Add `EstimateUsage(stream EstimateFrame) returns (stream RecordFragment)` to `Connector` service.
  - Regenerate protobuf code via `protoc` in `internal/ipc/gen/`.
- In `internal/connector/external/`:
  - Implement `Models(ctx context.Context, query core.ModelQuery, services core.InvocationServices) (core.ModelsResult, *core.GatewayError)` on `*Connector`:
    - Enforce 2 s query timeout bounded by caller context; require initialized and non-closing connector.
    - Validate scope (`Protocol`, `Mode` must be native or translation).
    - Stream fragmented `ModelQuery` to child; read and assemble fragmented `ModelsResult`.
    - Preserve `Supported`, `Models` list, capability states (`supported`, `unsupported`, `unknown`), and nullable `Available` boolean (`*bool`).
  - Implement `EstimateUsage(ctx context.Context, query core.UsageQuery, services core.InvocationServices) (core.EstimateResult, *core.GatewayError)` on `*Connector`:
    - Enforce 2 s query timeout bounded by caller context; require initialized and non-closing connector.
    - Validate scope (`Protocol`, `Mode` must be native or translation).
    - Stream fragmented `UsageQuery` record (including `query.MaxBodyBytes`) followed by separate bounded `BodyChunk`s for request payload via `ipc.WriteBody(..., query.MaxBodyBytes)`.
    - Child reassembles payload body under the conveyed admitted route bound (`query.MaxBodyBytes`) via `ipc.BodyAssembler`, rejecting chunks exceeding bounds.
    - Receive and assemble fragmented `EstimateResult`.
    - Preserve `Supported`, `Known`, `Method`, and nullable `UsageReport` counters (`InputTokens`, `OutputTokens`, `ReasoningTokens`, `CachedTokens`, `Source`, `Completeness`); nil usage is distinct from zero.
    - Resolve reviewer P2 cancellation mapping: context cancellation returns `estimate_cancelled` / `CategoryCancelled` with unknown retry.
- Limits: Model enumeration and usage estimation bridging only. No authentication bridging (M6-016), no Execute streaming response bridging (M6-017/018), no Core route-selection/eligibility/policy changes or synthetic gateway endpoints.

## Acceptance

- [x] Core `UsageQuery` carries runtime-owned `MaxBodyBytes int64` populated by Core dispatch from the admitted route limit; protobuf `UsageQuery` carries field 6 `max_body_bytes`.
- [x] `Models` validates scope, exchanges fragmented `ModelQuery` and `ModelsResult` over IPC, and preserves supported flag, model list, capability states, and nullable `Available` pointers.
- [x] `EstimateUsage` exchanges fragmented `UsageQuery` and `EstimateResult` over IPC, preserving supported/known flags, method, and nullable usage counters without fabricating zero tokens for nil counts.
- [x] `EstimateUsage` transmits request payload bodies as separate incremental `BodyChunk`s; child reassembles under the conveyed runtime-owned `MaxBodyBytes` limit via `ipc.BodyAssembler`, rejecting chunks exceeding bounds.
- [x] Uninitialized or closing connector, invalid protocol/mode scope, and transport timeouts fail closed with honest error or unsupported/unknown result within the 2 s operation deadline; cancellation maps to `estimate_cancelled` / `CategoryCancelled`.
- [x] Helper-child test fixture verifies bidirectional parity for both operations under normal, boundary/nil, and over-bound body cases.
