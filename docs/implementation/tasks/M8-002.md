## Scope

- Within `internal/connector/claudecode`, connect translation, scoped credential
  access, HTTP invocation, response validation, bounded error handling, and
  incremental stream ownership into public `Execute`.
- Use the offline fake-only transport/endpoint boundary authorized by user approval:
  target fixed `https://api.anthropic.invalid/v1/messages?beta=true` and include
  test-only header `anthropic-beta: synthetic-beta`.
- Enforce transport isolation: require non-nil `services.Transport`, reject 3xx
  redirects without following them, and ensure no external network dispatch.
- Reject unready connector state, wrong protocol (require `openai.responses.v1`),
  wrong mode (require `core.ModeTranslation`), canceled context, missing or
  invalid `oauth` credentials (empty token, unknown fields, malformed JSON),
  missing transport, and unsupported payloads before dispatch.
- Handle responses:
  - 200 OK: validate `Content-Type: text/event-stream` (optional charset UTF-8),
    reject unsupported encodings (`identity` or absent only), and return
    `ExecutionResponse` with incremental `messagesStream`.
  - Non-200 / error responses: drain at most 64 KiB, close body immediately, and
    map to prescribed `GatewayError` (401/403 -> unauthenticated/unsafe,
    429 -> rate_limited/unknown, 5xx/3xx/other -> unavailable/unknown).
  - Guarantee response body closure on all paths (normal completion, error,
    stream read failure, context cancellation, and consumer Close).
- Advertise `execute` in Descriptor operations once the public path is connected.
- Keep gateway composition rejected by default and all capabilities `Unknown`.
  Do not implement live provider calls or production routing.

## Acceptance

- [x] Public `Execute` executes against an injected fake `core.HTTPDoer` transport and delivers incremental `Head -> Body* -> Complete -> EOF` frames for synthetic SSE streams.
- [x] Pre-dispatch validation rejects (zero transport calls): unready state, wrong protocol, wrong mode, canceled context, missing transport, missing/invalid `oauth` credential bundle, empty access token, and unsupported request semantics.
- [x] Transport isolation: requests target fixed `https://api.anthropic.invalid/v1/messages?beta=true` with `anthropic-beta: synthetic-beta`; 3xx responses fail closed without following redirects.
- [x] Error classification: 401/403, 429, 5xx, 3xx, and network errors return prescribed `GatewayError` with exact retry/disposition and bounded body drain (<= 64 KiB) and closure.
- [x] Credential handling: extracts only `oauth.access_token` via scoped `services.Credentials`, emits `Authorization: Bearer <token>`, and never logs secrets.
- [x] Descriptor exposes `execute` alongside `authenticate`; capabilities remain `Unknown`; gateway composition continues to reject the component.
