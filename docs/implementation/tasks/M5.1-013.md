## Scope

- Carry DEC-010 `CredentialExpiresAt` from `core.AuthResult` into generic Core auth operations and store persistence:
  - Add optional `ExpiresAt *time.Time` to `core.AuthCredentials`.
  - In `core.AuthCoordinator` (`Start`, `Continue`, `Refresh`), carry non-nil `result.CredentialExpiresAt` into replacement credentials passed to the store.
  - Core validation: if `CredentialExpiresAt` is non-nil, validate that it is a positive/future timestamp; fail closed on zero or past expiry. If nil, retain existing non-expiring credential behavior.
  - In `cmd/gateway/auth_store.go`, update `credentialReplacement` to accept and preserve `expiresAt *time.Time` on the target credential (replacing unconditional `old.ExpiresAt = nil`).
  - In `cmd/gateway/auth_store.go`, update `FinishAuthSession`, `ResolveRefresh`, and `ReplaceAuthCredentials` to persist `ExpiresAt` atomically with ciphertext and revision.
- Preserve atomic single-transaction commit and CAS safety:
  - Commit ciphertext, nonce, format_version, key_version, and `expires_at` together with revision increment; acknowledge success only after SQLite commits both.
  - Revision mismatch, disabled account, or missing candidate fails closed with `ErrAuthRevisionMismatch` / `ErrAuthUnavailable` and never mutates existing credentials or expiry.
  - Support bootstrapping an unauthenticated Codex account row with encrypted empty bundle and nil expiry without bearer privileges.
- Add regression coverage in `internal/core` and `cmd/gateway` / `internal/storage/sqlite`:
  - Primary check `TestAuthCoordinatorPersistsCredentialExpiry`: verify `Start`, `Continue`, and `Refresh` persist valid future `ExpiresAt` and reject zero/past expiry.
  - SQLite real-file / restart tests: verify encrypted credential round-trip decrypts rotated generation with valid `ExpiresAt`, and legacy credentials without expiry retain `ExpiresAt == nil`.
- Explicit limits:
  - Provider payload encoding stays Connector-private; Core treats candidate values as opaque bytes.
  - Do NOT implement operator CLI/HTTP wiring (M5.1-014, M5.1-015) or pre-dispatch inference freshness check / auto-refresh (M5.1-016).
  - No live network or provider calls.

## Acceptance

- [x] `Start`, `Continue`, and `Refresh` flows carry `AuthResult.CredentialExpiresAt` into persisted credentials; valid future expiry is committed atomically with ciphertext and revision increment, without setting `ExpiresAt = nil`.
- [x] Incomplete candidates, revision mismatch, wrong account, or invalid/past expiry fail closed and do not overwrite stored credentials or clear existing expiry.
- [x] Decrypted credentials and expiry round-trip across synthetic real-file restart; legacy credentials without expiry retain `ExpiresAt == nil`.
