- Add client-to-gateway-to-fake-runtime text roundtrip tests for all three versioned profiles (`ollama-v0.40.3`, `vllm-v0.31.0`, `llamacpp-v0.6.0`).
- Test non-streaming JSON responses and incremental SSE streaming delivery through protected gateway loopback HTTP endpoints.
- Verify byte preservation for native opaque requests, unknown allowed extensions, and upstream response JSON/SSE deltas.
- Verify incremental delivery without whole-response buffering: first SSE body delta reaches client before stream completion.
- Verify terminal stream failures: mid-stream truncation or disconnect after commit does not settle successful and never replaces status or body with synthetic success.
- Execute strictly with synthetic secrets, SQLite storage, and virtual-key authentication.
- Limits: Deterministic fake/loopback test servers only; no live provider, external network, or running daemon required. Tool calling deferred to M5.2-015; parallel tools deferred to M5.2-016; history/reasoning deferred to M5.2-017; cancellation/backpressure stress deferred to M5.2-019.
