## Scope

- Document reproducible, executable local gateway startup and verification steps against a local fake target with synthetic credentials (in `README.md` or a dedicated doc), covering required configuration fields (`upstream_endpoint`, `upstream_credential_env`, limit and timeout durations) and loopback listener constraints.
- Implement a reproducible local measurement test or script for native proxy baseline observations under local Go test:
  - Latency overhead and time-to-first-byte (TTFB) comparing direct fake upstream vs through-gateway path.
  - Memory allocations / bytes per active stream during steady-state streaming.
  - Goroutine and memory cleanup / absence of leaks after client disconnect / stream cancellation.
- Run and record the complete local M1 regression suite covering:
  - Opaque request body preservation and unknown fields.
  - SSE split boundaries, event ordering, and interleaved tool IDs.
  - Downstream cancellation and upstream request termination.
  - Bounded backpressure under stalled downstream reader.
  - Stream idle timeout, pre-commit timeout classification, and deadline cancellation.
  - Concurrent request isolation, drain admission, and exactly-once finalization.
  - Downstream credential/header isolation, Accept-Encoding override, and response encoding rejection gate.
- Update `CURRENT.md` with verified commands, actual capabilities, and next handoff.
- Limits: Stop before live provider inference (M1-023..026), new persistent benchmark infrastructure, tuning to invented performance budgets, M2 connector registry/conformance, or M3 auth/storage.

## Completion Evidence

- Added `docs/implementation/LOCAL-M1.md` and linked it from the README. The documented temporary-workspace procedure starts a Python standard-library fake `POST /v1/responses` target and the built gateway using synthetic bearer credentials, then curls health, readiness and inference. Required endpoint, environment-variable credential, byte-limit, positive timeout and loopback requirements match `cmd/gateway/main.go`.
- Clean-source verification: exported the full working source (excluding `.git`, `.refs`, `.opencode`) under `/tmp/opencode/m1-022-source.*`; ran the complete shell block from `LOCAL-M1.md` from that export. Offline Go 1.27.1 build passed; health/readiness returned `ok`, fake inference returned 200, and its assertions checked route, synthetic selected credential and unknown field. No real credentials/provider were used.
- Revised `TestNativeBaseline` uses the same `http.Client`/transport, serial concurrency (1) and five warm-ups per path, then 25 alternating samples per path with min/median/p95/max for TTFB and complete response. Three forced-uncached runs on Linux amd64, Go `go1.27.1-X:nodwarf5`, 8 logical CPUs gave per-run medians: direct TTFB 38.436–41.68µs vs gateway 98.418–113.151µs; complete direct 40.881–45.201µs vs gateway 101.673–116.62µs. Across those runs, p95 ranges were direct/gateway 52.213–59.606µs / 123.883–315.833µs (TTFB), and 54.589–62.145µs / 128.089–325.509µs (complete). Low-load loopback observations only, not budgets.
- Active memory snapshots separately compared direct and gateway SSE with N=4 and N=8. Signed whole-process heap delta divided by N ranged 76,588–78,378 B (direct N=4), 150,164–159,594 B (gateway N=4), 67,312–71,951 B (direct N=8), 126,263–127,038 B (gateway N=8). These include fixture/test/runtime and are not gateway-attributed; GC/runtime noise is substantial. Post-cancel heap is retained as an observation, not a leak test.
- Leak-proof evidence: before each fixture, the test closes idle client connections, forces GC, and waits for ten consecutive stable goroutine-count samples. After cancellation it requires all tracked client goroutines to exit and all upstream `Cancelled` channels to close; then closes gateway, Connector transport, client idle connections and fake server. It polls for at most 2s until process goroutines are `<=` the stable pre-fixture count and fails otherwise (no additive tolerance). Three forced-uncached runs returned to 7/7 goroutines in every direct and gateway batch (N=4,8).
- `./scripts/check.sh`, `GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go test -race -v ./cmd/gateway/...`, `GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go test -race -cpu=1,4 -count=1 -v -run TestNativeBaseline ./cmd/gateway/...`, three forced-uncached baseline runs, documented startup against fake from a full clean source export, and `git diff --check` passed. Changed-document relative targets were checked; there is no dedicated repository doc checker.

All acceptance criteria verified; task accepted DONE. No real-client or live-provider compatibility is claimed.
