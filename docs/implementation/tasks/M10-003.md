## Scope

- Within `internal/connector/antigravity/testdata/`:
  - Create `manifest.json` registering version 1, SHA-256 digests of all fixtures, and explicit synthetic provenance (no live provider captures, no credentials, no production claims).
  - Add candidate translated request fixture (`request-positive.json`) conforming to the candidate schema defined in `M10-BINDING.md` (`project`, `model`, `request` with `contents`).
  - Add streaming SSE fixtures:
    - `stream-text.sse`: incremental text chunks via candidate `data:` SSE envelopes (`candidates[].content.parts`).
    - `stream-usage.sse`: candidate stream chunk containing token counts / usage.
    - `stream-premature-eof.sse`: stream terminating abruptly before complete terminal envelope.
    - `stream-malformed.sse`: SSE data containing invalid/malformed JSON.
  - Add HTTP error response fixtures:
    - `http-401.json`: unauthenticated error body.
    - `http-403.json`: permission denied / forbidden error body mapped to `unauthenticated` (`false / unsafe`) per frozen binding.
    - `http-429.json`: rate limited error body.
    - `http-500.json`: internal server error body.
- Within `internal/connector/antigravity/`:
  - Add `fixtures_test.go` checking manifest checksums, verifying synthetic origin assertions, and validating that no external URLs or real credentials exist in fixtures.
- Within `docs/implementation/`:
  - Add `M10-SLICE-DECISION.md` recording:
    - GO decision for offline fake-only vertical slice of `openai.responses.v1` text/stream prompt execution.
    - Strict fake-only transport specification targeting fixed synthetic `.invalid` endpoint (e.g. `https://antigravity.synthetic.invalid/v1internal/projects/{project}:generateContent?alt=sse`).
    - Model allowlist for fixture execution (`gemini-2.5-pro`, `gemini-2.5-flash`).
    - Explicitly unsupported and Unknown fields/behaviors: tools, function calls, thought signatures, multimodal input, system instruction, live endpoints, OAuth refresh/exchange, enterprise project discovery / auto-provisioning.
    - Licensing / clean-room provenance: MIT-licensed OpenCode plugin observations adapted into Go fixtures without copying proprietary client secrets or binary assets.
- Limits:
  - No implementation of public `Execute` or connector runtime logic (owned by M10-004).
  - No live provider calls, network access, or real account credentials.
  - No edits to shared core or gateway files; gateway integration is deferred and sequenced for M11.
