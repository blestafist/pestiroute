## Scope

- End-to-end integration tests in `cmd/gateway/`:
  - Launch protected gateway configured with an external native Responses child connector (`cmd/responses-connector-child`) over Unix socket IPC.
  - Set up a loopback fake upstream server handling upstream Responses API requests.
  - Test real HTTP client non-streaming JSON request (`POST /v1/responses`): assert exact status code, response body byte preservation, and accurate SQLite accounting settlement.
  - Test real HTTP client streaming SSE request (`POST /v1/responses` with `stream: true`): assert `Content-Type: text/event-stream`, incremental delivery, early chunk arrival (first chunk observed before upstream completes), exact chunk byte preservation, and attempt finalization.
  - Test tool-call payload roundtrip: verify opaque tool arguments and unknown fields pass through client → gateway → child → upstream → child → gateway → client without corruption.
  - Verify clean gateway shutdown after traffic: child process group terminated, reaped, and Unix socket directory unlinked.
- Limits:
  - Fault injection, crash classification, and delivery-safe fallback accounting belong to M6-027.
  - Concurrent multi-account isolation belongs to M6-028.
  - Conformance suite unification belongs to M6-029.
  - Core runtime remains provider- and transport-neutral; no direct IPC imports in Core.
