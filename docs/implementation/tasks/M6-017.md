## Scope

- Protobuf `ExecuteFrame` carrier in `connector.proto` (`epoch`, `call_id`, `invocation_id`, oneof `payload` with `RecordFragment record` and `BodyChunk body`) and `rpc Execute(stream ExecuteFrame) returns (stream ExecuteFrame)` on `Connector`.
- Under authorized DEC-016: runtime-owned `MaxBodyBytes int64` on `core.AttemptScope` (normalized to `math.MaxInt64` if unbounded), populated in `Dispatcher.executeAttempt`, and carried as additive field 3 on protobuf `ExecuteStart`.
- Host-side `core.Connector.Execute` client:
  - Registers invocation in `invocationRegistry` with invocation context and scoped services.
  - Opens bidirectional `Execute` RPC stream to child process.
  - Sends fragmented `ExecuteStart` record (containing `ExecutionRequest` metadata, `AttemptScope`, and `MaxBodyBytes`).
  - Streams request payload body chunks (<=64 KiB) followed by fragmented `InputComplete` record.
  - Reads child response: pre-Head `GatewayError` record returns `(ExecutionResponse{}, gatewayErr)`; valid `HeadFrame` initializes an active `core.Stream`.
  - Stream `Next()` yields exact `BodyFrame` chunks from inbound body frames, followed by `CompleteFrame` record, and returns `io.EOF` at stream end.
- Child test harness handler:
  - Reassembles `ExecuteStart` control record and receives incremental body chunks bounded by `AttemptScope.MaxBodyBytes`.
  - Rejects body accumulation exceeding `MaxBodyBytes` before executing handler.
  - On `InputComplete`, runs the deterministic fixed-response test fixture only after the full request validates; this is not production child composition.
  - If handler returns pre-Head `*GatewayError`, serializes and fragments `GatewayError` record and closes stream.
  - If handler returns `ExecutionResponse`, streams fragmented `HeadFrame`, followed by incremental response `BodyChunk` frames, fragmented `CompleteFrame`, and closes stream cleanly.
- Limits: Single fixed attempt only. Production child composition root wrapping native Responses belongs strictly to M6-024. Incremental early partial-frame delivery without response aggregation is verified in M6-018. Invocation cancellation and deadlines are M6-019. Backpressure and concurrency bounds belong to M6-020. Fault injection and recovery belong to M6-021/M6-022.
