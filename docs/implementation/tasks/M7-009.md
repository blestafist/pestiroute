## Scope

- Create `internal/connector/claudecode/component.go`:
  - Component descriptor declaring supported protocol `openai.responses.v1`, operations `["execute", "models", "estimate_usage", "authenticate"]`, connector type `"claudecode"`, and auth methods `["oauth"]`. Profile is NOT a Descriptor field.
  - Strict profile configuration: parsed from `core.ComponentConfig` during `Init`; validates configured profile equals `claude-code-messages-v1` and rejects invalid/unknown configurations.
  - Conservative capability reporting in `Capabilities(context.Context, core.CapabilityScope)`: all capabilities (`llm.streaming`, `llm.tools`, `llm.reasoning`, `auth.oauth`, `usage.exact`) return `core.Unknown`. The connector is non-routable by default until live evidence is verified.
  - Lifecycle methods: `Init(context.Context, core.ComponentConfig) error`, `Close(context.Context) error`, and `Health(context.Context) core.Health` (reporting `HealthReady` when active, `HealthUnavailable` when uninitialized or closed).
  - Compile-complete, contract-correct `core.Connector` stubs:
    - `Execute(context.Context, core.ExecutionRequest, core.AttemptScope, core.InvocationServices) (core.ExecutionResponse, *core.GatewayError)`: returns `&core.GatewayError{Code: "connector_unavailable", Category: core.CategoryUnavailable, RetryDisposition: core.RetryUnknown, Message: "Claude Code connector execution is unavailable"}` with an empty execution response and zero stream frames.
    - `Authenticate(context.Context, core.AuthRequest, core.InvocationServices) (core.AuthResult, *core.GatewayError)`: returns `core.AuthResult{Supported: false}` until successor task M7-010 implements the PKCE exchange.
    - `Models(context.Context, core.ModelQuery, core.InvocationServices) (core.ModelsResult, *core.GatewayError)`: returns accurate offline semantics (`Supported: true` with declared profile model, all capabilities `core.Unknown`, `Available: nil`).
    - `EstimateUsage(context.Context, core.UsageQuery, core.InvocationServices) (core.EstimateResult, *core.GatewayError)`: reports accurate offline semantics (`Supported: true, Known: false, Usage: nil`) without external network calls.
- Add unit tests in `internal/connector/claudecode/component_test.go`:
  - Lifecycle state transitions (`Init` -> active -> `Close`).
  - `Health` reporting (`HealthUnavailable` before init -> `HealthReady` -> `HealthUnavailable` after close).
  - Capabilities audit confirming 100% `core.Unknown` across all queries.
  - Execute stub verification asserting explicit `GatewayError` with a nonempty client-safe `Message` and no stream frames.
  - Authenticate stub asserting `Supported == false`.
  - Models and EstimateUsage contract-compliance assertions.
- Explicit limits: Component lifecycle and compile-complete contract stubs only; full wire execution, translation, and auth exchanges belong to successor backlog tasks; Core does not import this concrete package.
