## Scope

- Create or update `internal/connector/claudecode/component.go`:
  - Component descriptor declaring supported protocol `openai.responses.v1`, no supported extension operations (all methods here are compile-required unsupported stubs), normative API connector type `"api"`, and auth methods `["oauth"]`. Profile is NOT a Descriptor field. `Authenticate` is not implemented, so it is not advertised as an operation.
  - Strict profile configuration: parsed from `core.ComponentConfig` during `Init`; validates configured profile equals `claude-code-messages-v1` and rejects invalid/unknown configurations, missing profile, or trailing data.
  - Conservative capability reporting in `Capabilities(context.Context, core.CapabilityScope)`: validates lifecycle readiness (`HealthReady`), protocol (`openai.responses.v1`), and mode (`core.ModeTranslation`); all capabilities (`llm.streaming`, `llm.tools`, `llm.reasoning`, `auth.oauth`, `usage.exact`) return `core.Unknown`. The connector is non-routable by default until live evidence is verified.
  - Lifecycle methods: `Init(context.Context, core.ComponentConfig) error`, idempotent `Close(context.Context) error`, and `Health(context.Context) core.Health` (reporting `HealthReady` when active, `HealthUnavailable` when uninitialized or closed).
  - Compile-complete, contract-correct `core.Connector` stubs respecting lifecycle, cancellation, protocol, mode, and bounds:
    - `Execute(context.Context, core.ExecutionRequest, core.AttemptScope, core.InvocationServices) (core.ExecutionResponse, *core.GatewayError)`: checks lifecycle (`connector_unavailable` if not `HealthReady`), then maps cancellation/deadline to cancelled/timeout `GatewayError`, and validates protocol (`openai.responses.v1`) and mode (`core.ModeTranslation`). Returns an unavailable error with an empty execution response and zero stream frames for an otherwise valid request.
    - `Authenticate(context.Context, core.AuthRequest, core.InvocationServices) (core.AuthResult, *core.GatewayError)`: checks lifecycle then maps cancellation/deadline to cancelled/timeout `GatewayError`; otherwise returns `core.AuthResult{Supported: false}` without network calls.
    - `Models(context.Context, core.ModelQuery, core.InvocationServices) (core.ModelsResult, *core.GatewayError)`: checks lifecycle (`connector_unavailable` when not ready), context cancellation/deadline (`ctx.Err()`), protocol (`openai.responses.v1`), and translation mode (`core.ModeTranslation`). Does not invent an unsupported `claude-code` model ID (M7-BINDING defines no such model; returns `core.ModelsResult{Supported: false}` without fabricated models).
    - `EstimateUsage(context.Context, core.UsageQuery, core.InvocationServices) (core.EstimateResult, *core.GatewayError)`: checks lifecycle, context cancellation/deadline, protocol, translation mode, and requires a positive `query.MaxBodyBytes` bound, rejecting nonpositive bounds or payloads exceeding it. Per M2 binding, Core represents an unbounded route using `math.MaxInt64`; zero is not an unbounded sentinel. Reports `core.EstimateResult{Supported: false, Known: false}` without external network calls.
- Add unit tests in `internal/connector/claudecode/component_test.go`:
  - Descriptor validation asserting normative `ConnectorType == "api"`, protocol `openai.responses.v1`, auth methods `["oauth"]`, zero advertised operations, and `Validate(core.ComponentConnector)`.
  - Strict profile configuration parsing: rejects missing profile, unknown profile, trailing data, unknown fields; succeeds for `profile: "claude-code-messages-v1"`.
  - Lifecycle state transitions (`Init` -> ready -> `Close` -> unavailable; idempotent close; re-init rejection).
  - `Health` reporting (`HealthUnavailable` before init -> `HealthReady` -> `HealthUnavailable` after close).
  - Capabilities audit confirming 100% `core.Unknown` across all queries, and empty result when unready or scope/protocol/mode mismatch.
  - Execute stub verification asserting lifecycle/cancellation/deadline checks, protocol/mode bounds, and explicit `GatewayError` with a nonempty client-safe `Message` and no stream frames.
  - Authenticate stub asserting lifecycle/cancellation/deadline checks and `Supported == false` when active.
  - Models stub contract compliance asserting lifecycle, cancellation, protocol/mode bounds, and no invented `claude-code` model ID.
  - EstimateUsage stub contract compliance asserting lifecycle, cancellation, protocol/mode bounds, rejection of nonpositive `MaxBodyBytes` and over-limit payloads, and `Supported: false, Known: false`.
- Explicit limits: Component lifecycle and compile-complete contract stubs only; full wire execution, translation, and auth exchanges belong to successor backlog tasks; Core does not import this concrete package. Offline synthetic testing only under DEC-018.
