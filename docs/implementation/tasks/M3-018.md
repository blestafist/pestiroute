## Scope

- Define runtime-owned `TrustedPrincipal` (`KeyID, PolicyID string`, `KeyRevision, PolicyRevision int64`) and `KeyStore` / `KeyVerifier` interface (`Verify(context.Context, string) (TrustedPrincipal, error)`) in `internal/core` without importing non-standard packages.
- Extract presented Bearer key from northbound HTTP `Authorization: Bearer <token>` header before execution; reject missing, non-Bearer, empty, or malformed credentials before route matching or reservation.
- In protected mode, verify presented key using `KeyStore`; map verification failures (invalid, revoked, disabled) to client-safe 401 Unauthorized errors (`CategoryUnauthenticated`, code `invalid_api_key`) via adapter `Encode`.
- Pass verified `TrustedPrincipal` through runtime request context/flow to downstream admission/routing; raw key material is discarded immediately after verification and never placed into `ExecutionRequest`, `RequestMetadata`, logs, or upstream headers.
- Retain unauthenticated access for probe endpoints (`GET /healthz`, `GET /readyz`).
- Explicit limits:
  - Policy authorization (allowed models, connectors, accounts) belongs to [M3-019](M3-019.md).
  - Protected YAML configuration loader belongs to [M3-020](M3-020.md).
  - Admission window arithmetic, reservations, and durable accounting ledger belong to [M3-021](M3-021.md)–[M3-028](M3-028.md).
  - Full protected gateway composition belongs to [M3-030](M3-030.md).
  - Protected mode does not accept legacy upstream credentials as virtual keys.
  - No contract semantic changes without an accepted ADR in DECISIONS.

## Acceptance

- [x] Missing, non-Bearer, malformed, empty, invalid, disabled, and revoked keys return client-safe 401 Unauthorized (`CategoryUnauthenticated`) with adapter-formatted JSON error before reservation, route resolution, or `Execute`.
- [x] Requests failing authentication make zero Connector, support, or upstream network calls.
- [x] Gateway `Authorization` bearer token is absent from `ExecutionRequest`, `RequestMetadata`, redacting logger output, and upstream HTTP headers; upstream receives only the selected connector account credential.
- [x] Successful authentication passes immutable `TrustedPrincipal{KeyID, PolicyID, KeyRevision, PolicyRevision}` to downstream runtime context/flow without leaking presented raw key bytes.
- [x] Probe endpoints (`GET /healthz`, `GET /readyz`) continue to respond without credentials in protected mode.
- [x] Production `internal/core` maintains zero imports of non-standard packages (`internal/storage/sqlite`, etc.), verified by `dependencies_test.go`.
