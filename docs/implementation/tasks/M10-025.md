## Scope

- Eligibility diagnostic reason enum:
  - Decompose `eligibleFreeTier` predicates into fixed, secret-safe diagnostic enum reason codes:
    - `schema-invalid`: root or candidate structure fails JSON or boolean typing.
    - `paid-present`: `paidTier` present and non-null.
    - `candidate-missing`: 0 free-tier candidates found in `allowedTiers`.
    - `ambiguous`: multiple free-tier candidates found in `allowedTiers`.
    - `userprojectrequired`: candidate requires user-defined GCP project.
    - `terms`: terms of service not accepted (`hasAcceptedTos` is false).
    - `privacy`: interactive privacy notice required (`privacyNotice.showNotice` is true).
    - `providerineligible`: candidate tier listed under `ineligibleTiers`.
    - `validationrequired`: `ineligibleTiers` contains `VALIDATION_REQUIRED`.
- Safe tier identity classification enum:
  - Classify discovered tiers strictly into safe enum: `free`, `legacy`, `standard`, `other`.
  - Never print, log, or return raw unrecognized tier IDs.
- Candidate vs unrelated entry distinction and bounded telemetry:
  - Distinguish schema-invalid within an unrelated entry vs within the candidate.
- Emit bounded counts (e.g. total allowed, ineligible count), fixed tier classes, and boolean flags with `Logger.Debug`; standard `slog` level filtering must keep them silent for ordinary LevelInfo loggers. Admin `auth --debug` configures the logger at LevelDebug and exposes this telemetry. Other runtime callers may intentionally inject a debug-enabled logger; this is not an admin-only capability.
- Core & Admin allowlists:
  - Add neutral eligibility diagnostic codes to `safeAuthDiagnosticCode` in `internal/core/auth_coordinator.go` and `cmd/gateway/admin_auth.go`.
  - Retain provider neutrality in Core; avoid provider-specific fields in universal errors.
- Safeguards & limits:
  - Defaults unchanged: fail-closed without `--allow-onboard`.
  - No new provider API requests, discovery calls, or retries solely for diagnostics.
  - Offline tests only; synthetic canary tests verify zero secret, token, or raw payload leakage.
