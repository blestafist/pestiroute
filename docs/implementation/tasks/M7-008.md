## Scope

- Add `internal/connector/claudecode/testdata/` directory containing:
  - Synthetic OAuth PKCE authorize URLs, token exchange JSON responses, and token refresh JSON responses.
  - Synthetic Messages request JSON bodies and SSE stream files (`.sse`) covering text streaming, tool calls, thinking/reasoning blocks, HTTP error bodies, and usage reports.
  - Edge-case and failure fixtures: malformed SSE frames, premature EOF, mid-stream disconnect, invalid UTF-8 sequences, and HTTP error bodies (400, 401, 403, 429, 500).
  - Manifest file listing SHA-256 hashes and provenance notes.
- Add `internal/connector/claudecode/fixtures_test.go` verifying manifest integrity and fixture parsing.
- Explicit limits: Pure synthetic fixtures only; zero real credentials, zero live network captures, zero proprietary npm binaries. Fixture success is strictly offline test evidence and does not constitute provider proof.
