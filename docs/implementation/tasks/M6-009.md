## Outcome

## Scope

- Implement host-side connection and handshake verification in `internal/connector/external` with wire definitions/codecs in `internal/ipc`.
- Verify peer process identity (`VerifyPeer`) on Unix domain socket connection before issuing RPCs.
- Negotiate fixed IPC protocol ID `pestiroute.connector.v1` and supported IPC major version (`1`) via server-streaming Handshake typed record.
- Request complete Descriptor via server-streaming RPC and require exact declared runtime Connector `APIVersion` pair (`core.APIVersion{Major: 1, Minor: 0}`) against child's `Descriptor.APIVersions` before Init.
- Enforce bounded handshake timeout sharing the supervisor's 30 s startup deadline or caller context.
- Handshake/service version compatibility and peer binding only; reject incompatible peers before any operation. Zero Init/Execute calls on rejection.
- Limits: no component lifecycle bridging (Descriptor proxying, Init, Health, Capabilities, Close execution) which belongs to M6-010. No reverse host services (M6-012..014) or Execute bridging (M6-017).

## Acceptance

- [x] Verify expected child identity via `SO_PEERCRED` / `VerifyPeer` and fixed protocol ID `pestiroute.connector.v1`; require supported IPC major version (`1`) and host's exact declared runtime Connector API pair (`core.APIVersion{Major: 1, Minor: 0}`) against child `Descriptor.APIVersions`.
- [x] Keep API pair, IPC version, protocol identifier and implementation version distinct; do not infer API compatibility from IPC minor version.
- [x] Reject wrong peer identity, bad protocol ID, unsupported IPC major, absent exact API pair, and malformed descriptor pre-Init with truthful error reporting and without invoking Init/Execute.
- [x] Handshake timeout or readiness failure enforces bounded deadline (shares 30 s startup deadline or caller context) and prevents all subsequent Component calls.
