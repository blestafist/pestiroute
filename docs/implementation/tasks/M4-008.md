## Scope

- Implement top-level field allowlist in `internal/connector/anthropic/translate.go`:
  - Allowed fields: `model`, `input`, `instructions`, `stream`, `max_output_tokens`, `temperature`, `store`, `include`.
  - Reject any other supplied field (e.g. `previous_response_id`, `conversation`, `background`, structured output, `response_format`, `tools`, `tool_choice`, `max_tokens`, `top_p`, penalties, stop sequences) with client-safe `*core.GatewayError` (Category `invalid_request`).
- Enforce required streaming:
  - Require JSON `stream: true` (boolean true). Reject missing, `false`, null, or non-boolean `stream`.
- Enforce client model identity:
  - Require non-empty string `model`.
- Enforce output budget (`max_output_tokens`):
  - When omitted, default backend `max_tokens` to 4096.
  - When present, require positive integer `<= 4096` and map unchanged to backend `max_tokens`.
  - Reject non-integer, zero, negative, `> 4096`, and legacy `max_tokens`.
- Enforce `temperature`:
  - When omitted, omit backend `temperature` parameter.
  - When present, require JSON number in `[0, 1]` and map unchanged to backend `temperature`.
  - Reject `< 0`, `> 1`, null, or non-numeric types.
- Enforce `store`:
  - Optional; accept omitted or exactly `false`. Reject `true`, null, or non-boolean.
- Enforce `include`:
  - Optional; accept omitted or exactly `["reasoning.encrypted_content"]`. Reject other arrays, elements, or types.
- Update `messagesRequest` and translation helpers in `internal/connector/anthropic/translate.go` to carry mapped parameters (`model`, `stream`, `max_tokens`, `temperature`).
- Verify input byte immutability and ensure no upstream dispatch occurs on failure.
- Out of scope: admission usage budget binding (M4-009), HTTP transport error classification (M4-010), streaming SSE execution (M4-013), tools (M4-017), and reasoning support (M4-029/M4-030).

## Acceptance

- [x] Top-level allowlist admits only `model`, `input`, `instructions`, `stream`, `max_output_tokens`, `temperature`, `store`, and `include`; any other top-level property fails locally with client-safe `*core.GatewayError`.
- [x] `stream: true` is strictly required; missing, `false`, null, or non-boolean values fail locally before upstream dispatch without mutating body bytes.
- [x] Omitted `max_output_tokens` defaults to 4096; explicit positive integers `<= 4096` are preserved in translated `max_tokens`; values `0`, negative, `> 4096`, floats, or legacy `max_tokens` fail locally.
- [x] Omitted `temperature` leaves backend `temperature` omitted; numbers in `[0, 1]` are mapped unchanged; values `< 0`, `> 1`, or non-numbers fail locally.
- [x] Omitted `store` or `store: false` succeeds; `store: true` or non-boolean fails locally.
- [x] Omitted `include` or `["reasoning.encrypted_content"]` succeeds; other arrays/elements/types fail locally.
- [x] All validations preserve admitted request body immutability and perform no network dispatch or model rewrite on failure.
